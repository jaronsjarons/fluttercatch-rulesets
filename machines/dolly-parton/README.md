## Full strategy

### Summary

Hit the first inline target to light the spinner, then test it once. Repeat a strong spinner; if it is weak, finish the inline bank for 5X before returning to it.

### Steps

- Plunge for the top saucer. Watch the miss and saucer feeds before you shoot the upper playfield again.

Mode Notes

- Skill shot: The top saucer adds one P-A-R-T-O-N letter. Wide misses can enter either side of the upper playfield.

- Hit the first inline drop target immediately. This lights the spinner.

Mode Notes

- Lit spinner: Each registered spin scores its lit value. A shot that registers 10 to 15 spins is useful. A shot with 20 or more spins is excellent.

- Shoot the lit spinner once. Count the spins and watch the return.

- If the spinner registers at least 10 to 15 spins and returns safely, repeat it from the left flipper.

- If the spinner is weak, continue through the inline bank. Stop when the bonus multiplier reaches 5X.

Mode Notes

- Bonus multiplier: The second inline target lights 2X. The third lights 3X. The fourth lights 5X. The multiplier applies to the end-of-ball bonus.

- At 5X, return to the lit spinner. From the right flipper, transfer the ball left when the transfer is safe.

- From the right flipper, shoot left of the bumpers and nudge the rebound toward the upper-left DOLLY targets or top saucer. Use this letter route in qualifying; in match play, return to a strong lit spinner.

Mode Notes

- Letters: The top saucer and inline drops add P-A-R-T-O-N. The upper-left standups add D-O-L-L-Y. Each lit letter adds 2,000 to base bonus.

### Overview

In Dolly Parton, the first inline drop lights the spinner, while deeper inline drops raise Bonus X through 5x. Test the spinner after the first target and repeat it when both spin count and return are strong; otherwise finish the inline bank before returning to it. In qualifying, complete D-O-L-L-Y and P-A-R-T-O-N once to hold 22,000 base bonus and twice to hold 44,000 across later balls.

### Fallback

Lit spinner

When

Use this plan when deeper inline targets or upper-left rebounds are dangerous.

Steps

- Hit only the first inline target.

- Repeat the lit spinner from the left flipper.

- Do not chase the 20,000 target behind the inline bank.

### Alternatives

- Qualifying bonus build

When

Use this plan in a best-game format or when the spinner is weak.

Steps

- Finish the inline bank for 5X bonus.

- From the right flipper, shoot left of the bumpers and nudge rebounds toward the upper-left DOLLY targets or top saucer. The inline drops and top saucer add PARTON.

- Complete one full letter set early for a held 22,000 base. Complete a second set for a held 44,000 base.

Mode Notes

- Held super bonus: The 22,000 and 44,000 bases remain available for later balls. With all ten letters and 5X, the maximum end-of-ball bonus is 320,000.

- Do not complete a third set unless Specials score points. A third set awards Special and resets the letters.

### Builds Toward

44,000 held Super Bonus

Steps

- Complete DOLLY with the five upper-left standups and PARTON with the top saucer and inline drops.

- The first complete DOLLY PARTON set locks a 22,000 base bonus for later balls.

- Complete the set a second time to lock a 44,000 base bonus.

### Simple Overview

In Dolly Parton, the first inline drop lights the spinner, and the next three inline drops raise Bonus X through 2x, 3x, and 5x. Hit the first drop and test the spinner; repeat it when it registers at least 10 to 15 spins with a safe return. When the spinner is weak, finish the inline bank for 5x and use the upper-left D-O-L-L-Y targets and top saucer to build held bonus.

### Machine Setup

- Confirm the 1979 Bally game, ball count, carryover, and Extra Ball or Special conversion.

- Test spinner registration, the inline-bank return, and saucer eject.
