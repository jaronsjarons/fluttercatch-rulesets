## Simple strategy

### Summary Title

The goal

### Summary

During single-ball play, shoot the flashing right orbit to raise the regular Jackpot and the left gap to advance innings. Then play regular Multiball through Home Run, orbit, and a timed return to Home Run for Jackpot, Double Jackpot, and an innings-scaled Super Jackpot.

### Steps

- During non-mode single-ball play, shoot the flashing right orbit to add 10M to the regular Jackpot.

- Shoot the left gap during non-mode single-ball play to advance innings and raise the eventual Super Jackpot by 100M per completed inning.

- Prepare regular multiball through Players Choice or the bullpen while keeping the Home Run feed under control.

- Start multiball and shoot Home Run for the base jackpot.

- Use the right orbit, or the left loop during multiball, to raise the jackpot before returning to Home Run.

- Return to Home Run within the combo window for the doubled award, then repeat the orbit-to-Home-Run cycle.

- After the required cycles, collect the Super Jackpot whose value reflects the innings built before the start.

- If the sixth inning completes, switch to the Seventh Inning route and use the major loops to spell BIG HURT for doubled jackpots.

### Simple Overview

Frank Thomas' Big Hurt builds two values before regular Multiball: the flashing right orbit raises the Jackpot, and the left gap advances innings to raise the Super Jackpot. Build both during single-ball play, then shoot Home Run, an orbit, and Home Run again within five seconds for Jackpot and Double Jackpot before repeating the cycle for the Super.
