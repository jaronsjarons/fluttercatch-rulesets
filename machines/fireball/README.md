## Simple strategy

### Summary Title

The goal

### Summary

On the 1972 Bally Fireball, learn the 3K plunge, keep one ball in Wotan when possible, and repeat the Wotan gate instead of forcing uncontrolled three-ball play.

### Steps

- Plunge so the ball stops before the upper-left gate. Let it fall across the horizontal 1K lanes.

- Use the plunge to light the mushroom bumpers. Treat each later lock as another skill-shot chance.

- Use the center mushroom to zip the flippers when the hit is available through normal play.

- Settle the ball on the zipped flippers. Micro flip the ball up the opposite flipper.

- Backhand Odin or Wotan to lock a ball. Prefer Wotan when both saucers are available.

- With one ball held in Wotan, repeat the Wotan shot. Let the moving ball pass the gate and score the lit bumper values.

Details

- Wotan gate loop: The held ball blocks the saucer. The next ball passes through the gate and crosses the upper rollovers before it returns.

- Lock value: Each lock also gives a new plunge and another chance at the 3K skill shot.

- If a side mushroom releases the held ball, relock a ball as soon as control permits. Do not chase three-ball chaos for its own sake.

### Alternatives

- Controlled multiball recovery

When

Use this after a side mushroom releases a locked ball.

Steps

- Keep the flippers zipped when the ball paths permit it.

- Do not flip at a ball that can settle on the zipped flippers.

- Use short flips to separate the balls.

- Return one ball to Odin or Wotan before you resume gate loops.

### Builds Toward

Repeat Wotan scoring

Steps

- Plunge the lit upper lane to light the mushroom bumpers.

- Zip the flippers and lock one ball in Wotan.

- Repeat the Wotan gate while the lock remains held.

- Restore the Wotan lock after each multiball release.

### Cautions

- Issue

Most non-saucer shots can rebound without control.

Response

Prefer saucer backhands. Trap the ball before each planned lock shot.

Source Url

[Source](https://rules.silverballmania.com/rules/G48ZN-Mb58O)

- Issue

The spinning rubber disk can hold a ball briefly and then throw it in a new direction.

Response

Keep both flippers ready when the ball crosses the disk. Do not predict a clean feed from its first contact.

Source Url

[Source](https://rules.silverballmania.com/rules/G48ZN-Mb58O)

- Issue

Top-bumper feeds can return at high speed and start uncontrolled multiball.

Response

Do not force a side-mushroom release. Rebuild one useful lock after the balls separate.

Source Url

[Source](https://rules.silverballmania.com/rules/G48ZN-Mb58O)
