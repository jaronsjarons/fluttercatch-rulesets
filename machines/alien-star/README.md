## Simple strategy

### Summary Title

The goal

### Summary

Complete ALIEN, use the spinner to select 5x, then start two-ball play at the left saucer. During multiball, repeat the spinner and use the right return lane for short 10x spinner windows.

### Steps

- Complete the ALIEN standups. Favor controlled or incidental hits over direct center rebounds.

- Shoot the spinner until 5x is selected. Then avoid the spinner while you finish ALIEN, so the saucer start keeps the selected 5x.

- Shoot the left saucer to start Alien Star Multiball.

Details

- Alien Star Multiball: Complete ALIEN, select a multiplier with the spinner, then shoot the left saucer to release the locked ball for two-ball play.

- Repeat the spinner during multiball. Use the second ball as protection for the fast center return.

- When the right return lane lights 10x spinner, take the spinner immediately if the feed is controlled.

- After one ball remains, rebuild ALIEN. Restore 5x only if later spinner contact moved the selection away from it.

- Multiplier selection

### Fallback

Alternative route: Right-return spinner

When

Use this when the left saucer or ALIEN standups are rejecting dangerously.

Steps

- Move the ball to the left flipper with a controlled transfer.

- Shatz pass through the right return lane to start the short 10x spinner window.

- Shoot the spinner at once. Do not spend the timer trying to regain a perfect cradle.

- Return to ALIEN progress when the center feed is stable.

### Warning

Direct ALIEN standup shots can rebound toward the drain.

Take letters from controlled angles or collect them incidentally during spinner work.

- 5x spinner without multiball

When

Use this when the spinner is safe but the left saucer is not.

### Simple Overview

Alien Star uses A-L-I-E-N to qualify two-ball play and the spinner to select its scoring multiplier. Complete the letters, time a spinner shot for 5x, start at the left saucer, then use the right return lane for short 10x spinner windows.

### Overview
