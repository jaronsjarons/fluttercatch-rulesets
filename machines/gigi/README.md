## Simple strategy

### Summary Title

The goal

### Summary

Send the ball between adjacent red bumpers and nudge for more contacts. Complete either color set during one ball for end-of-game bonus.

### Steps

- Plunge to graze the top of yellow bumper 4.

- Guide the falling ball toward yellow bumper 3 or 5.

- Read both color sets before the ball reaches a flipper.

- Shoot between adjacent red bumpers from 2-3 through 5-6.

- Nudge while the ball is among the bumpers to extend the current color set.

- Repeat the red-bumper threads until one color set reaches all seven.

- When the ball reaches the top, accept natural hits on the two upper standup targets.

- Ignore the five green rollovers and continue the bumper route.

### Quick Info

- Two color sets

Summary

Gigi has one seven-bumper red set and one seven-bumper yellow set.

- Single-ball sets

Summary

A color set must reach all seven bumpers during one ball because the bumper lamps reset each ball.

- End-of-game bonus

Summary

One completed set gives 100, two give 200, and three or more give 300 at game end.

### Fallback

Alternative route: Scoring side drain

When

Use this plan only when a drain is unavoidable and the ball can still reach either outlane.

Steps

- Stop flipping when another stroke would direct the ball toward the center drain.

- Use one small nudge toward the nearer outlane.

- Let the outlane score 100 instead of accepting a zero-point center drain.

- On the next ball, restart a complete color set because all bumper lamps reset.

### Warning

Feeds from the bumpers and side lanes can reach a drain or the slingshots without control.

Track each exit and nudge before the ball reaches a slingshot. Do not assume a side-lane feed is safe.

### Alternatives

- Upper standup pass

When

Use this plan when bumper action already sends the ball above the yellow 2 or 6 bumper.

Steps

- Track the ball while it remains above the yellow bumpers.

- Nudge toward the nearby upper standup target.

- Do not replace an open bumper thread with a forced standup shot.

- Resume bumper threads when the ball returns to the lower flippers.

### Builds Toward

Maximum 300 end-of-game bonus

Steps

- Complete all seven bumpers of either color during one ball.

- On a later ball, complete another full color set.

- Complete a third full color set before the game ends.

- Protect each ball because six lit bumpers give no set credit.

### Simple Overview

Gigi counts one complete seven-bumper red set or yellow set toward its end-of-game bonus, but partial sets reset at the start of each ball. Thread the ball between adjacent bumpers, nudge for missing contacts, and finish one color before the ball drains.

### Overview

Gigi turns complete seven-bumper color sets into an end-of-game bonus, but partial sets reset every ball. Use repeatable threads between adjacent red bumpers and controlled nudges to finish one color in a single ball. Complete full sets on later balls until the game-end award reaches its three-set maximum.
