- Hit lit 20,000 targets to raise the head-wheel value, then send the ball to the upper rider to collect it.

## Full strategy

### Overview

Devil Riders links its two moving-ramp banks to Specials and drain recovery. Complete either five-target bank to lower the moving ramp, advance Orange Special, and light REACT. Hit the flashing Advance Red Special targets to build D-E-V-I-L R-I-D-E-R-S and raise the head-wheel value; lit 20,000 targets also raise that value. Send the ball to the upper rider to collect the lit head-wheel score. Side tunnels advance the bonus multiplier. When REACT is lit, press a flipper button as the ball enters an outlane to return it to play.

### Alternatives

- Keep REACT available

When

Use this when outlane risk matters more than finishing a Special.

Steps

- Complete the required target or bank sequence to relight REACT.

- If the ball enters an outlane while REACT is lit, press the corresponding flipper button to return it to play.

### Builds Toward

Convert a completed bank

Steps

- Use a Spot Move Ramp target to spot a bank target and relight REACT when helpful.

- Finish that bank, then take the lowered moving ramp or lit Special before beginning the other side.

### Machine Setup

- Check the DEVIL RIDERS letters awarded per bank, Orange Special bank requirement, REACT reset setting, ball count, and configured Special awards.

- Test both five-target banks, moving ramps, Spot Move Ramp targets, Advance Red and 20,000 targets, upper rider, both side tunnels, REACT lamps, and outlane switches.

### Cautions

- Issue

REACT relight and Special progress vary by setup.

Response

Confirm whether one target or a whole bank relights REACT, and how many DEVIL RIDERS letters each completion awards.
