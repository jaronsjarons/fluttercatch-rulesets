## Simple strategy

### Summary Title

The goal

### Summary

Collect useful lit 1–9 numbers at the center target, redirect repeats into SPECIAL lanes, then collect the safest center, saucer, or return-lane award.

### Steps

- Read the lit number below the center target before each controlled shot.

- If the number extends a row or adds a missing corner, shoot the center target.

- If the lit number is already collected, shoot a safe lettered lane instead.

- Use 100-point switch play to move the lit number. Read the new number before another center shot.

- After three in a row or all four corners, collect a lit center-target or side-saucer award.

Details

- Number pattern: Gulfstream lights the center target and both saucers for 5,000. Tropic Fun awards 50,000 for a line and 100,000 for four corners.

- Complete S-P-E-C-I-A-L through the lettered lanes.

- Collect a lit return lane when its feed is safer than another center-target rebound.

### Quick Info

- Center target

Summary

The center standup collects the currently lit number from the 1-9 grid.

- Number change

Summary

Each 100-point switch changes which 1-9 number is lit for the center target.

- Number patterns

Summary

Three numbers in a row or all four corners light the center target and both side saucers for major awards.

### Fallback

Alternative route: SPECIAL lane route

When

Use this when the lit number repeats or center-target rebounds are not controlled.

Steps

- Identify a missing S-P-E-C-I-A-L letter.

- Shoot the safer lettered lane.

- Complete all seven letters to light both return lanes.

- Collect the safer lit return lane.

### Warning

Bumper exits can reach the slingshots, center drain, or outlanes without flipper control.

Prepare both flippers before the ball leaves the bumpers. Stop forcing switch play after an unsafe exit.

### Simple Overview

Gulfstream and Tropic Fun use the center target to collect lit numbers on a changing 1-through-9 grid. Form three in a row or four corners for major awards; complete S-P-E-C-I-A-L when its lane returns are safe to light both return lanes.

### Overview

In Gulfstream and Tropic Fun, the center target records whichever number is lit on the 1-through-9 grid. Completing a row or all four corners lights the center target and both saucers for their larger awards. Completing S-P-E-C-I-A-L lights both return lanes; Tropic Fun uses ten-times scoring and add-a-ball treatment.

### Machine Setup

- Identify Gulfstream replay, Tropic Fun add-a-ball, or licensed Segasa Gulfstream before applying score scale and award rules.

- Confirm ball count, Extra Ball and Special handling, tilt, and whether replay awards receive tournament point substitutes.
