## Simple strategy

### Summary Title

The goal

### Summary

Make the loop skill shot, spell JUDGE, use the left ramp to build Multiball, alternate the left ramp and subway for four rising Jackpots during Multiball, then complete the set to reach Ultimate Challenge.

### Steps

- Let the plunge circle the large loop. Use the upper-left flipper to shoot the loop again for the skill shot.

- Use the opening ball save to test the JUDGE bank, both ramps, and the Deadworld subway return.

- Complete the JUDGE drop targets to light each lock. After collecting two locks, leave the third lock lit until the left-ramp feed is controlled.

- Shoot the left ramp for each lock. The third lock starts four-ball Multiball on release software.

Details

- Deadworld Multiball: Release behavior depends on the installed Deadworld mechanism and ROM settings.

- During Multiball, use JUDGE hits to build Jackpot value. Shoot the left ramp to light the next Jackpot.

- Shoot the subway behind the Deadworld target to collect the Jackpot. Repeat the ramp and subway cycle four times.

Details

- Jackpot ladder: The four awards are Mortis, Fire, Fear, and Death.

- After the Death Jackpot, use the replenished balls to shoot the lit Crime Scenes.

Details

- On release L-7, Ultimate Challenge restores lost balls and lights the Crime Scene shots for 10,000,000 each.

- Between Multiballs, start a safe Chain Link at the flashing left ramp or Sniper Tower. Prefer Manhunt, Blackout, or Sniper Tower when their shots are controlled.

Summary

### Fallback

Alternative route: Ramps and Crime Scenes

When

Use this plan when the JUDGE bank produces dangerous rebounds.

Steps

- Repeat the safer ramp. Its unlit value increases during the current ball.

- Collect a lit Crime Scene when its shot has a controlled return.

- Start a Chain Link only when its flashing start shot is safe.

- Return to the JUDGE bank only when one lock will justify the rebound risk.

Summary

The left ramp and Sniper Tower alternate as mode starts during single-ball play.

- Chain Links and Multiball

Summary

Starting regular Multiball normally stops the active Chain Link, then restarts it after Multiball with its points preserved. Certain two-stage Chain Links can remain active because of a software bug; do not depend on that exception.

### Builds Toward

Death Jackpot and six-ball Ultimate Challenge

Steps

- Complete all four Multiball Jackpots to start the immediate Ultimate Challenge.

- Play all nine Chain Links to qualify the full six-ball Ultimate Challenge.

- On release L-7, shoot the lit Crime Scenes for 10,000,000 each during Ultimate Challenge.

### Cautions

- Issue

The JUDGE drop bank can send the ball toward the center or the slings.

Response

Work the bank under ball save or Multiball protection. Stop when the next lock is not close.

Source Url

[Source](https://www.pinball.org/rules/judgedredd.html)

- Issue

Deadworld lock and release behavior differs between mechanisms, ROMs, and operator settings.

Response

Watch the first release. Use the actual feed instead of assuming prototype or release-ROM behavior.

Source Url

[Source](https://www.pinball.org/rules/judgedredd.html)

- Issue

A lit lock prevents the left ramp from starting a Chain Link, and ball time in the Deadworld mechanism does not pause an active Chain Link timer.

Response

Start the Chain Link before you light the lock, or use the Sniper Tower start. Do not spend mode time waiting on a slow Deadworld return.
