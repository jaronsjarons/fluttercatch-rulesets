## Simple strategy

### Summary Title

The goal

### Summary

Read the Solar Value and flashing rainbow line. Hit the exact flashing target to open the visor, lock both eye saucers, and start Visor Multiball. Relock one ball, then shoot the ramp with the other for repeatable Solar Value collects.

### Steps

- Before the plunge, read Solar Value and the flashing rainbow line. Dial the center Vortex only if the plunge is repeatable.

- From control, hit the exact flashing rainbow target to open the visor immediately.

Details

- Rainbow grid: A correct flashing target opens the visor; a miss means that all 25 grid lights must be completed.

- If the direct target is unsafe, complete the rainbow grid in rows. When Energy Value is worthwhile, hit the lit left drop target and shoot the raised ramp to collect it.

- After the visor opens, lock one ball in each eye saucer to start Visor Multiball.

Details

- Visor Multiball is two-ball full-playfield 2x scoring. Preserve one controlled ball because the eye-saucer ejects can end the feature quickly.

- Relock either ball in one eye saucer. The ramp lights the current Solar Value for a timed collect.

- Use the free ball to shoot the ramp and collect Solar Value before the timer expires.

Details

- Solar Value collect: The award resets to 100,000 after collection, so rebuild it before the next relock.

- Repeat the eye relock and ramp collect while two balls remain. Visor Multiball ends when one ball remains.

- After Multiball, rebuild the grid and Solar Value. Do not chase planets; use Advance Planet only when its carried bonus can decide the game.

Summary

### Fallback

Alternative route: Recovery: Full grid and ramp value

When

Recovery pivot: Use this when the flashing rainbow target or eye saucers reject.

Steps

- Complete the 25 rainbow-grid lights in controlled groups.

- For Energy Value, hit the lit left drop target and shoot the raised ramp.

- Build Solar Value with repeatable ramp shots.

- Hit the final safe grid target to open the visor.

- Protect the carried Solar Value instead of forcing an eye lock.

### Warning

The center rainbow targets can reject toward the drain.

Shoot only the exact flashing target from control, or use safer grid progress.

### Alternatives

- Position play: Left saucer awards

When

When trailing, use this higher-ceiling route: use this when the saucer is lit for a useful award and its kickout is controlled.

Steps

- Shoot the upper-left saucer for its lit award.

- Use the returned plunge to raise the Vortex Multiplier.

- Resume grid or ramp progress after the top feed.

- Vortex plunge value

When

Use this when a center-Vortex plunge can be repeated without losing control.

Steps

- Dial the center Vortex on each served or returned plunge.

- Send each served or returned plunge through the center Vortex to raise its multiplier toward 10x.

- Stop after a plunge that misses the Vortex or gives an unsafe feed.

### Builds Toward

Repeated Solar Value cycles

Steps

- Build Solar Value toward 5,000,000 with ramp shots.

- Hit the flashing rainbow target to open the visor, then lock both eye saucers to start Visor Multiball.

- Relock one ball in an eye saucer.

- Collect Solar Value at the ramp before its timer expires.

- Repeat the relock and collect while two balls remain.

- The visor cycle is the main long-term objective; PIN-BOT has no separate wizard mode.

### Simple Overview

PIN-BOT uses the flashing rainbow target to open the visor, then one lock in each eye starts Multiball. Hit the exact flashing target, lock both eyes, relock one ball during Multiball, and shoot the ramp with the other for Solar Value.

### Overview

On PIN-BOT, the flashing rainbow target opens the visor, and one lock in each eye starts Multiball. Read the flashing rainbow line and Solar Value, hit the exact target, and lock both eyes. During Multiball, relock one ball to light the timed ramp collect, shoot the ramp before the Solar Value timer expires, and repeat while two balls remain.
