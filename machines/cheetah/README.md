### Summary Title

The goal

### Summary

Build Bonus X from the top or right bank, complete 1–5 to light Collect Bonus, and cash the long left lane only after checking whether this copy allows repeated collections.

### Steps

- Work the top three-bank or repeat the more reachable right three-bank to raise Bonus X.

- Complete the numbered 1–5 drop bank; the lit next number is worth more, and completion lights the far-left Collect Bonus lane.

- Build base bonus with the right bank, outer return lanes, or a second numbered-bank completion.

- When the base and multiplier are strong, shoot the narrow far-left lane to collect.

## Full strategy

### Overview

Cheetah is a build-and-collect game. The top three-bank and repeated right-bank completions raise Bonus X, while the numbered five-bank lights the long left Collect Bonus lane. Build the base and multiplier before taking that lane, and determine first whether the installed code permits one collect or repeated collects per ball.

### Simple Overview

### Alternatives

- One-collect setup

When

Use this when the game allows only one bonus collection per ball.

Steps

- Leave the Collect Bonus lane lit while raising the base and multiplier.

- Take the lane only after the bonus is near its useful maximum.

- After the collect, switch to bank values, lit spinners, or the horseshoe instead of expecting another collect.

### Builds Toward

Maximum bonus and a controlled collect

Steps

- Raise Bonus X through the top or right bank.

- Finish 1–5 to light Collect Bonus and repeat it to max the base.

- Shoot the far-left Collect Bonus lane.

### Machine Setup

- Identify stock versus updated/custom code before play; the Minutorial explicitly warns that rule behavior differs.

- Test all three drop banks, the numbered sequence, far-left collect lane, horseshoe, spinners, bonus lamps, and upper-left flipper feed.

- Confirm whether bonus can be collected once or repeatedly per ball, plus Extra Ball and Special conversion.

### Cautions

- Issue

Stock and updated/custom Cheetah code can change progression and collect behavior.

Response

Read the installed-code notice and verify collect behavior on that machine; do not transfer updated-code rules blindly to stock code.
