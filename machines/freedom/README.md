## Simple strategy

### Summary Title

The goal

### Summary

Prioritize upper-playfield access over square target hits. The saucers convert the wheel's current selection into a feature, while repeated trips through the top also feed the bumpers and lit spinners.

### Steps

- Shoot to the top and read the feature selected on the center wheel.

- Shoot either upper saucer to collect or activate the selected feature.

- When Lite Spinners is selected, use the saucer to light both spinners, then repeat the safer side shot.

- Finish the target set only from controlled feeds; the first completion awards the configured Extra Ball and later completions add 5,000.

## Full strategy

### Overview

Freedom's central wheel points to the feature the upper saucers can activate. When Lite Spinners is selected, shoot either upper saucer to light both side spinners; other wheel positions award the indicated feature. Every additional completed target bank adds 5,000, and finishing the full target set awards the configured Extra Ball. The controlled plan is to keep returning to the top, collect the selected wheel feature, then exploit lit spinners.

### Simple Overview

Shoot to the top and use either upper saucer to collect the feature shown on the center wheel. When Lite Spinners is selected, a saucer lights both side spinners; keep sending the ball through them for 1,000 per spin. Finish the target set for the configured Extra Ball, with later target-bank completions adding 5,000.

### Alternatives

- Target-completion route

When

Use this when the saucer feeds are poor but the targets can be grazed safely.

Steps

- Pick off the outermost remaining targets rather than shooting through the center of the set.

- Complete the set for the configured award.

- Return to the upper saucers after the bank resets.

### Builds Toward

Lit-spinner control loop

Steps

- Return to the top until the wheel selects Lite Spinners.

- Collect that feature at either upper saucer.

- Repeat side-spinner shots while using upper-playfield returns to regain control.

### Machine Setup

- Identify the electromechanical or solid-state edition; test the center feature wheel, both upper saucers and ejects, both spinners, the full target set and reset, bumpers, outlanes, and the Extra Ball and Special lamps.

- Confirm spinner value, three- or five-ball play, Extra Ball versus replay settings, and the early-versus-later instruction-card target award before competition.

### Cautions

- Issue

Freedom exists in EM and solid-state editions, and multiple factory cards survive.

Response

Verify the installed apron card: spinner values and the first completed-target award can differ by production and operator configuration.
