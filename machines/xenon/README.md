## Simple strategy

### Summary Title

The goal

### Summary

Repeat the left orbit from the right flipper and tube ramp from the left, build the left saucer, qualify two three-hit saucer sets, then use Multiball to light the 1,000-point spinner.

### Steps

- Use the plunge and right flipper to send the ball to the top saucer.

- From the right flipper, repeat the left orbit for safe top access.

- Hit the top saucer three times to light Lock.

- From the left flipper, shoot the tube ramp into the left saucer to lock the ball.

- Hit the top saucer three more times to start Multiball.

- During Multiball, repeat the top-saucer set to light the 1,000-point spinner, then rip the spinner while extra balls remain.

- After Multiball, repeat the left orbit and built tube-ramp saucer route.

### Quick Info

- Left saucer

Summary

Tube-ramp collects raise the saucer from 5,000 to 90,000, where it remains.

- Ball lock

Summary

Three top-saucer hits light the lock at the left saucer through the tube ramp.

- Multiball

Summary

After a ball is locked, three more top-saucer hits start Multiball.

### Fallback

Alternative route: Left-orbit control

When

Use this when the tube-ramp saucer kickout is unsafe.

Steps

- Delay the ramp and lock.

- Repeat the left orbit from the right flipper.

- Use safe top-saucer and upper-rollover contacts for progress.

- Return to the tube ramp only when Multiball protection or a safe kickout makes the risk acceptable.

### Warning

Pop-bumper exits and direct drop-target rebounds can send the ball toward a drain.

Prefer orbit access and upper rollovers that spot targets over direct bank shots.

### Alternatives

- Bank and bonus route

When

Use this when upper rollovers spot bank targets and the orbits are unreliable.

Steps

- Use upper rollovers to spot targets without direct bank rebounds.

- Complete the bank once for 2x bonus and again for 4x bonus.

- Take later bank awards only when the target return remains safe.

- Built 90,000 saucer

When

Use this when the tube ramp and saucer kickout are repeatable.

Steps

- Repeat the tube ramp to raise the left-saucer value by 5,000 per collect.

- Reach 90,000 and continue the ramp only while its return stays controlled.

### Builds Toward

Multiball, 1,000-point spinner, and retained Super Bonus

Steps

- Complete the first three-hit top-saucer set and lock a ball.

- Complete the second three-hit set to start Multiball.

- Complete another saucer set during Multiball to light the spinner.

- Rip the lit spinner while protected.

### Techniques

- Two-flipper orbit loop

Instruction

Shoot the left orbit from the right flipper, then shoot the tube ramp from the left flipper after the return is controlled.

- Issue

Response

### Simple Overview

Xenon uses repeated top-saucer sets to light a lock, start Multiball, and then light its high-value spinner. Repeat the left orbit and tube ramp, complete two three-hit saucer sets for Multiball, then complete another set during Multiball before ripping the lit spinner.

### Overview

Xenon uses repeated top-saucer sets to light a lock, start Multiball, and then light its high-value spinner. Use the first cycle to light and take the lock, the second to start Multiball, and a third during Multiball to light the 1,000-per-spin spinner and 50,000 outlanes. Build the left-saucer value along the way and reach the 20,000 and 40,000 Super Bonus floors.
