## Full strategy

### Summary

Use the top drops and Snake Run for safe awards. Spell RADICAL for each lock. In multiball, collect Mega-Million and rebuild it.

### Steps

- Plunge through the left ramp when the needed RADICAL letter is lit. Test the four flipper feeds and both outlanes.

- Complete the three top drop targets. Then shoot the lit Snake Run behind them.

Mode Notes

- Snake Run: A timed random award. Awards include Skate or Die, extra ball, stored feature totals, points, or 1,000,000.

- Skate or Die: Immediately lights the three lock shots without a RADICAL completion.

- Complete RADICAL through the seven major shots. Use the bottom drops and Spot Letter target when a direct ramp is unsafe.

Mode Notes

- RADICAL: Snake Lane, vertical ramp, left orbit, right ramp, bottom drops, left ramp, and right orbit each own one letter.

- A completion lights Skate or Die, relights the left kickback, lights Bottom Million, and adds 100,000 carried bonus.

- Lock the first ball at the Snake Lane, left ramp, or right ramp. Complete RADICAL again. Then make a lit lock shot to start two-ball multiball.

Mode Notes

- First lock: RADICAL and its letter values reset. The second lock needs a new RADICAL completion unless Snake Run awards Skate or Die.

- During multiball, shoot the left ramp for Mega-Million.

Mode Notes

- Mega-Million: A jackpot selected from 3,000,000 to 10,000,000 on standard code. Tournament settings can fix the value.

- The left ramp remains lit briefly if one ball drains.

- After the jackpot, spell RADICAL. Put both balls into the lock lane within about three seconds. Then shoot the left ramp again.

Mode Notes

- Jackpot relight: During multiball, RADICAL lights the lock lane. Two fast re-locks relight Mega-Million.

- If one ball drains before both re-locks, finish RADICAL and take one lit physical lock for the next multiball.

Mode Notes

- At Free Play Florida 2018, Escher Lefkoff collected the opening Mega-Million, then ended the multiball with one ball physically locked for the next build.

### Fallback

Snake Run awards

When

Use this when several letter shots or the upper-left flipper feed are not controlled.

Steps

- Complete the top drop bank to light Snake Run.

- Shoot the target behind the bank before its timer ends.

- Take Skate or Die when awarded. Otherwise, repeat for points, 1,000,000, or another useful award.

### Alternatives

- Tail Sliders

When

Use this when the left ramp safely feeds the upper-right flipper.

Steps

- Collect the second A in RADICAL to light Tail Slider.

- From the upper-right flipper, repeat the left ramp for 100,000 per Tail Slider.

Mode Notes

- Tail Slider: A self-feeding left-ramp loop. The diverter ends the run after two shots, then three, then four on later runs.

### Builds Toward

Repeat Mega-Million jackpots

Steps

- Complete RADICAL twice and start multiball.

- Collect Mega-Million at the left ramp.

- Complete RADICAL and re-lock both balls for each additional jackpot.

### Cautions

- Issue

The upper-left flipper has no guide and usually receives an uncontrolled bumper feed.

Response

Do not depend on it for a critical right-ramp letter. Use Spot Letter or Snake Run when the feed is not clean.

Source Url

[Source](https://www.youtube.com/watch?v=iqyxn1EH1OA&t=75s)

- Issue

The right inlane and outlane area can be difficult to save.

Response

Nudge before the ball settles there. Use the sling top or nearby post to move the ball back toward the playfield.

Source Url

[Source](https://www.youtube.com/watch?v=iqyxn1EH1OA&t=382s)

- Issue

Both drop banks remove ball control and can return the ball toward a drain.

Response

Use them for Snake Run, Spot Letter, or Bonus X only. Be ready before every rebound.

Source Url

[Source](https://pinball.org/rules/radical.html)

### Simple Overview

In Radical!, complete R-A-D-I-C-A-L to light a lock at the Snake Lane, left ramp, or right ramp. Lock one ball, complete the letters again, then shoot a lit lock to start two-ball Multiball. Shoot the left ramp for Mega-Million; to relight it, complete R-A-D-I-C-A-L and put both balls into the lock lane within about three seconds.

### Overview

In Radical!, each R-A-D-I-C-A-L completion lights one of three lock shots, and the second lock starts two-ball Multiball. Use the top drop bank and Snake Run for safe awards, complete the letters twice, then shoot the left ramp for Mega-Million. Complete the letters again and relock both balls quickly to relight that Jackpot, or preserve one physical lock for the next Multiball if one ball drains.
