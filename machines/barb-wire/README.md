## Simple strategy

### Summary Title

The goal

### Summary

Advance the Start Round state at Big Fatso, finish Hideout, Big Fatso, Crash the Tolls, and Hammerhead Bar, then play Haywire. Use each multiball round's long save and left-ramp add-a-ball before chasing its objectives.

### Steps

- Enable Tournament Mode by holding both flippers before Start, then test Big Fatso, Retina Scan, Mind Read, and their ejects.

- Follow the Big Fatso insert through light Start Round, open the door, and start the lit round only when the return is controlled.

- Complete Hideout, Big Fatso, Crash the Tolls, and Hammerhead Bar by following each round's lit objectives.

- At the start of a multiball round, shoot the lit left ramp for its one add-a-ball while the long ball save remains active.

Details

- Round ball-count rule: Multiball rounds begin with two balls and light the left ramp for one additional ball.

- After all four rounds are complete, start Haywire. Collect roving arrow shots to finish H-A-Y-W-I-R-E before falling to one ball.

- In Haywire frenzy, use the four balls and long save to build the bonus to 990M, then collect it at Big Fatso when the door opens.

- If Haywire ends before the letters are complete, use controlled skill shots or Retina Scan awards to finish the word and restart the frenzy.

- Collect Mega Bonus at Big Fatso only after testing the opening and eject; otherwise preserve control and continue rounds.

### Fallback

Alternative route: Arrow and Firefight route

When

Use this when Big Fatso or its return is unsafe.

Steps

- Collect the lit major-shot arrows from controlled feeds.

- Complete the arrow set to start Firefight multiball.

- Use the moving lit jackpots for protected points, then resume round progress.

### Warning

The lower-right kickout can eject close to the center drain.

Test and trap its feed before relying on repeated Mind Read or Mega Bonus collects.

- Mega Bonus cashout

When

Use this when Mega Bonus is already built and one safe collect can secure position.

Steps

- Hit the lower-right target to open Big Fatso.

- Collect Mega Bonus only if the opening and eject are behaving predictably.

- Do not repeat the dangerous target after the needed score is secured.

### Builds Toward

Haywire

Steps

- Complete Hideout, Big Fatso, Crash the Tolls, and Hammerhead Bar.

- Start Haywire and collect its roving H-A-Y-W-I-R-E arrows while two or more balls remain.

- Build the frenzy bonus to 990M and collect it at Big Fatso.

- If needed, complete retained letters through skill shots or Retina Scan to restart Haywire frenzy.

### Check Before Play

- Confirm the 1996 Gottlieb/Premier game, installed revision, Tournament Mode, round order, qualification counts, and ball-save times.

- Tournament Mode must disable persistent BARB WIRE progress and convert Extra Ball to 50M and Special to 200M.

- Test the manual and auto-plunges, lower Mind Read eject, Retina Scan eject, Big Fatso door and eject, left-ramp add-a-ball switch, and center post.

### Overview

Barb Wire advances one active round through the Big Fatso start sequence, and several rounds begin their own Multiball. Follow Big Fatso through light, open, and start states, complete each round's displayed objectives, and use the opening ball save to collect the left-ramp add-a-ball during Multiball rounds.
