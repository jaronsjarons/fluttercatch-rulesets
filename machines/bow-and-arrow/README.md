## Simple strategy

### Summary Title

The goal

### Summary

Build at least 7,000 bonus with the spinners, then repeat the upper-left saucer from the right flipper.

### Steps

- On the plunge, try to enter the top saucer when 3,000 is lit.

Details

- Top saucer at 3,000: Scores 3,000 and opens the return gate.

- Backhand either spinner to build bonus. Use the safer spinner on this machine.

- When bonus reaches at least 7,000, trap on the right flipper.

- Shoot the upper-left saucer to collect the full bonus.

Details

- Bonus saucer: Collects the current bonus without resetting it.

- Control the saucer kickout on the right flipper. Repeat the saucer.

### Cautions

- Issue

The A-B-C-D standups can give dangerous rebounds.

Response

Do not shoot them as a main plan. Finish the bank only when one letter remains.

Source Url

[Source](https://www.kineticist.com/games/pinball/bow-and-arrow)

- Issue

The upper-left saucer kickout can remove control.

Response

Watch the first kickout. Use the tested One-time shot or Live catch; abandon repeat saucer play if neither receives it safely.

Source Url

[Source](https://www.kineticist.com/games/pinball/bow-and-arrow)

- Issue

A ball through the open return gate can become a house ball after the next plunge.

Response

Do not shoot at the gate from a flipper. Nudge through it only when the ball is already near it.

### Simple Overview

In Bow and Arrow, shoot either spinner to build base bonus, then shoot the upper-left saucer from the right flipper once the bonus reaches at least 7,000. The saucer collects the full bonus without resetting it, so control the kickout and repeat the saucer.

### Overview

In Bow and Arrow, spinner shots build base bonus and the upper-left saucer collects the current value without resetting it. Build at least 7,000 through the safer spinner, trap on the right flipper, then repeat the saucer while its kickout remains controlled. Finish A-B-C-D for Double Bonus only when three letters are already complete.

### Machine Setup
