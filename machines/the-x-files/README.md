## Simple strategy

### Summary Title

The goal

### Summary

Hit the file cabinet until its drawer opens, then enter it to start Multiball. Make two left-ramp Jackpots, the timed right-ramp Double Jackpot, and the cabinet Super Jackpot.

### Steps

- Test the file-cabinet rebound and both ramp returns while ball save is active.

- Hit the file cabinet until its upper drawer opens.

- Shoot the open drawer to start File Cabinet Multiball.

- Shoot the left ramp for the first Jackpot, then repeat the left ramp for the second Jackpot.

- Transfer quickly to the right ramp for the timed Double Jackpot.

- Shoot the file cabinet for the Super Jackpot, then begin the sequence again while two balls remain.

Details

- Multiball order: Left ramp, left ramp, timed right ramp, then file cabinet for the Super Jackpot.

- If Multiball ends before any jackpot, shoot the cabinet during its one brief restart window, then take the first left-ramp Jackpot after the relaunch.

### Quick Info

- File Cabinet Multiball

Summary

Repeated cabinet hits lower the drawer; shooting the open drawer starts three-ball play.

- Jackpot sequence

Summary

Two left-ramp jackpots light a brief right-ramp Double Jackpot, followed by a cabinet Super Jackpot.

- Restart

Summary

If no jackpot was made before one-ball play, the cabinet may offer one brief restart window.

### Fallback

Alternative route: Episode scoring

When

Use this when the cabinet face or its drawer eject is unsafe.

Steps

- Shoot the scoop to start the available episode.

- Take the episode shots with the cleanest returns.

- Return to the cabinet only after its feed can be attacked from control.

### Simple Overview

The X Files turns the file cabinet and two ramps into a repeatable Multiball ladder. Hit the cabinet until its drawer opens and enter it, shoot the left ramp twice, transfer to the briefly lit right-ramp Double Jackpot, then hit the cabinet for Super Jackpot before beginning the sequence again.

### Overview

Repeated cabinet hits open its drawer and start The X Files' three-ball Multiball, whose Jackpots follow a fixed left-left-right-cabinet order. Execute the sequence from controlled feeds. Use the one restart window after an empty Multiball, or play Episodes at the scoop when cabinet rebounds make that loop unsafe.

### Machine Setup

- Confirm ROM, episode rules, timers, and award settings.

- Test cabinet hits, both ramps, and scoop returns.
