## Full strategy

### Summary

Send the ball up top to collect the numbered lanes, then choose between the 5,000-point center horseshoe and the center saucer, which scores for each collected number. Keep the route whose return survives the lower center bumper.

### Steps

- Send the ball up top to collect numbers 1 through 6.

- Shoot the center saucer after several numbers are lit; it scores 1,000 for each collected number.

- Shoot the center horseshoe for 5,000 when its exit off the lower center bumper is safer than the saucer kickout.

- Repeat the safer of those two shots. If neither return is controlled, return to the upper lanes.

### Simple Overview

Spanish Eyes uses the six numbered upper lanes to raise the center saucer's value. The center horseshoe pays a fixed 5,000, so the useful choice is between a growing saucer and a fixed horseshoe with different returns.

### Overview

Each numbered upper lane in Spanish Eyes adds 1,000 to the center-saucer value, while the center horseshoe always scores 5,000. Collect numbers up top, then compare the saucer kickout with the horseshoe exit off the lower bumper. Repeat the safer scoring shot, or return upstairs when neither feed is controlled.
