## Simple strategy

### Summary Title

The goal

### Summary

Use the spinner and top lanes to finish the three colors without direct target shots. Lock three balls. Build the jackpot to 1,000,000, then collect at the jump ramp.

### Steps

- Lane-change before the plunge. Put an unlit color insert under the lane between the two flashing guides.

Details

- Skill shot: The guided lane scores 100,000 times the ball number. An unlit color insert also spots one target of that color.

- From the right flipper, repeat the left spinner. Nudge the ball into an unlit top lane for an unfinished color.

Details

- Color progress: Green needs four standups. Yellow needs three. Red needs the captive ball. Unlit top lanes can spot these targets.

- Completing a color lights one arrest at the jump ramp and raises the spinner value, up to 3,000 per spin on default settings.

- When an arrest is lit, make the right jump ramp to lock one ball. Repeat the spinner and lane route for all three arrests.

- Lock the third ball at the jump ramp to start three-ball multiball.

Details

- RoboCop multiball: The jump ramp is lit for one jackpot. Normal scoring raises its value from about 500,000 to a 1,000,000 cap.

- During multiball, rip the spinner and let incidental standup rebounds raise the jackpot to 1,000,000. Then make the jump ramp.

- After the jackpot, hit five green, yellow, or red standups during multiball. Then shoot the ramp for Special when it is set to 1,000,000 points.

Details

- Post-jackpot Special: The target count is operator-adjustable. It is the only planned time to shoot standups directly.

### Alternatives

- Sweet Jump and 2x

When

Use this only when a made jump returns cleanly to the left flipper.

Steps

- Make two consecutive jump ramps to start double playfield scoring.

Mode Notes

- Double scoring: Two clean jumps start 2x. Further pairs of consecutive jumps refresh the feature on standard settings.

### Simple Overview

Robocop uses the spinner and top lanes to finish three color arrests without forcing the standups. Lock each completed color at the jump ramp, start three-ball Multiball, then rip the spinner to build the Jackpot and collect it at the ramp.

### Overview

Completing each green, yellow, or red target color lights one arrest at the jump ramp in Robocop. Take all three ramp locks to start Multiball. During Multiball, normal scoring raises the one available Jackpot toward 1,000,000; collect it at the jump ramp.

### Machine Setup
