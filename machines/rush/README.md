## Simple strategy

The goal

### Summary

Use colored records for a song, the Time Machine ramp for multiball, or purple records for La Villa Strangiato.

### Steps

- Start a song mode

Shoot flashing cyan record shots to qualify Tom Sawyer, or flashing orange record shots to qualify Working Man. Shoot the red-lit Time Machine to start the qualified song.

## Full strategy

### Summary

Prepare Time Machine Multiball, start Tom Sawyer or Working Man first, then begin the multiball and use a matching stored Album Weapon.

### Steps

- Short-plunge to the upper flipper. Take a controlled side-loop, side-ramp, or upper-scoop skill shot.

Mode Notes

- Skill shot: Any upper-flipper shot scores it and extends ball save. The upper scoop scores 3x. The side ramp scores 2x.

- A full plunge sends the ball into the bumpers. Use it only after the bumper exit is known.

- Shoot the Time Machine ramp until green Multiball is ready. Then stop one shot before the start.

Mode Notes

- Time Machine Multiball: The first attempt needs three power-up shots and one start shot. Later attempts need more shots. Time Machine decades reduce that requirement.

- The dead-end shot changes Red Barchetta, Subdivisions, or Fly by Night. Do not force the selector when its return is unsafe.

- Collect cyan records for Tom Sawyer or orange records for Working Man. Shoot the red-lit Time Machine to start the song mode.

Mode Notes

- Song mode: Flashing record shots qualify an untimed mode. The color with the most records selects the mode.

- More records add 10% to mode scoring. Matching-color record shots score 2x. Six matching records make all mode shots 3x.

- Qualification order: Collect the matching records before starting the ready song and Time Machine Multiball stack.

- Tom Sawyer: Shoot both orbits, then both ramps, then all major shots.

- Working Man: Shoot orange shots to move the clock from nine in the morning to five in the afternoon. The left orbit, side loop, and side ramp move it faster. Shoot the left orbit to clock out.

- Start the ready Time Machine Multiball. Use the ball save to advance the song mode and the multiball sequence.

Mode Notes

- Red Barchetta: Score lit jackpots. Use bumpers to shift gears. Each gear ends with a Super Jackpot.

- Subdivisions: Shoot the Time Machine, then the fast-flashing inner jackpots. The lit shots spread outward. Return to the Time Machine for the Super Jackpot.

- Fly by Night: Shoot red jackpots and fast-flashing double jackpots. When the playfield becomes dark, shoot the strobing blue Super Jackpot.

- Time Machine Multiballs start with two balls. Time Machine upgrades can add balls and ball-save time. The feature ends when one ball remains.

- If a matching Album is stored, hold the lit action button during the song mode or multiball.

Mode Notes

- Album: Complete its shown 1-2-3 shot sequence. Collect the Combo Jackpot at the yellow-lit Time Machine.

- Weapon: A stored Album power. During its song mode, it spots lit mode shots. During its multiball, it adds a ball and ball-save time. One use spends the Album.

- A short action-button press changes the ramp diverter. A long press uses the Weapon.

- For the first Far Cry Multiball, complete LIGHT and LOCK. Collect the first lock at the upper scoop, then collect the second at either scoop.

Mode Notes

- Far Cry Multiball: Later attempts become harder. Follow the display, including the right ramp when it is required. The second collected lock starts multiball.

- Shoot the rainbow-colored jackpots. Fifteen jackpots light the Super Jackpot at the Time Machine.

- A Super Jackpot adds five years. A flawless set adds ten years. A matching Snakes & Arrows Weapon adds a ball.

- The feature ends when one ball remains.

- When the Drum Clock reaches midnight, shoot the right orbit during another multiball to add Headlong Flight.

Mode Notes

- Drum Clock: Pop-bumper hits move the clock from 5 p.m. to midnight; progress persists until the first Headlong Flight starts.

- Headlong Flight is the only multiball that can start during another multiball.

### Fallback

La Villa single-ball combo

When

Use this plan when scoop locks or multiball control are unreliable, but the major shots are dialed in.

Steps

- Collect purple records. Shoot the Time Machine to start La Villa Strangiato.

- Start at the right ramp. Follow the 12-shot sequence. Make the next shot before the combo timer ends.

Mode Notes

- La Villa Strangiato: A fixed 12-shot sequence. Each fast successive shot increases the combo multiplier.

- The mode is untimed. Stop and regain control when a feed is not safe.

### Alternatives

- Far Cry first

When

Use this when the right ramp and both scoop feeds are safer than the Time Machine return.

Steps

- Complete LIGHT and LOCK. Collect the first lock at the upper scoop and the second at either scoop.

- Collect the Snakes & Arrows Album before the second lock when its 1-2-3 sequence is controlled.

- Start a song mode. Lock the second ball and start Far Cry.

- Use the Weapon after ball save starts to add a ball.

- Collect 15 jackpots and the Time Machine Super Jackpot.

### Builds Toward

Cygnus X-1 and 2112

Steps

- Start all six named multiballs. The sixth start lights Cygnus X-1 Book 1 at the Time Machine.

- Complete all six song modes. The sixth completion lights Cygnus X-1 Book 2 at the Time Machine.

- Collect 100 years and play both Cygnus modes. Shoot the Time Machine to start 2112.

### Overview

Rush lets a Song continue into one Multiball, but Songs cannot start during Multiball. Collect cyan records for Tom Sawyer or orange for Working Man; leave Time Machine one shot from Multiball, start the Song at red-lit Time Machine, then shoot Time Machine again for Multiball. If its Album is stored, hold the lit action button during the overlap to use its Weapon.

### Simple Overview

Rush lets an untimed Song continue into one Multiball, but a Song cannot start after Multiball begins. Shoot any flashing record to qualify a Song, then shoot the red-lit Time Machine to start it. Shoot the Time Machine ramp three times and once more to start the first Time Machine Multiball.
