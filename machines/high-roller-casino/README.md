## Simple strategy

### Summary Title

The goal

### Summary

Lock three balls at the Slot Machine, advance safe shots through single, double, and triple Jackpots, make the Slot Machine triple to light Super, and add more triples before cashing it.

### Steps

- Test the Slot Machine, lock, middle-ramp, orbit, and roulette feeds before selecting a scoring route.

- Spin the Slot Machine until lock is lit, then collect each of the three locks.

- Start Slot Machine Multiball and take the safest lit major shot for its single jackpot.

- Move through the available major shots for double and triple jackpots rather than repeating a dangerous feed.

- Advance the Slot Machine shot through its Triple Jackpot to light Super Jackpot.

- If ball count remains healthy, add safe Triple Jackpots before following the flashing Super arrow; each one raises its value.

- Between multiballs, complete only the safest casino games while collecting chips toward Break the Bank.

### Alternatives

- Casino Frenzy build

When

Use this when several of the six casino games are already won.

Steps

- Finish the nearest safe casino game.

- Avoid forcing Roulette or another rejecting game solely for completion.

- After all six wins, start Casino Frenzy from a settled feed and use four-ball protection to collect the six game Jackpots.

- ATM and orbit points

When

Use this when the pop-bumper feed and lit orbits are safer than the central devices.

Steps

- Build ATM value through the pop bumpers.

- Collect ATM from the lit orbit.

- Return to Slot Machine qualification when the center feed improves.

### Builds Toward

Casino Frenzy and Break the Bank

Steps

- Win all six casino games.

- Collect chips across controlled game and multiball awards.

- Start Casino Frenzy after the sixth game and complete its lit multiball shots.

- Reach 100 chips and start Break the Bank when lit.

### Cautions

- Issue

Response

Test each mechanism early and switch to Roll'n'Win or ATM scoring if a return becomes dangerous.
