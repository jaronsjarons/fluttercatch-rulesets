## Simple strategy

### Summary Title

The goal

### Summary

Collect five band members, start a useful mode, then play Regular Multiball through two ramp-pair and right-hole cycles before collecting the mini-loop Super Jackpot.

### Steps

- Use the Rose Plunger and right-hole feed to collect band members while testing both ramps and the mini loop.

- Use the gun trigger to hold a mode whose lit shots overlap the ramps and right hole.

- Start the selected mode before collecting the sixth band member or using the five-member G-ramp start.

- Start Regular Multiball, then collect one Jackpot at each ramp.

- Shoot the right hole for 100M, collect both ramp Jackpots again, then return to the right hole for another 100M.

- Shoot the mini loop for the 250M Super Jackpot after the second right-hole award; bumper hits raise it by 1M before collection.

- If multiball drains to one ball before a jackpot, use the available G-ramp or right-hole restart immediately.

- Between starts, complete normal modes toward Riot while preserving a prepared Coma stack.

### Alternatives

- Coma mode stack

When

Use this when Coma and another useful mode are both close before multiball.

Steps

- Lock the desired normal mode with the gun trigger.

- Start Coma with the other mode prepared.

- Bring regular multiball into the overlapping scoring window.

- Ramp-combo control

When

Use this when the right hole eject is dangerous but the ramps feed predictably.

Steps

- Alternate the two ramps for combo and mode progress.

- Backhand the right ramp when that is the safer geometry.

- Return to the right hole only during multiball protection or from a settled feed.

### Simple Overview

In Guns N' Roses, collecting the band members starts Multiball, and a selected mode can continue while it runs. Choose a mode that uses the ramps, start it before collecting the last member, then make both ramp Jackpots and the right-hole award twice before shooting the mini loop for Super Jackpot.

### Overview

Guns N' Roses lets normal modes, Coma, and Regular Multiball overlap, while band-member collects control the start. Prepare a useful mode, begin Multiball with five or six members, then complete two ramp-pair and right-hole cycles before the mini-loop Super. Use Coma only when it strengthens this existing shot pattern.
