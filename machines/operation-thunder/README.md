## Simple strategy

### Summary Title

The goal

### Summary

A served ball starts the current mission automatically. Complete its flashing shot for a promotion; a drain advances without one. Refill timed missions at the spinner. Mission 3 starts two-ball play, upgraded to three balls when both locks are ready.

### Steps

- Launch the ball to start the current mission automatically.

- Use the flipper buttons while the ball circles the Power Plant to steer the rotating target lights toward the ball.

- Shoot the flashing mission objective. A completed mission awards a promotion; a drain moves on without that promotion.

- During a fuel-timed mission, return to the spinner before the gauge empties; zero fuel disables the flippers and ends the ball when that rule is enabled.

- Reach Mission 3 to start two-ball play automatically. Earn both available locks beforehand to upgrade it to three balls.

## Full strategy

### Overview

Operation: Thunder runs through twelve missions in a fixed order. A mission starts automatically with each served ball; completing its flashing objective or draining advances to the next one. Use the flipper buttons while the plunged ball circles the Power Plant to steer it toward lit targets, then attack the flashing mission shot. Mission 3 automatically begins two-ball play and can become three-ball play when both locks were earned first.

### Simple Overview

Each served ball starts the next mission automatically. Shoot the flashing mission objective; completing it earns a promotion, while draining still advances the sequence. On timed missions, shoot the spinner to refill fuel before it reaches zero. Mission 3 starts two-ball play automatically, or three-ball play if both balls were locked first.

### Alternatives

- Exploit the STRAFE spinner

When

Use this from Mission 1 when the Power Plant gives you a strong STRAFE value.

Steps

- Steer the Power Plant so its lit targets raise the STRAFE value on the launch.

- Shoot the spinner repeatedly; each spin scores the built STRAFE value and can outscore the nearby single-shot objectives.

### Builds Toward

Finish the twelve-mission tour

Steps

- Take the fixed missions one served ball at a time and finish as many objectives as possible for promotions.

- Treat the fuel gauge as the priority on timed missions; refuel first, then return to the objective.

- Carry extra balls into the later timed missions so a failed objective does not end the full run.

### Machine Setup

- Confirm the timed-mission difficulty, fuel-out behavior, and extra-ball settings; each changes how forgiving the twelve-mission run will be.

- Test the Power Plant target ring, spinner, both locks, drop targets, ramp, saucers, and fuel display before competitive play.
