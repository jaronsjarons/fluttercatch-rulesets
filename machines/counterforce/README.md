## Full strategy

### Overview

Counterforce is a timed fight against seven descending missile columns. The first playfield switch starts the chase; hit a numbered drop target directly or use its matching yellow lane or standup to knock it down before that column's red light reaches the green multiplier row. A missed column loses only its corresponding multiplier lamp when the cycle resets. Clear all seven targets before the chase passes row three to light the upper-left Collect Bonus hole. Base bonus reaches 29,000 and Bonus X reaches 8x; collecting bonus resets the base value but keeps the multiplier.

### Simple Overview

### Alternatives

- Multiplier preservation

When

Use this when the full bank cannot be completed before the chase reaches the green row.

Steps

- Prioritize the columns whose green multiplier lamps are already lit.

- Let lower-value unfinished columns reset if necessary; completed columns keep their multiplier contribution.

### Builds Toward

29,000 at 8x

Steps

- Use repeated chase cycles to preserve all seven target-linked multiplier lamps plus the outlane contribution.

- Build base bonus to 29,000 while protecting the 8x multiplier.

- Clear a fast cycle to light Collect Bonus and cash the full value without losing Bonus X.

### Machine Setup

- Test all seven memory drop targets and resets, all seven descending chase columns, the yellow spot lanes and standups, the Collect Bonus hole and kickout, both pop bumpers, four flippers, and the bonus display.

- Confirm that each yellow shot knocks down only its matching target, each missed column clears only its own multiplier lamp, partial targets and Bonus X are remembered between balls, and the chase audio accelerates with the light sequence.

### Cautions

- Issue

The bank reset does not necessarily erase every multiplier lamp.

Response

Track each missile column separately: only targets still standing when their chase reaches the green row lose the corresponding progress.
