## Simple strategy

### Summary Title

The goal

### Summary

Select a Gotham Event or Light Lock at the plunge, spell CAVE for each VUK lock, then take both ramp Jackpots, the side-ramp Double, and the Batwing U-turn Super during Multiball.

### Steps

- Use the opening save to test the CAVE drops, VUK, three ramps, U-turn ramp, Batwing feed, and right-orbit saucer eject.

- Select Start Gotham Event or Light Lock at the plunge according to the safer current objective.

- Spell CAVE to light each VUK lock. Before the third lock, choose the normal VUK start or the stronger Batwing-assisted start.

Details

- Normal start: Shoot the lit VUK for three-ball Multiball.

- Four-ball start: Make four ramp shots to light the Batwing. With the third lock lit, load the Batwing at the left ramp and fire into the VUK for four balls and a 75,000,000 base Jackpot. Use this only when the cannon aim is reliable.

- During Multiball, collect one Jackpot at each outer ramp.

- After both outer Jackpots, shoot the side ramp for the Double Jackpot.

- Shoot the left ramp to load the enabled Batwing, then fire its ball through the U-turn ramp for the Super Jackpot.

Details

- Multiball order: Left and right outer ramps, side-ramp Double, left-ramp Batwing load, then Batwing through the U-turn ramp for Super.

### Cautions

- Issue

The Batwing Super Jackpot is a difficult two-part shot.

Response

Cash both outer Jackpots and the side-ramp Double before risking ball count on the Batwing-to-U-turn shot.

Source Url

[Source](https://www.kineticist.com/news/batman-forever-pinball-tutorial)

- Issue

A2.00 uses four-ball Multiball, while later production revisions normally start three balls and can qualify a four-ball start.

Response

Read the installed revision and trough behavior before relying on ball count or base Jackpot value.

Source Url

[Source](https://www.kineticist.com/news/batman-forever-pinball-tutorial)

### Simple Overview

Batman Forever uses C-A-V-E to light each VUK lock and a four-step Jackpot ladder during Multiball. Collect both outer-ramp Jackpots, shoot the side ramp for Double Jackpot, then load the Batwing at the left ramp and fire through the U-turn ramp for Super Jackpot.

### Overview

Batman Forever stops other feature progress while a Gotham Event is running. Finish the Event before returning to C-A-V-E and VUK locks, or prepare the Batwing-assisted four-ball start when its aim is reliable. During Multiball, complete both outer ramps, the side-ramp Double, and the Batwing-to-U-turn Super in order.
