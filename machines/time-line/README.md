## Simple strategy

### Summary Title

The goal

### Summary

Start with the center X, then read the grid instead of clearing every target group. Choose the safest bank or numbered target set that finishes a line; a win raises both the end-of-ball multiplier and the next award, so preserving the ball becomes more valuable after each board.

### Steps

- On the mini-playfield, knock down seven targets before the timed flippers go dead to place the center X.

- Read the backglass grid and choose the safest main-playfield group that advances a possible three-X line.

- Complete the yellow drop bank for square 1, the red drop bank for square 7, or red 1-2-3 for square 9.

- Finish any three-X line before the machine completes three O's; the win raises Bonus X and advances the next Win or Draw award.

## Full strategy

### Overview

Time Line turns each target group into an X on its tic-tac-toe grid. Knock down seven targets on the timed mini-playfield to place the center X; the yellow drop bank places square 1, the red drop bank square 7, and red 1-2-3 square 9. Complete any three-X line before the machine completes three O's. Each win raises Bonus X and the next Win or Draw award, while a loss lowers that ladder.

### Simple Overview

Knock down seven targets on the timed mini-playfield to place the center X. On the main playfield, the yellow drop bank places square 1, the red drop bank square 7, and red 1-2-3 square 9. Choose the group that completes a three-X line before the machine makes three O's; each win raises Bonus X and the next Win or Draw award.

### Alternatives

- Main-playfield recovery

When

Use this when the mini-playfield timer ends before seven targets fall.

Steps

- Inspect which X squares are already lit and which line still has no blocking O.

- Use the yellow bank, red bank, red 1-2-3, side targets, or lower rollovers to place the needed X.

- Stop shooting a completed group and move immediately to the feature for the final square.

### Builds Toward

Higher Win or Draw award

Steps

- Complete a three-X line to win the current board.

- Use the resulting Bonus X increase to grow the end-of-ball payout.

- Win later boards to advance the Win or Draw award toward Extra Ball, 50,000, and Special.

### Machine Setup

- Test both mini-playfield flippers, all five mini drops and their reset, both main drop banks, red 1-2-3, side targets, return and outlane switches, the left kicker, the return gate, the grid lamps, and the separate O response.

- Confirm three- or five-ball play, Extra Ball and Special conversion, playfield-memory difficulty, and whether the mini-playfield timer and seven-hit counter behave consistently.

### Cautions

- Issue

The selected difficulty controls which grid, award, and gate progress carries between balls.

Response

Read the live grid at the start of every ball; do not assume the previous player's or previous ball's state was retained.
