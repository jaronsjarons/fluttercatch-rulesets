## Full strategy

### Summary

Roll through an inlane to light the spinner on that same side, then repeat the lit spinner to reach the upper saucers. Collect the top-left saucer for 2X Bonus and the top-center saucer for 3X.

### Steps

- Roll through either inlane to light the spinner on the same side.

- Shoot the lit spinner for 1,000 per spin and send the ball to the upper playfield.

- Collect the top-left saucer to light 2X Bonus, then collect the top-center saucer to light 3X.

- Keep repeating the lit spinners while the ten pin rollovers build strikes and the held base bonus.

- When the center drop bank is lit, complete it for one strike; when it is unlit, stay on the spinner route.

### Cautions

- Issue

Right-spinner shots that fall short can rebound from the targets.

Response

Repeat only the spinner that clears cleanly to the upper playfield.

### Overview

Each inlane in Memory Lane lights the spinner on the same side. Shoot that spinner to return to the upper playfield, collect the left and center saucers for 2X and 3X Bonus, and use the ten pin rollovers to build strikes and held bonus.
