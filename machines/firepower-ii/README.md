## Simple strategy

### Summary Title

The goal

### Summary

Start two-ball Multiball with the lock saucer and Release target. Use its 2x playfield scoring while feeding A-B-C-D from the right side, then repeat the route until Bonus X reaches 5x.

### Steps

- Shoot the upper-right lock saucer during single-ball play.

- Hit the top-center Release target to start Firepower II Multiball.

Details

- Firepower II Multiball: Lock one ball, then hit Release to start two-ball play with 2x playfield scoring.

- During Multiball, shoot the right-side top feed to reach the A-B-C-D lanes.

- Use the flipper buttons to move the lit lane and complete A-B-C-D.

- Repeat the lock and Release sequence until Bonus X reaches 5x.

- After 5x is ready, repeat the lit spinner or the right-side top feed.

- If Hold Bonus lights, shoot its orbit before the short timer ends.

### Quick Info

- Lock saucer

Summary

The upper-right saucer is lit during single-ball play, and its value advances from 10K to 20K to 50K.

- Firepower II Multiball

Summary

Lock one ball, then hit the top-center Release target to start two-ball play with 2x playfield scoring.

- Release value

Summary

Multiball starts score 50K, 100K, and 150K, then score 200K for each later start.

### Fallback

Alternative route: Fast Multiball repeats

When

Use this when the top-lane feed is too fast or unpredictable.

Steps

- Lock one ball at the upper-right saucer.

- Start Multiball at the Release target.

- Use safe switch play until one ball remains.

- Repeat the two-shot start for the increasing Release value.

### Warning

The Release target can rebound directly between the flippers.

Keep both flippers ready when you start Multiball. Do not assume that the second ball gives immediate protection.

### Alternatives

- Spinner after 5x

When

Use this when the spinner is lit and its return is safer than the top feed.

Steps

- Complete A-B-C-D until Bonus X reaches 5x.

- Confirm that the spinner is lit from FIREPOWER progress.

- Repeat the spinner while its return remains controlled.

- Take a lit Hold Bonus orbit before its short timer ends.

### Builds Toward

200K starts and 495K bonus

Steps

- Start Multiball three times to raise later Release awards to 200K.

- Build the base bonus through top lanes and flashing FIREPOWER targets.

- Complete A-B-C-D until Bonus X reaches 5x.

- Hold the built base bonus when the orbit lights.

### Cautions

- Issue

The Release target can rebound directly between the flippers.

Response

Keep both flippers ready when you start Multiball. Do not assume that the second ball gives immediate protection.

Source Url

[Source](https://rules.silverballmania.com/rules/GRWYk-Mb5OV)

- Issue

A left-orbit shot can return quickly from the right side and drain through the center.

Response

Observe one full orbit return before you repeat it. Use the right-side top feed for lane progress.

Source Url

[Source](https://rules.silverballmania.com/rules/GRWYk-Mb5OV)

- Issue

FIREPOWER standups and balls descending between the bumpers can produce center drains.

Response

Do not shoot the standups without control. Prepare both flippers before the ball leaves the upper area.

### Check Before Play

- Confirm the 1983 Williams Firepower II, not the licensed Taito edition, plus ball count, Extra Ball and Special conversion, and tilt.

- Confirm Bonus X resets each ball, lock and Release values carry, Hold Bonus timing, spinner light, and Multiball 2x playfield scoring.

- Test the lock saucer eject, Release rebound, right-side top feed, left-orbit return, spinner, top lanes, and standups before choosing repeated Multiballs.

### Simple Overview

Firepower II uses the upper-right saucer for one lock and the top-center Release target for two-ball Multiball with 2x playfield scoring. Start Multiball, use the protected play to complete A-B-C-D for Bonus X, and repeat the lock-and-release route as its start award rises.

### Overview

The upper-right saucer locks one ball in Firepower II, and the Release target starts two-ball Multiball with 2x playfield scoring. Completing A-B-C-D raises Bonus X, while a completed FIRE, EPO, or WER group briefly lights Hold Bonus at an orbit. Use the protected play to build both bonus systems.

### Machine Setup

- Confirm the 1983 Williams Firepower II, not the licensed Taito edition, plus ball count, Extra Ball and Special conversion, and tilt.

- Confirm Bonus X resets each ball, lock and Release values carry, Hold Bonus timing, spinner light, and Multiball 2x playfield scoring.

- Test the lock saucer eject, Release rebound, right-side top feed, left-orbit return, spinner, top lanes, and standups before choosing repeated Multiballs.
