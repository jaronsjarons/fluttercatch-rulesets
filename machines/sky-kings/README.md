## Full strategy

### Summary

Plunge the top saucer to light both captive-ball lanes. If the captive-ball rebounds are controlled, repeat either lit lane; otherwise keep sending the ball through the center spinner to the top saucer.

### Steps

- Plunge the top saucer. It lights both captive-ball lanes and the pop bumpers.

- If the plunge misses, hit the mushroom target beside an unlit captive-ball lane to light that side.

- Shoot a lit captive-ball lane for 1,000 to 4,000, depending on how far the captive ball travels.

- Keep repeating the captive-ball shot only while its rebound returns safely. If it does not, shoot through the center spinner and return to the top saucer.

### Alternatives

- Top-saucer loop

When

Use this when either captive-ball rebound is dangerous or a square hit rarely scores 4,000.

Steps

- Shoot through the center spinner to send the ball up top.

- Collect the top saucer for 3,000 and continue through the upper playfield.

### Cautions

- Issue

Captive-ball shots can rebound toward a drain.

Response

Test each side once and keep only the side whose rebound reaches a flipper or return lane.

### Simple Overview

Sky Kings uses the top saucer to light both captive-ball lanes and the pop bumpers. A lit captive-ball lane pays according to how far its ball travels, while the center spinner provides a safer return to the upper saucer.

### Overview

Sky Kings alternates between variable captive-ball scoring and a safer spinner-to-saucer loop. Plunge the top saucer to light both captive-ball lanes, then test a lit captive ball for value and rebound. Repeat it only when the return is controlled; otherwise use the center spinner to collect the saucer and relight upper play.
