## Simple strategy

### Summary Title

The goal

### Summary

Complete the center three-bank and left five-bank to raise Bonus X to 14x. Use the two-button lane change to fill the bonus grid. Start three-ball play only when SKY DIVERS and Walker progress come safely.

### Steps

- Hold both flipper buttons, then release one once per advance to move the selected bonus-grid row.

- Complete the center three-bank whenever its rebound is controlled.

- Complete the left five-bank. When practical, hit 1 through 5 in order for 50,000 and a lit Altitude-lane Special.

- Repeat both banks until Bonus X reaches 14x.

- Continue lane-change work to fill high-value grid spaces. Protect the built bonus instead of forcing a low-value target.

- When SKY DIVERS is complete and two balls are loaded, send the third ball through the Walker to start the three-ball feature.

Details

- Three-ball feature: Light SKY DIVERS, load two balls, then send the third ball through the Walker to release three-ball play.

- Protected use: Use the extra balls to finish bank, grid, and Bonus X progress.

- During three-ball play, continue the safest Bonus X and grid shots. Return to bonus control after one ball remains.

Summary

Summary

### Alternatives

- Direct three-ball feature

When

Use this when SKY DIVERS and Walker shots are safer than the drop banks.

Steps

- Complete the SKY DIVERS runway lights.

- Shoot the lit Walker once to load the first ball, then shoot it again to load the second.

- Shoot the Walker a third time to start three-ball play.

- Use the extra balls to complete grid and bank progress.

### Builds Toward

Maximum bonus card

Steps

- Complete upper switch groups until Bonus X reaches 14x.

- Use lane change to fill the strongest bonus-card rows.

- Complete SKY DIVERS and load all three Walker positions.

- Use three-ball play to extend the 14x grid-scoring ball.

### Cautions

- Issue

Drop-bank rebounds can remove control before the required target sequence is complete.

Response

Use a cradle before each bank shot. Do not hit a lowered target or a target that is out of sequence.

Source Url

[Source](https://www.youtube.com/watch?v=qIdNCeAak8Q)

- Issue

Walker loading adds live balls without a Jackpot or a separate scoring objective.

Response

Start the feature only when the extra balls protect valuable grid or multiplier progress.

### Simple Overview
