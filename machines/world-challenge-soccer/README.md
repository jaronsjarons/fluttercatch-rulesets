## Simple strategy

### Summary Title

The goal

### Summary

Hit the left or center target to raise Goal Value before Multiball. Complete the MULTI and BALL drops to light both locks, then alternate the qualified Goal and ramp Jackpots.

### Steps

- Use the opening ball save to test the center target, left target, goal, and both lock feeds.

- Hit the safer left or center target to raise Goal Value before committing to Multiball.

- Complete the MULTI and BALL drop groups to light the two lock shots.

- Lock both balls, then plunge through the lit top rollover to qualify the opening Multiball jackpots.

- Collect the qualified Goal jackpot, then the qualified ramp jackpot; rebuild the drop banks between later collects.

- Use B-O-O only when opening the goal converts a major value or a match-critical shot.

Details

- B-O-O rule: Holding both flippers opens the goal for one shot and is available once per ball.

### Alternatives

- Position play: Challenge ladder

When

When trailing, use this distinct scoreboard route: use this when Challenge is ready and one controlled goal is safer than the remaining lock work.

Steps

- Start the lit Challenge match.

- Score the required goal before returning to qualification shots.

- Repeat only while Challenge progress and the Goal feed remain favorable.

### Builds Toward

World Championship

Steps

- Win the required Challenge matches across controlled balls.

- Start World Championship and score its required goals.

- Continue into the final Riot phase only while ball control remains stable.
