## Simple strategy

### Summary Title

The goal

### Summary

Shoot whichever spinner is lit for 1,000 per spin. If neither spinner is lit, complete the five left drop targets once to light a spinner and Double Bonus, then return to the lit spinner and protect the doubled end-of-ball bonus.

### Steps

- Shoot the lit spinner

Check the lamps beside the left and right spinners, then shoot whichever spinner is lit for 1,000 points per spin. An unlit spinner scores only 10 per spin.

- Light one when both are dark

If neither spinner is lit, complete the five left drop targets once. The completed bank lights one spinner, lights Double Bonus for this ball, and resets the targets.

- Return and collect

Return to the lit spinner. Hits at the top C and Y lanes, any drop target, the right C-L-E targets, or either inlane can move the lit spinner, so read both lamps before the next spinner shot. Stop forcing shots at 15,000 base bonus and finish the ball without tilting to collect 30,000 with Double Bonus.

## Full strategy

### Summary

On solid-state Evel Knievel, read both spinner lamps, complete the five-drop bank only if neither is lit, return to the lit spinner for 1,000 per spin, and protect the prepared 30,000 bonus collect.

### Steps

- Read both spinner lamps before the plunge.

Mode Notes

- Lit Spinner: Only one spinner can be lit. It scores 1,000 per spin. An unlit spinner scores 10 per spin.

- Factory three-ball play lights one spinner at the start of each ball.

- Five-ball play starts with both spinners unlit. The first drop-bank completion lights one.

- If a spinner is lit, do not force the drop bank.

- Plunge for the top saucer only after its feed is known.

Mode Notes

- SUPER: This five-letter collection uses a moving arrow to select the next letter. The top saucer or center target collects it. Completion spends the configured award and resets the word.

- The saucer scores 3,000 and collects the selected SUPER letter.

- Cradle the first controllable ball. Shoot the lit spinner from the flipper with the safe line.

- Read both spinner lamps after the top C or Y lane, any drop target, a right C-L-E target, either inlane, or a completed drop bank.

Mode Notes

- A 500-point event can alternate the lit spinner. These events include top C and Y, each drop, right C-L-E, and both inlanes.

- Each 500-point event also advances base bonus by 1,000.

- A completed drop bank scores 5,000 and can alternate the lit spinner.

- If both spinners are unlit, complete the five left drop targets once.

Mode Notes

- Double Bonus: The first bank completion lights this per-ball multiplier. It doubles base bonus at the drain, then is spent. It does not carry between balls.

- Each drop scores 500 and adds 1,000 base bonus.

- The full bank scores 5,000, lights a spinner, lights Double Bonus, and resets the bank.

- Return to the lit spinner. Read both lamps again after any top C or Y lane, drop target, right C-L-E target, or inlane.

- After an inlane changes the lit spinner, cradle a slow feed or use one immediate shot on a fast feed.

- Continue controlled lit-spinner shots until base bonus reaches 15,000.

- Stop forcing bonus advances. Drain without tilting to collect 30,000 with Double Bonus.

### Fallback

One bank and protected bonus

When

Use this plan when the lit spinner rejects or returns dangerously.

Steps

- Cradle on the flipper with the safer line to the five left drops.

- Choose one standing target. Shoot one target at a time.

- Each target scores 500 and adds 1,000 base bonus.

- Complete all five once. Collect the 5,000 bank award.

- Confirm that Double Bonus and one spinner are lit.

- Resume the spinner only when its return is controlled.

- Otherwise, use top lanes, inlanes, and incidental drops to reach 15,000 base bonus.

- Protect the prepared 30,000 end-of-ball bonus.

- Do not shoot the right standups only for bonus advances.

### Alternatives

- Second and later drop-bank completions

When

Use this plan when target rebounds are controlled and the configured replay award has value.

Steps

- Complete the five-drop bank a second time.

Mode Notes

- Extra Ball: This replay award serves another ball after the current ball drains. The second bank completion can qualify it, depending on settings.

- Special: This operator-configured replay award can give a credit or Extra Ball. Original electronic code does not offer a point award for Special.

- The recommended three-ball setting awards Extra Ball.

- Other settings award nothing, 5,000, or 5,000 plus Extra Ball.

- Complete the bank a third time or later only when the rebound remains safe.

- The recommended three-ball setting awards Special.

- Other settings award nothing, 5,000, or Extra Ball.

- SUPER route

When

Use this plan when the top saucer is controlled and the configured word award has value.

Steps

- Watch the moving arrow under S-U-P-E-R.

Mode Notes

- SUPER: This five-letter collection uses a moving arrow to select the next letter. The saucer or center target collects it. Completion spends the configured award and resets the word.

- Each 10-point event advances the arrow by one letter.

- Shoot the top saucer or center target. The shot scores 3,000 and lights the selected letter.

- The arrow advances again after the collect.

- Complete all five letters on the same ball.

- The factory three-ball award is one credit.

- Settings can award nothing, one credit, Extra Ball, or two credits.

- Prefer the saucer. The center target is a major rebound risk.

- CYCLE route

When

Use this plan only when standup rebounds are controlled and outlane awards have value.

Steps

- Collect the top C and Y lanes. Then hit the right C, L, and E standups.

Mode Notes

- CYCLE: This five-letter collection uses two top lanes and three right standups. It lights bumper and outlane awards for the current ball, then resets at the drain.

- Complete C-L-E to light the center red bumper for 1,000 per hit.

- Recommended three-ball rules also light one outlane Special.

- Complete all of C-Y-C-L-E to light both outlane Specials continuously for the ball.

- An operator can make full CYCLE light only one alternating outlane.

- A lit outlane can award nothing, Extra Ball, one credit, or one credit plus Extra Ball.

- Ignore this route when replay awards do not score.

### Builds Toward

Lit-spinner points and 30,000 end-of-ball bonus

Steps

- Confirm a lit spinner.

- If needed, complete the five-drop bank once.

- Use the bank to light Double Bonus.

- Shoot the lit spinner for 1,000 per spin.

- Let spinner shots and incidental 500-point features build base bonus.

- Stop forcing advances when base bonus reaches 15,000.

- Drain without tilting to collect 30,000.

- Repeat on the next ball. No rule progress carries between balls.

### Check Before Play

- Read the configured second-bank, later-bank, SUPER, CYCLE, Extra Ball, and Special awards before choosing a replay route.

### Simple Overview

Evel Knievel uses playfield lamps to choose which spinner pays 1,000 per spin. Read both lamps, complete the five-drop bank only when neither spinner is lit, then repeat the lit spinner while building base bonus. Protect the prepared 30,000 Double Bonus collect.

### Overview

In Evel Knievel, lanes, targets, and inlanes move the lit 1,000-per-spin award between the two spinners, while one five-drop completion lights Double Bonus. Read both spinner lamps after every qualifying switch and shoot only the lit side from control. Stop forcing bonus advances at 15,000 base and preserve the 30,000 drain collect.
