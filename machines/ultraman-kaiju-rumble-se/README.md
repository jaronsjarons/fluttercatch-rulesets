## Simple strategy

### Summary Title

The goal

### Summary

Clear the center drop bank, shoot the lit Beta Capsule/right scoop, choose a Kaiju with the flippers, and double-flip to start. Choose the Battle before starting a Multiball; otherwise the game automatically starts the easiest unfinished Battle.

### Steps

- Clear all three center drop targets to light the Beta Capsule/right scoop.

- Shoot the lit scoop, choose an available Kaiju Battle with the flippers, and double-flip to start it.

- Start the Battle before a Multiball when selection matters. A Multiball started first automatically begins the easiest unfinished Battle.

- For Baltan Multiball, shoot each of the three far-left scoops once.

- For Bemular Multiball, shoot the middle-playfield drop and scoop, hit both wheel standups, then repeat the drop and scoop. Multiball starts when the ball leaves the middle playfield.

- Completing Baltan and Bemular qualifies Jirahs. When the upper-playfield diverter opens, shoot the center ramp to start Jirahs.
