## Simple strategy

### Summary Title

The goal

### Summary

Send controlled shots to the two top-corner Triples horseshoes, use a same-flipper return or Dead bounce for the mirror shot, and ignore the narrow vari-targets unless a deep hit is reliable.

### Steps

- Prepare both flippers for the automatic launch from the center of the lower playfield.

- Control the ball, then shoot the more reliable top-corner Triples horseshoe.

- Watch the horseshoe return. Catch it on the same flipper or dead-bounce it to the opposite flipper.

- Use the controlled return for the same horseshoe or its mirror shot.

- Take incidental hits on a lit center bumper or a side Double chute.

- Ignore the numbered runner targets during points play.

- Repeat the Triples route while the top feeds remain controlled.

### Quick Info

- Autoplunger

Summary

The machine launches each ball from between the flippers, so it has no player-controlled skill shot.

- Triples horseshoes

Summary

Each top-corner Triples horseshoe scores 3K on Home Run, while Playball uses one-tenth scoring.

- Lit bumpers

Summary

The bumpers stay lit after activation and can start the game in a lit state.

### Fallback

Alternative route: One-corner Triples loop

When

Use this plan when only one top horseshoe has a predictable feed.

Steps

- Choose the top-corner Triples horseshoe with the safer entry and return.

- Shoot only that horseshoe from a controlled flipper.

- Catch the return or use one dead bounce to regain control.

- Repeat the same horseshoe instead of forcing the mirror shot.

### Warning

A ball that exits a side Double chute at the wrong speed can drain through the center.

Prepare both flippers before the exit. Do not chase a Double chute from an uncontrolled ball.

### Alternatives

- Deep vari-target home run

When

Use this plan only when a forehand or backhand can push a vari-target to its deep value safely.

Steps

- Trap the ball and choose the vari-target with the cleaner angle.

- Make one controlled shot that can reach the home-run value.

- Prepare for a direct target rebound or a side-chute feed.

- Return to the Triples horseshoes if the shot does not reach the deep value safely.

### Builds Toward

Repeatable top Triples scoring

Steps

- Identify the safer top-corner horseshoe.

- Learn whether its return stays on one flipper or crosses safely.

- Use a dead bounce when it produces a controlled mirror shot.

- Repeat the top route and accept incidental bumper or Double-chute value.

### Simple Overview

Playball and Home Run launch each ball automatically and reward repeat shots through the two top-corner Triples horseshoes. Find the safer horseshoe, learn whether it returns to the same flipper or crosses, and repeat that route instead of forcing a narrow vari-target.

### Overview

Playball and Home Run center on two top-corner Triples horseshoes, with bumper, Double-chute, and deep vari-target value around them. Identify the safer horseshoe and use its same-flipper or cross-playfield return to set up the mirror shot. Accept incidental upper scoring, but avoid forcing the Double chutes or vari-targets until their feeds are proven.
