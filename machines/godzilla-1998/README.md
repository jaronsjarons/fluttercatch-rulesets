## Full strategy

### Overview

Sega's Godzilla builds five separate Multiballs, all started at the left inner loop after their own qualification. The quick route is Taxi Multiball: complete the T-A-X-I targets, then shoot the left inner loop. You can qualify several Multiballs before that start shot, or add another qualified one during play for a fresh ball save and larger Jackpots.

### Simple Overview

Complete the T-A-X-I targets to qualify Taxi Multiball, then shoot the left inner loop to start it. Every qualified Multiball starts at that same inner loop, so you can prepare more than one before shooting it.

### Summary

### Alternatives

- Safer repeatable orbit route

When

Use this when the left orbit is more controllable than the T-A-X-I bank.

Steps

- Shoot the left orbit four times to qualify Baby Zilla Multiball.

- Shoot the left inner loop to start it, then return to the left orbit for Jackpots.

### Builds Toward

Reach Save New York

Steps

- Qualify Godzilla with four right-ramp shots, Baby Zilla with four left-orbit shots, Taxi by completing T-A-X-I, Sonar with six captive-ball hits, and Helicopter by building the inlane-to-opposite-target combos through 6X.

- Start each qualified Multiball at the left inner loop; starting several together still records each one as played.

- After all five have been played, shoot the left inner loop to start Save New York. Complete N-E-W Y-O-R-K at the major shots, then return to the left inner loop for the Super Jackpot.

### Machine Setup

- Prefer CPU 2.05 with display 2.0; earlier software can behave differently.

- Check the left inner loop, both orbits, right ramp, T-A-X-I bank, three captive balls, inlanes, and yellow combo targets before competitive play.

### Cautions

- Issue

Starting several Multiballs together raises the Jackpot but spends every prepared start at once.

Response

Stack two or more when control is good; otherwise start the safest one and add another during ball save so the new start restores balls and refreshes protection.
