## Full strategy

### Summary

Use Drive My Car to build a repeatable upper-loop score, collect its stored score before draining, then use All My Loving on ball three for two-ball spinner-and-magnet play.

### Steps

- Choose Drive My Car at the start of ball 1. Use a partial plunge, then shoot the upper-right loop with the upper flipper.

Mode Notes

- Drive My Car: Each completed loop raises the mode level. Each loop scores 25,000 times the current level. The mode runs for 60 seconds.

- Loop skill shot: A partial plunge feeds the upper flipper. The upper-right loop adds a skill-shot award and starts the loop chain.

- Repeat the loop while it is controlled. Reach the highest practical mode level before the timer ends.

- When the mode ends, shoot the standup behind the F-A-B drops to collect the lit Super Jackpot. Collect it before the ball drains.

Mode Notes

- Mode Super Jackpot: A completed mode lights this target for the full score earned in that mode. It becomes unlit at the end of the ball.

- Outside a mode, complete the F-A-B and F-O-U-R drop banks. Then shoot the loop into the upper magnet to start another mode.

Mode Notes

- Later mode start: Complete both named drop banks. The loop feeds the upper magnet. The pop bumpers change the selected lit mode before the start.

- Choose Ticket to Ride when the spinner is safer than the loop. Shoot the spinner until the mode ends, then collect its Super Jackpot.

Mode Notes

- Ticket to Ride: Every 30 spinner spins raises the mode level. Each spin scores 10,000 times the current level. The mode runs for 60 seconds.

- On ball 3, choose All My Loving. Shoot the left spinner to make the required switch hits. Then shoot the upper magnet for the jackpot.

Mode Notes

- All My Loving: This is an untimed two-ball multiball. It is available on ball 3, or after the four single-ball modes. All scoring is 2x.

- The display shows the switch count for the next jackpot. The left spinner can complete the count quickly. The jackpot is available from either direction through the upper loop.

- All My Loving enters the song rotation on ball three, or after the four single-ball songs have been played.

- Repeat the spinner and upper-magnet jackpot. Use a staged flip when one ball is trapped and the other ball reaches the upper flipper.

- Hit both upper-corner Mystery targets. Then backhand the lower-left Mystery target to add a ball.

Mode Notes

- All My Loving Mystery: The two corner targets light Mystery. The first Mystery award during this multiball adds one ball.

### Fallback

Ticket to Ride

When

Use this plan when the upper-right loop does not feed the flippers safely.

Steps

- Choose Ticket to Ride at the start of a ball.

- Shoot the safer spinner. Every 30 spins raises the mode level.

- Stop forcing the spinner if its return becomes uncontrolled. Complete F-A-B and F-O-U-R from trapped balls.

- When Ticket to Ride ends, collect the lit Super Jackpot before a drain.

### Alternatives

- I Should Have Known Better

When

Use this plan when the drop banks are safer than the loop and spinner.

Steps

- Choose I Should Have Known Better. Complete the three drop banks.

Mode Notes

- I Should Have Known Better: Each completed bank raises the mode level. Each drop scores 7,500 times the current level. The mode runs for 60 seconds.

- Use controlled bank shots and safe rebounds. Do not force the last drop from a moving ball.

- Collect the lit Mode Super Jackpot after the mode ends.

- Stacked Super Jackpots

When

Use this plan only when more than one completed mode has left a Super Jackpot uncollected on the same ball.

Steps

- Complete another mode before you hit the Super Jackpot standup.

- Shoot the standup repeatedly. Each uncollected mode adds another stepped Super Jackpot award.

- Do not hold these awards through a dangerous shot. A drain removes all uncollected Mode Super Jackpots.

### Builds Toward

Beatlemania and Taxman

Steps

- Play each of the five selectable song modes until all five reach level 2, or level 3 in Competition Mode. Shoot the upper magnet to start Beatlemania.

- Continue qualifying the five songs and raise every one to level 5. Shoot the upper magnet to start Taxman Multiball.

### Cautions

- Issue

On ball 3, the mode selector may move on its own or when a flipper button is pressed.

Response

Wait until All My Loving is selected, then plunge without practice flips. Confirm the selected mode before the ball enters play.

Source Url

[Source](https://pinballvideos.com/v/5574/7569)

- Issue

The upper loop can return through the center instead of reaching a flipper.

Response

Test the return during ball save. Use Ticket to Ride when the loop return is not repeatable.

Source Url

[Source](https://www.youtube.com/watch?v=U4uHZFGOhm0&t=629s)

- Issue

It Won't Be Long requires pop-bumper hits and gives less control than the other modes.

Response

Do not choose it for the main plan. Choose Drive My Car, Ticket to Ride, or All My Loving.

Source Url

[Source](https://www.youtube.com/watch?v=U4uHZFGOhm0&t=963s)

- Issue

The extra-ball inlane can bounce the ball toward the outlane.

Response

Watch the feed and nudge before the ball reaches the inlane divider. Do not assume the inlane will feed a flipper.

Source Url

[Source](https://www.youtube.com/watch?v=U4uHZFGOhm0&t=724s)

- Issue

A drain removes every uncollected Mode Super Jackpot from that ball.

Response

Collect a large Mode Super Jackpot before you start another risky feature.

### Overview

The Beatles gives each selected song its own scoring feature, and a finished song lights its full score at the standup behind the F-A-B drops. Choose Drive My Car and repeat the upper-right loop, or choose Ticket to Ride when the left spinner is more repeatable. Collect the lit Mode Super Jackpot before the ball drains. On ball three, select All My Loving before plunging for untimed two-ball play, use the left spinner to build its Jackpot, shoot through the upper magnet to collect it, and use the first lit Mystery to add a ball.

### Simple Overview

The Beatles begins each ball with a song choice. Drive My Car scores upper-loop shots for 60 seconds; when it ends, shoot the standup behind the F-A-B drops to collect the Mode Super Jackpot. Ticket to Ride instead builds from spinner spins. On ball three, select All My Loving before plunging; it starts untimed two-ball play, and the upper magnet collects a Jackpot after enough switch hits.

### Machine Setup

- Check Competition Mode and Extra Ball or Special conversion.
