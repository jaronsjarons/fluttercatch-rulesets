## Simple strategy

### Summary Title

The goal

### Summary

Build Lock at the two center holes, then lock one ball on each side to start four-ball Multiball. During it, shoot the center ramp for the first Jackpot, relock both balls for Double Jackpot, then use the two side ramps for Super Jackpots.

### Steps

- Shoot the two center lock holes until the Lock lamps are ready, then put one ball into each lit side lock.

- The second locked ball starts four-ball Multiball; shoot the center ramp for the first Jackpot.

- After the center-ramp Jackpot, relock one ball in each side hole to collect the Double Jackpot.

- Complete the left- and right-ramp Super Jackpots, returning to the center ramp when the sequence relights it.

## Full strategy

### Overview

Viper Night Drivin' uses the left ramp for six events, the lower targets for Post-Save, and the two center lock holes for four-ball Multiball. Work the lock holes until Lock is lit, then lock one ball on each side; the second lock starts Multiball. Light Post-Save before beginning a dangerous feature, because the Launch button can then raise the center post.

### Simple Overview

Shoot the two center lock holes until Lock is lit, then lock one ball on each side; the second lock starts four-ball Multiball. Before starting, complete the lower targets to light Post-Save, which the Launch button activates.

### Summary

### Alternatives

- Notepad event route

When

Use this when the left ramp is safer than the center lock holes.

Steps

- Build the displayed mileage while no other event is running.

- When the left ramp flashes for Notepad, shoot it to start the selected event.

- After an event, build another 20 miles to relight the Notepad route.

### Builds Toward

Mancow's Morning Madhouse

Steps

- Complete the six Notepad events by qualifying each one with mileage and starting it at the flashing left ramp.

- Keep Post-Save ready before an event or Multiball: complete the lower targets, then press Launch only when the save is needed.

- After all Notepad events are complete, follow the flashing left-ramp and display direction into Mancow's Morning Madhouse.

### Machine Setup

- Prefer CPU and display 2.01. ROM inventories also preserve 1.02, so verify the installed version before relying on event values or thresholds.

- Check both center lock holes, all three ramps, lower Post-Save targets, Launch button, center post, inlanes, and both raccoon targets before competitive play.
