The goal

### Summary

Use the right scoop for Barroom Brawl, then the LITE LOCK targets and saucer for two-ball Secret Agent Multiball.

### Steps

- Start Barroom Brawl

Use the yellow buttons to select Barroom Brawl, then shoot the right scoop to start it.

Mode Guide

Barroom Brawl

Reason

Complete it before Secret Agent so Seeing Double doubles the later Jackpots.

Play

Shoot the lit mugs, fill the mug, and complete the chug sequence.

- Start Secret Agent Multiball

Complete both LITE LOCK target groups, then shoot the saucer once to lock a ball. Shoot the saucer again while it is not lit for Lock to start two-ball Secret Agent Multiball.

Repeat either ramp for Jackpots. With Seeing Double active, each Jackpot is doubled and also collects an Agent.

## Full strategy

### Summary

Complete Barroom Brawl for Seeing Double, then start two-ball Secret Agent Multiball and repeat either ramp for doubled Jackpots.

### Quick Info

- Covered build

Summary

This route uses Escape From Earth app v2.1.0.0. Secret Agent Showdown v2.1.1.0 is a different game package.

- Seeing Double

Summary

Complete Barroom Brawl's mugs, fill, and chug sequence. Seeing Double then doubles Secret Agent Jackpots for the rest of the game.

- Secret Agent Multiball

Summary

Complete both LITE LOCK target groups, lock qualified balls in the saucer, then shoot the saucer while it is not lit for Lock. Secret Agent can start with two through eight balls.

- Secret Agent Super Jackpot

Summary

Either ramp scores Jackpots and collects Agents. The 25th Jackpot awards the Super Jackpot and a wizard item.

- Feature exclusivity

Summary

Secret Agent and Lights Out cannot start while a story mode or another multiball is running.

### Steps

- Use the yellow buttons to select Barroom Brawl, then shoot the right scoop to start it.

- Shoot the lit mugs, fill the mug, and complete the chug sequence.

Mode Notes

- Completing Barroom Brawl activates Seeing Double for the rest of the game. Finish the mode before starting Secret Agent Multiball.

- Complete both LITE LOCK target groups, then shoot the saucer once to lock one ball and ready the two-ball start.

- Shoot the saucer while it is not lit for Lock to start two-ball Secret Agent Multiball.

- Repeat either ramp for Secret Agent Jackpots.

Mode Notes

- Because Seeing Double is active, each Jackpot is doubled. Each Jackpot also collects an Agent.

- If the multiball lasts for 25 Jackpots, collect the Super Jackpot and its wizard item.

### Techniques

### Cautions

- Issue

Secret Agent qualification becomes harder after each start.

Response

Response

Finish Barroom Brawl first, then start Secret Agent after the mode ends.
