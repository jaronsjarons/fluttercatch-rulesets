## Simple strategy

### Summary Title

The goal

### Summary

Load four balls into the Power Amp by repeating the main ramp. On the fifth ball, take the 50K skill shot and shoot the right saucer for five-ball Meltdown. Preserve ball count for higher playfield multiplier and repeat the ramp.

### Steps

- Shoot the main ramp repeatedly to load four balls into the Power Amp.

- When the fifth ball is served, plunge for the 50,000 skill shot if it is safely available.

- Shoot the right saucer while four balls are held to start five-ball Meltdown Multiball.

- During Multiball, preserve as many balls as possible and repeat the ramp; the live-ball count sets playfield multiplier.

## Full strategy

### Overview

Shoot the main ramp repeatedly to load balls into the Power Amp. After four balls are held, the machine serves the fifth ball; make its 50,000 skill shot, then shoot the right saucer to start five-ball Meltdown Multiball. During Multiball, each surviving ball raises the playfield multiplier, so preserving all five while looping the ramp is the main scoring route.

### Simple Overview

Repeat the main ramp until four balls are held in the Power Amp. On the fifth served ball, collect the 50K skill shot and shoot the right saucer for five-ball Meltdown Multiball. Keep as many balls alive as possible because the ball count controls playfield multiplier, then keep shooting the ramp.

### Alternatives

- Start promptly in multiplayer

When

Use this when physical locks can be left for the next player.

Steps

- Once four balls are held, prioritize the right saucer instead of leaving the Power Amp loaded.

- If the ramp feed is controllable, continue the full five-ball route rather than abandoning lock progress.

### Builds Toward

Multiply the ramp

Steps

- Separate the balls at Multiball start before committing to repeat ramp shots.

- As balls drain, expect the playfield multiplier to fall; take the safest ramp feed while the multiplier is still high.

### Machine Setup

- Confirm lock sharing, skill-shot value, extra-ball conversion, and live-ball playfield multipliers.

- Test the main ramp and its Power Amp locks, fifth-ball serve, right saucer, all lock releases, top skill-shot lanes, and trough capacity.

### Cautions

- Issue

Physical lock progress can benefit the next player.

Response

In multiplayer, finish the four-ramp load and right-saucer start in the same turn whenever possible.
