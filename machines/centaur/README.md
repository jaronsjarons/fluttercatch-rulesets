## Simple strategy

### Summary Title

The goal

### Summary

Complete O-R-B-S in exact order to start two-ball play, repeat the ordered bank during Multiball to add balls, then complete ordered 1-2-3-4 to light the upper-right Collect Bonus and release a stored ball.

### Steps

- Test both lane-change buttons. Note the outlane posts, tilt, target rebounds, and release feed.

- Complete the O, R, B, and S drop targets in exact order.

Details

- Ordered ORBS: The exact sequence stores a ball and starts two-ball play. An out-of-order completion stores a ball but does not release it at once.

- During Multiball, trap one ball when possible. Repeat ordered ORBS to add another ball.

- Complete the 1, 2, 3, and 4 drop targets in exact order. Use the green reset target if the sequence is spoiled.

Details

- Ordered 1-2-3-4: The targets score 10,000, 20,000, 40,000, and 80,000. They also add 1, 2, 4, and 8 bonus advances.

- Time the lit far upper-right Collect Bonus lane for its 5x lamp. An ordered 1-2-3-4 completion also makes this the direct stored-ball release route.

- During Multiball, pass both left-arc stars before the captive-ball shot. This doubles its current value.

- Knock down the left inline drops while Multiball protects their rebounds. Use the open path as a second stored-ball release route.

### Quick Info

- ORBS

Summary

Complete the four drops in exact order to store a ball and start two-ball play.

- 1-2-3-4

Summary

An ordered completion scores rising values, builds bonus, and lights Collect Bonus.

- Collect Bonus

Summary

The far upper-right target collects bonus and can release a stored ball when lit.

### Fallback

Alternative route: Lane-change release

When

Use this plan when the ordered drop banks are not reliable.

Steps

- Use the left flipper button to change the left pair of bottom lanes.

- Use the right flipper button to change the right pair of bottom lanes.

- Complete all four lanes while a ball is stored. The fourth lane releases two-ball Multiball.

- Without a stored ball, build the top-lane bonus multiplier and complete 1-2-3-4 in any order to light Collect Bonus.

### Warning

Competition machines can remove the factory outlane post rubbers.

Nudge before the ball reaches an outlane. Do not depend on the rubber to return the ball.

### Alternatives

- Controlled 1-2-3-4 position play

When

Use this when ORBS rebounds are unsafe but the right-side bank can be attacked from a cradle.

Steps

- Trap on the flipper that gives the cleanest shot at target 1.

- Shoot 1-2-3-4 in order; use the green reset target immediately after a spoiled sequence.

- Use the ordered completion to light the upper-right Collect Bonus release.

- Wait for the 5x lamp, collect bonus, and use the released ball to begin controlled Multiball.

### Builds Toward

Five-ball play and maximum bonus

Steps

- Repeat ordered ORBS during Multiball to add stored balls, up to five-ball play.

- Score targets and top lanes, with ordered 1-2-3-4 hits adding 1, 2, 4, and 8 bonus advances, until base bonus reaches 79,000.

- Complete the top lanes to raise the bonus multiplier to five times.

- Collect or protect the 395,000 maximum bonus. Base-bonus hold stops at its set thresholds, and the multiplier resets.

### Techniques

- Independent lane change

Instruction

Use the left flipper button for the left lane pair. Use the right flipper button for the right lane pair.

### Cautions

- Issue

The ORBS, 1-2-3-4, and inline drop banks can produce uncontrolled rebounds.

Response

Use Multiball protection for repeated bank work. Stop a single-ball sequence after a dangerous rebound.
