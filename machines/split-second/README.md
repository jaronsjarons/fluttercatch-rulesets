## Full strategy

### Overview

Split Second combines a lit-spinner route with a captive-ball release ladder. Spell S-P-L-I-T S-E-C-O-N-D to raise the spinner, use either center three-bank for Bonus X up to 15x, and release captive balls with drop-bank completions or the lit 50,000 Release All target.

### Simple Overview

Spell SPLIT SECOND to raise the spinner, and complete either center three-bank to raise Bonus X. Drop banks release one captive ball; when Release All is lit, hit the 50,000 target to release the group.

### Alternatives

- Left-orbit captive-ball route

When

Use this when the left orbit and captive-ball feed are safer than direct center-bank rebounds.

Steps

- Send the ball around the left orbit toward the captive-ball area.

- Take incidental captive and letter progress.

- Return to the spinner when its value is built.

### Builds Toward

Lit spinner with 15x bonus

Steps

- Complete SPLIT SECOND to build the spinner and light Release All.

- Complete center three-banks until Bonus X reaches 15x.

- Use the spinner and a controlled captive-ball release for the scoring finish.

### Machine Setup

- Test letter movement from both slings, the spinner value lamps, both center three-banks, captive-ball drop banks, release mechanisms, and 50,000 target.

- Confirm Extra Ball, Bonus Ball, and Special conversion before competitive play.
