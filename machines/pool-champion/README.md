## Full strategy

### Overview

Pool Champion uses the upper B-A-L-L targets and top hole for its Red Special route. Complete B-A-L-L, then shoot the top hole to open the upper gate and score the 8 Ball. Each lit 8 BALL lane entry spots a B-A-L-L letter; completing the word lights Red Special. The three center targets light SHOOT NOW, and completing that sequence advances Orange Special. The side Ball Return lane advances its lamps until a lit pass returns the ball, while upper buttons and targets advance the bonus multiplier.

### Alternatives

- Build Ball Return

When

Use this when the side return lane is safer than the upper target routes.

Steps

- Repeat the Ball Return lane to advance its three lamps.

- Enter the lane while Ball Return is lit to send the ball back to the shooter lane.

### Builds Toward

Finish B-A-L-L

Steps

- Use the target bank and lit 8 BALL lane to fill missing letters.

- Convert the completed word at Red Special before rebuilding the upper route.

### Machine Setup

- Check the Red and Orange Special difficulty settings, right-kickback lane requirement, ball count, and configured awards.

- Test B-A-L-L targets, top hole and gate, 8 BALL lane, three center targets, SHOOT NOW lamps, Ball Return lane, upper buttons, and multiplier lamps.

### Cautions

- Issue

Special and Ball Return thresholds are operator-adjustable.

Response

Use the lane and sequence lamps instead of assuming a fixed number of passes.
