## Simple strategy

### Summary Title

The goal

### Summary

Plunge through the right star into the top saucer. Then shoot the left orbit and spinner from the right flipper. Each saucer visit scores 3,000, adds three bonus steps, and sends the ball through all four feature flags. Control that return and repeat.

### Steps

- Plunge over the right star rollover and into the top saucer when that lane is available.

- Use the saucer eject to roll through the four feature flags.

Details

- Feature flags: The matching standups activate flags 1 through 4. The top stars also activate flags 1 and 4.

- Control the flag-lane exit and move the ball to the right flipper.

- From the right flipper, shoot through the left spinner and return to the top saucer.

- Repeat the saucer route until Flag 4 raises the spinner to 100 and Flag 3 enables Double Bonus.

Details

- Double Bonus: Flag 3 doubles the end-of-ball bonus. Base bonus reaches 19,000.

- Continue the spinner-to-saucer loop and protect the doubled bonus.

### Quick Info

- Feature flags

Summary

After activation, a later roll through each of the four physical flags enables its scoring feature.

- Flag 1

Summary

It raises pop bumpers from 10 to 100.

- Flag 2

Summary

It raises the center target from 500 to 3,000.

### Fallback

Alternative route: Recovery: Controlled top-entry route

When

Recovery pivot: Use this when the spinner is weak or the flag exit does not transfer safely.

Steps

- Shoot any controlled top entry instead of forcing the spinner.

- Prioritize the top saucer over a star rollover.

- Control the flag exit on whichever flipper receives it.

- Repeat only while that return remains predictable.

### Warning

The recessed 5,000 standup can drain on a miss or a direct hit.

Ignore it unless its points can immediately decide the game.

### Alternatives

- Position play: Direct Double Bonus setup

When

When trailing, use this higher-ceiling route: use this when base bonus is near 19,000 and Flag 3 is not active.

Steps

- Hit the lower-left standup that activates Flag 3.

- Return the ball to the top saucer.

- Roll through Flag 3 to enable Double Bonus.

- Protect the doubled end-of-ball bonus.

- Left-flipper spinner backhand

When

Use this only when the left flipper can make the spinner without a dangerous reject.

Steps

- Test one left-flipper backhand through the spinner.

- Use it only when the ball reaches the top cleanly.

- Stop after the first uncontrolled reject.

### Builds Toward

A 38,000 doubled bonus

Steps

- Repeat the spinner-to-top-saucer loop until base bonus reaches 19,000.

- Activate Flag 3 at its matching standup.

- Roll through Flag 3 to enable Double Bonus.

- Drain without tilting to score the 38,000 bonus.

- When enabled, 19,000 also lights the Extra Ball lane and right Special target.

### Simple Overview

Wizard! is a top-saucer and feature-flag scoring loop. Plunge through the right star into the saucer, control its exit through the four flags, then shoot the left spinner from the right flipper to return to the saucer and repeat.

### Overview

Each top-saucer visit in Wizard! sends the ball through all four physical flags. Flag 1 lights the bumpers, Flag 2 raises the center-target value, Flag 3 enables Double Bonus, and Flag 4 raises the spinner. Use the left spinner to return to the saucer and control the flag-lane exit.

### Machine Setup

- Confirm Bally Wizard! replay or add-a-ball instruction card.

- Test outer flags, spinner, saucer, and gate returns.
