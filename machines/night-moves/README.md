## Simple strategy

### Summary Title

The goal

### Summary

Lock a ball in either saucer, light Release with pop-bumper or slingshot hits, then shoot the spinner for two-ball Multiball.

### Steps

- Lock one ball

Shoot either saucer to lock one ball.

- Start Multiball

After the lock, hit pop bumpers or slingshots until Release is lit, then shoot the spinner to release the ball and start two-ball Multiball.

- Relock a ball

During Multiball, keep both balls in play and shoot either saucer to relock one ball.

### Quick Info

- Lock and Release

Summary

Either saucer locks one ball. Pop-bumper and slingshot hits toggle Release; when Release is lit, the spinner releases the held ball for two-ball Multiball.

- R-O-C-K

Summary

Complete the R-O-C-K rollovers to light Extra Ball. Any R-O-C-K or return rollover starts the Display Feature Award sequence.

- CLUB and RIO

Summary

Complete either CLUB or RIO target-bank sequence to advance the NIGHT MOVES bonus toward Special.

## Full strategy

### Quick Info

- Lock and Release

Summary

Either saucer locks one ball. Pop-bumper and slingshot hits toggle Release; when Release is lit, the spinner releases the held ball for two-ball Multiball.

- R-O-C-K

Summary

Complete the R-O-C-K rollovers to light Extra Ball. Any R-O-C-K or return rollover starts the Display Feature Award sequence.

- CLUB and RIO

Summary

Complete either CLUB or RIO target-bank sequence to advance the NIGHT MOVES bonus toward Special.

- Right flipper

Summary

The right flipper rotates the lit Extra Ball and R-O-C-K lamps and freezes the top LITE 2X lamp.

### Steps

- Shoot either saucer to lock one ball.

Mode Notes

- The ball remains in that saucer while the next ball enters play.

- After the lock, hit pop bumpers or slingshots until Release is lit.

Mode Notes

- These switches toggle Release. Read the lamp before shooting the spinner.

- When Release is lit, shoot the spinner to release the locked ball and start two-ball Multiball.

Mode Notes

- The spinner is the Multiball start only while Release is lit.

- During Multiball, keep both balls in play and shoot either saucer to relock one ball.

Mode Notes

- Relocking one ball leaves the other ball live and returns the game to the Release sequence.

- Hit pop bumpers or slingshots until Release is lit again, then shoot the spinner to return to two-ball play. Repeat the relock-and-release loop while both balls remain available.

### Builds Toward

NIGHT MOVES Special

Steps

- Complete either the CLUB target-bank sequence or the RIO target-bank sequence to advance the NIGHT MOVES bonus.

- Repeat those target-bank completions until the NIGHT MOVES bonus sequence is complete and Special lights.

### Check Before Play

- Test both saucers, the Release lamp, spinner, R-O-C-K rollovers, and right-flipper lamp rotation.

### Simple Overview

Night Moves turns one locked ball into a repeatable release loop. Lock at either saucer, use pop-bumper and slingshot hits to light Release, then shoot the spinner for two-ball play. Relock a ball during Multiball and repeat the same Release sequence.

### Overview

Night Moves turns either saucer lock into a repeatable two-ball scoring loop. Pop-bumper and slingshot hits toggle Release; when Release is lit, the spinner releases the locked ball. Relock and repeat while two balls remain, then use single-ball play for R-O-C-K awards and CLUB or RIO completions toward the NIGHT MOVES Special.

### Machine Setup

- Test both saucers, the Release lamp, spinner, R-O-C-K rollovers, and right-flipper lamp rotation.
