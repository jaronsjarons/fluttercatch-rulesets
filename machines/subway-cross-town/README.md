## Simple strategy

### Summary Title

The goal

### Summary

Use the plunge to light a useful bumper, build the red and yellow center values with bumper hits, then shoot the center target only when both values match.

### Steps

- Plunge for a colored top lane. Note which bumper becomes lit.

- Send controlled shots beside the bumpers to return the ball to the upper playfield.

- Use red-bumper hits to advance the red center value.

- Use yellow-bumper hits to advance the yellow center value.

- Compare the two center lights after each bumper sequence. Do not shoot the center target while the values differ.

- When both colors show the same value, shoot the center target. Repeat the upper-play route for the next match.

### Fallback

Alternative route: Upper-play scoring

When

Use this when the center target rebound is unsafe or the two values are far apart.

Steps

- Shoot beside the bumpers instead of at the center target.

- Use the top lanes and lit bumper for steady scoring.

- Watch the two color values as the bumpers advance them.

- Return to the center target only after a useful match appears.

### Warning

Bumper exits can feed the center drain or the slingshots.

Keep both flippers ready. Do not flip the ball back into a bumper from a poor feed.

### Alternatives

- Low-value center collect

When

Use this when the values match and the center target has a predictable rebound.

Steps

- Confirm that the red and yellow values match.

- Shoot the center target from the controlled flipper.

- Return the next safe feed to the upper playfield.

### Builds Toward

300-point center collect

Steps

- Advance both color lights through repeated bumper hits.

- Let a color roll past Special and return to 50 when needed.

- Match the red and yellow lights at 300.

- Shoot the center target before another bumper changes either value.

### Simple Overview

Subway and Cross Town use red- and yellow-bumper hits to move two center values. Plunge a colored top lane to light its bumper, build both colors until their displayed values match, then shoot the center target for the combined award.

### Overview

In Subway and Cross Town, each colored top lane lights the matching bumper. Red-bumper hits raise the red value below the center target, and yellow-bumper hits raise the yellow value. Shoot the center target only when the two displayed values match because an unmatched pair pays just 10 points.
