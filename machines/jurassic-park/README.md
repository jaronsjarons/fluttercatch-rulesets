## Full strategy

### Summary

Prepare Raptor Tri-Ball, capture the first dinosaur on an outside route, then choose System Boot when its exact combos are controlled and use Raptor to protect the route.

### Steps

- Try the skill-shot chain: left ramp, right ramp, tower ramp, then O. Use each return to measure the copy.

- Complete the Raptor Pen bank twice. Shoot the center dead-end lane and reduce fence integrity to zero, but stop before the final dead-end start.

Mode Notes

- Raptor preparation: Bank completions qualify the center capture. The first dead-end shot captures a ball; fence hits then lower integrity to zero. The next dead-end shot starts Raptor Tri-Ball.

- Shoot one white MAP arrow. Shoot the left ramp to start the first Paddock, then capture its dinosaur.

Mode Notes

- Paddock: Shoot one red Rescue and one yellow Set Trap target. The first Paddock does not require the Helipad.

- Shoot the moving yellow-green dinosaur arrow to capture the dinosaur and end the Paddock.

- A capture gives a permanent Paddock Perk. The first capture lights Control Room.

- Keep the truck on an outside route. This reaches Visitor Center through fewer difficult Paddocks.

- Shoot C. Select System Boot at Control Room when its exact two-shot combos are controlled.

Mode Notes

- System Boot: Complete one two-shot combo from each opener: left ramp, Helipad, and spinner. Return to C for the combined collect and Fossil.

- Current tournament guidance ranks System Boot above Restore Power when the exact combos are reliable.

- Complete all three purple targets so Supply Drop is ready. Leave the far-right 2x target available.

Mode Notes

- Supply Drop: The large target gives an award after the three purple targets are complete.

- Each collected Supply Drop lights the far-right target for 45 seconds of 2x playfield scoring.

- The first Supply Drop collected during Raptor Tri-Ball adds a ball.

- Shoot the final center dead-end lane to start Raptor Tri-Ball. Collect the first Supply Drop for add-a-ball, then start 2x only when the far-right target angle is safe.

Mode Notes

- Raptor Tri-Ball phase 1: Shoot both ramps. The second ramp jackpot is double.

- Phase 2: Shoot all five C-H-A-O-S jackpots.

- Phase 3: The game adds three balls. Shoot the right ramp for 2x and the upper loop for 3x, multiplied by balls in play.

- Phase 4: Shoot C-H-A-O-S victory laps. The dead-end lane relights them. The feature ends when one ball remains.

- Finish System Boot's three exact combos and return to C. Score both Raptor ramp jackpots, complete C-H-A-O-S, and prioritize the upper loop during the six-ball phase.

Summary

### Fallback

Feed T-Rex Multiball

When

Use this plan when C, the Raptor Pen, or the far-right 2x target rejects.

Steps

- Hit the truck three times on default settings to spell T-REX and start the hurry-up.

- Shoot orange arrows. Each shot resets the timer to 20 seconds and raises the value.

- Shoot the left ramp when the value is adequate. Do not overbuild without ball save.

- During two-ball T-Rex Multiball, shoot all five C-H-A-O-S jackpots. Then shoot the left ramp for the Super Jackpot.

Mode Notes

- The collected hurry-up becomes the jackpot base.

- A left-to-right jackpot sequence adds 1x to the next jackpot and 250,000 to its value.

- The Super equals the jackpot sum. A Super relights jackpots and resets the multiplier.

### Alternatives

- Restore Power and Raptor stack

When

Use this lower-precision route when System Boot's exact two-shot combos are unreliable.

Steps

- Start Restore Power at Control Room after the first dinosaur capture.

- Shoot the spinner, then start Raptor Tri-Ball. Restore Power continues during the Multiball.

Mode Notes

- A Control Room mode can run with one Multiball. A second Multiball cannot start during the overlap.

- Use the extra balls to complete Restore Power's seven broadly lit major shots.

- Make the final lit shot for the Fossil, then resume the Raptor jackpot sequence.

- 2x Chaos comeback

When

Use this high-ceiling line when 2x, Chaos Multiball, an active Paddock, and a T-Rex Event are already aligned.

Steps

- Start 2x before the protected scoring window.

- Start Chaos Multiball while the Paddock and single-ball T-Rex Event are active. The T-Rex Event continues during the Multiball.

Mode Notes

- A single-ball T-Rex Event can run with one Multiball. Multiball T-Rex Events cannot stack with another Multiball.

- Use a Smart Missile for Clear Paddock when that removes the least controllable requirement.

- Prioritize overlapping lit shots while the 2x timer and extra balls remain active.

- Amber Bonus

When

Use this line on a pop-heavy copy when the precision shots are not reliable.

Steps

- Use bumpers to build the Amber base for the game.

- Use the top rollover to light the amber-mine target.

- Capture dinosaurs to add multipliers to the next Amber collect.

- Shoot the amber target to collect the base with stored multipliers.

- The base does not reset. End-of-ball bonus spends the current multiplier.

### Builds Toward

Visitor Center and mini-wizards

Steps

- Complete the outside-route Paddocks to reach Visitor Center.

- Play all three Control Room modes to qualify Secure Control Room, and all four T-Rex Events to qualify Museum Mayhem.

- Complete modes and Raptor Super Jackpots to earn Fossils. Follow the installed display for the next lit mini-wizard start because the start shot can change with the goal.

- Test Raptor Pen, dead-end lane, truck, C, spinner, Helipad, Supply Drop, far-right 2x target, ramps, and upper-loop returns.

### Overview

Jurassic Park uses first Paddock capture to light Control Room before Raptor Tri-Ball. Complete the Raptor Pen twice, capture at the dead-end lane, lower fence to zero, then leave final start ready. Shoot one white MAP arrow and the left ramp, capture an outside-route dinosaur, then shoot C for System Boot; start Raptor, collect Supply Drop for add-a-ball, then hit far-right target for 2x.
