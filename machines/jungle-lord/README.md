## Simple strategy

### Summary Title

The goal

### Summary

Keep the ball on the upper playfield, complete the progressive five-bank, use Double Trouble for growing awards, then start Multiball after L-O-R-D is complete.

### Steps

- Use the upper flippers to keep the ball on the upper playfield.

- Complete the lit pattern on the upper five-bank; read the pattern before each shot.

- After Double Trouble starts, shoot the timed lit target while the angle remains safe.

- Collect numbers 1 through 5 for Double Scoring; numbers 4 and 5 come from the return lanes.

- Complete L-O-R-D in the upper-left pachinko area, then shoot either saucer to start Multiball.

- During Multiball, use the upper playfield and available saucer extension while 2x scoring is active when possible.

- Collect side drop targets only from a controlled angle. Save the stored Magna-Save time for a real outlane threat and press the matching button before the ball reaches the outlane mouth.

### Quick Info

- Upper five-bank

Summary

Its required pattern grows from one target to all five, then changes to Double Trouble.

- Double Trouble

Summary

Timed random targets score 10,000 through 160,000, and partial progress is retained.

- Double Scoring

Summary

Completing numbers 1 through 5 starts 2x scoring for the rest of the ball.

### Fallback

Alternative route: Upper-bank survival

When

Use this when the L-O-R-D feed or saucer shot is unsafe.

Steps

- Keep the ball away from the lower standups.

- Continue the progressive upper five-bank.

- Take only safe Double Trouble targets.

- Build base bonus through upper-bank completions and natural return lanes.

### Warning

Fast exits from the upper playfield can drain, especially from the left ramp.

Track the ramp exit early and prepare the lower flippers before the ball leaves the upper level.

### Alternatives

- Bonus and horseshoe route

When

Use this when a return lane gives a controlled horseshoe shot.

Steps

- Collect either return lane to light the horseshoe briefly.

- Shoot the horseshoe before its timer ends to advance Bonus X.

- Repeat through 10x only while each return remains controlled.

- At 10x, use the next lit horseshoe to light the outlane save when enabled.

### Builds Toward

Double Scoring, 10x bonus, and Multiball

Steps

- Complete numbers 1 through 5 for Double Scoring.

- Use lit horseshoe shots to reach 10x bonus.

- Score return lanes, completed upper or lower drop banks, and the four L-O-R-D lanes until base bonus reaches 30,000.

- Complete L-O-R-D and start Multiball.

- Use the protected play to finish the strongest active scoring features.

### Simple Overview

Jungle Lord grows its upper five-bank pattern into Double Trouble, while numbered targets supply permanent Double Scoring and L-O-R-D prepares Multiball. Stay upstairs, finish 1-through-5, work the progressive bank, then start Multiball after L-O-R-D is complete.

### Overview

Jungle Lord grows its upper five-bank pattern into Double Trouble, while numbered targets supply permanent Double Scoring and L-O-R-D prepares Multiball. Keep the ball upstairs, complete 1-through-5 and safe horseshoe shots, then finish L-O-R-D before using either saucer. Use Multiball to protect the strongest Double Trouble, 10x bonus, and 30,000 base-bonus work.
