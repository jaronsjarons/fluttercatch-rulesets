## Simple strategy

### Summary Title

The goal

### Summary

Complete A-B-C twice for 3x Bonus, use the lit spinner before Base Bonus reaches 20,000, then complete D-E pairs to light and collect a 50,000 Snake Pit.

### Steps

- Use a controlled plunge toward B. Read the unlit A-B-C lanes because the game has no lane change.

- Complete A-B-C once for 2x and again for 3x Bonus X.

Details

- Bonus X: A-B-C completions advance the end-of-ball multiplier to 3x; a drain spends and resets it.

- Build Base Bonus to 10,000. Rip the spinner before Base Bonus reaches 20,000.

Details

- Lit Spinner Window: The spinner scores 1,000 per spin from 10,000 through 19,000 Base Bonus, then stays unlit for the rest of the ball.

- Shatz pass through D and E only while the inlane geometry is safe. Each completed pair spots one 1-2-3-4 number.

Details

- D-E Pair: Collect both inlane letters to spend the pair and spot one number under the configured random or sequential setting.

- Complete all four numbers to set Snake Pit to 50,000 and advance Star Progress.

Details

- 1-2-3-4 Set: Completing all four lit numbers spends the set, sets Snake Pit to 50,000, and advances the star and target-Special track.

- Shoot Snake Pit for 50,000. Values of 20,000 or more reset the ladder after collection.

Details

- Snake Pit: GOR completions raise the award; the number set makes it 50,000. Collects at 10,000 or less remain repeatable, while larger collects reset it.

- Rebuild D-E and 1-2-3-4. Stop alley passing if the ball crosses toward an outlane.

- Use GOR completions as the fallback Snake Pit build when the inlane pass is unsafe.

- Protect up to 29,000 Base Bonus at 3x for an 87,000 drain collect.

### Quick Info

- Bonus X

Summary

Two A-B-C completions raise end-of-ball bonus to its 3x maximum.

- Lit Spinner Window

Summary

The spinner scores 1,000 per spin while Base Bonus is between 10,000 and 19,000.

- D-E Pair

Summary

Collecting both inlane letters spots one number in the 1-2-3-4 set.

### Fallback

Alternative route: GOR and repeatable Pit values

When

Use this when D-E alley passes threaten the outlanes.

Steps

- Stop cross-alley passes.

- Shoot GOR from the right flipper.

- Complete the bank to raise Snake Pit one step.

- Collect 5,000 or 10,000 only when the magnet release is safe.

- Continue GOR toward a larger Pit value and use the lit spinner before 20,000 Base Bonus.

### Warning

A hard D-E pass can continue through the inlane into the outlane.

Reduce flip power and stop when the ball reaches the top of the inlane.

### Alternatives

- Repeatable 15,000 eject

When

Use this only after the left-saucer kickout is proven safe.

Steps

- Complete GOR and GAR pairs until the Eject Ladder reaches 15,000.

- Do not advance to Extra Ball unless that award is useful.

- Shoot the eject saucer for 15,000.

- Trap the kickout and repeat while the ladder remains at 15,000.

- GAR targets

When

Use this when the GAR bank has safe rebounds.

Steps

- Complete GAR and read the newly lit feature.

- Build bumper values under the installed Function 31 rule.

- Use the 5,000 GAR targets when lit.

- Ignore the outlane Special when it has no tournament value.

### Builds Toward

3x and a 50,000 Snake Pit

Steps

- Complete A-B-C twice for 3x Bonus X.

- Use the lit-spinner window for points and top-lane returns.

- Complete D-E pairs to spot 1-2-3-4.

- Complete the number set and collect a 50,000 Snake Pit.

- Repeat the number set to advance Star Progress.

- Protect up to 87,000 end-of-ball bonus.

### Overview
