### Summary

Complete the left Lock targets and lock one ball at the top-right hole. Plunge the next ball into that hole for three-ball Multiball; a miss starts two-ball play. Start Gunfight at the flashing top-left hole and finish all five Scenes for Select-a-Feature.

### Steps

- Complete the left Lock target sequence to light Lock at the top-right hole.

- Shoot the top-right hole to capture the first ball.

- On the next plunge, send the served ball into the top-right hole to lock it and start three-ball Multiball.

- If the plunge misses the hole, continue with the two-ball Multiball that starts instead.

## Full strategy

### Overview

Complete the left Lock target sequence, then shoot the top-right hole to capture the first ball. On the next plunge, send the served ball into that same top-right hole to lock it and start three-ball Multiball; if the plunge misses, two-ball Multiball begins instead. The five movie Scenes build toward Select-a-Feature at the same hole.

### Alternatives

- Start Gunfight

When

Use this when the top-left hole is flashing for Gunfight.

Steps

- Shoot the top-left hole to start Gunfight.

- Wait for DRAW, then press the right flipper button to fire.

- Complete the five Scenes

When

Use these routes to reach Select-a-Feature.

Steps

- For Stair Scene, light SPIN, shoot the spinner, then use the top-right hole to transfer each lit card; collect all five cards.

- For Jackpot Scene, clear the center drop bank, then advance the exposed center target to Collect Jackpot.

- For Stunt Scene, clear the right drop bank, hit the top-left target, then finish the flashing targets.

- After all five Scenes, shoot the top-right hole; cycle with the right flipper and select with the left.

### Builds Toward

Finish the movie

Steps

- Use the Scene inserts to see which movie sequences remain.

- Prioritize the physical task for an unfinished Scene rather than repeating a completed one.

- Once all five are complete, return to the top-right hole for Select-a-Feature.

### Machine Setup

- Confirm Multiball, Extra Ball, Special, and timed-feature settings before competitive play.

- Test the left Lock targets, top-right capture hole, shooter-lane feed, top-left Gunfight hole, both drop banks, spinner, card inserts, and flipper-button selections.

### Cautions

- Issue

The second plunge determines whether Multiball begins with three balls or two.

Response

Aim for the top-right hole on the plunge; if it misses, switch immediately to controlled two-ball play.
