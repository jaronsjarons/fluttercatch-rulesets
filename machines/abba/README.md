## Simple strategy

### Summary Title

The goal

### Summary

Choose a song, knock down a note target, and shoot the song scoop to start it. Right inlane then left orbit collects an instrument; left inlane then right orbit collects an outfit. Spell TOUR at the inlanes, then shoot the hotel target to start a Tour task.

### Steps

- Choose a song before the first plunge. At the start of a later ball, change the selection if a different song is better for your progress.

- Knock down at least one note target to light the song scoop, then shoot the scoop to start the selected song.

- For an instrument, roll through the right inlane and then shoot the left orbit. For an outfit, roll through the left inlane and then shoot the right orbit.

- Complete the blue shots for all four band members, then shoot the left ramp to the magnet to start their challenge.

- Spell TOUR through the inlanes, then shoot the hotel target to start a Tour task. Complete the shown task and return to the hotel target to finish it.
