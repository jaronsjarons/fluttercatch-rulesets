## Simple strategy

### Summary Title

The goal

### Summary

Prioritize the repeatable right orbit for a rest-of-ball doubler. For Multiball, complete 1-2-3 and lock upper-left, then repeat 1-2-3 and lock far-left.

### Steps

- Repeat the right orbit through its 20,000-to-60,000 ladder; the next completion starts double playfield scoring for the rest of the ball.

- Complete the top 1-2-3 lanes to light the upper-left lock, then shoot that saucer to capture the first ball.

- Complete 1-2-3 again to light the far-left lock.

- Shoot the far-left lock to capture the second ball and release all three balls for Multiball.

## Full strategy

### Overview

Repeat the right orbit as it rises through 20,000, 30,000, 40,000, 50,000, and 60,000; the next completion starts double playfield scoring for the rest of the ball. Complete the top 1-2-3 lanes to light the upper-left lock, lock one ball there, then complete 1-2-3 again to light the far-left lock. Shoot the far-left lock to capture the second ball and start three-ball Multiball.

### Simple Overview

### Alternatives

- Build Bonus X

When

Use this when a return-lane feed is controlled.

Steps

- Roll through a lit return lane to advance Bonus X toward 5x, then return to the right-orbit doubler route.

### Builds Toward

Combine Multiball with the rest-of-ball doubler

Steps

- Finish the right-orbit ladder before taking the second lock when the orbit is safe.

- Start three-ball Multiball only after double playfield scoring is running.

### Machine Setup

- Confirm ball count, lock memory, Extra Ball and Special conversions, Cosmic Ball settings, and Bonus X maximum.

- Test the right orbit and value lamps, top 1-2-3 lanes and lane change, both left locks and releases, X-Y lanes, drop banks, and all three balls.

### Cautions

- Issue

The right-orbit value is held, but the playfield doubler lasts only for the current ball.

Response

Finish the ladder early enough to use the doubler on locks and Multiball.
