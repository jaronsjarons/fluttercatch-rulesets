## Simple strategy

### Summary Title

The goal

### Summary

Keep the ball up top until bonus reaches 15,000, open the lower gate, complete A-B-C-D for Double Bonus, then protect the completed state.

### Steps

- Plunge across as many white bonus buttons as possible. Include the orange gate rollover when the lane is available.

- Return the ball to the upper playfield until base bonus reaches 15,000.

Details

- Base bonus: Top buttons and both return lanes add bonus. The maximum base value is 15,000.

- Make another top shot when the lower gate is not open. Do not attack A-B-C-D without an available escape path.

- Complete A-B-C-D to activate Double Bonus.

Details

- A and B: A side-rubber bank shot or a center-bumper rebound can collect these upper targets.

- C and D: Shoot these lower targets directly only from a controlled flipper.

- After Double Bonus and 15,000 base bonus are ready, return to the upper route. Protect the earned 30,000 end-of-ball bonus.

- Ignore the spinner unless a harmless feed enters it. Do not trade the protected bonus for low spinner value.

### Quick Info

- Base bonus

Summary

Top micro-switches and both return lanes advance base bonus to its 15,000 maximum.

- Double Bonus

Summary

Complete the four A-B-C-D drop targets to double the end-of-ball bonus.

- Lower gate

Summary

The orange top rollover opens the lower gate and gives the ball another path away from the drain.

### Fallback

Alternative route: Protect the 15,000 base bonus

When

Use this when the A-B-C-D targets or lower gate are unsafe.

Steps

- Keep the ball in the top and use return lanes to raise base bonus.

- Stop target attacks after base bonus reaches 15,000.

- Continue upper-playfield points and avoid the spinner.

- Take the single end-of-ball bonus instead of risking the ball for Double Bonus.

### Warning

The center bumper, drop targets, and spinner can send the ball toward a slingshot, outlane, or center drain.

Use top switches to raise base bonus first. Attack only the remaining A-B-C-D targets after the orange top rollover opens the lower gate.

### Alternatives

- Rubber bank for A-B

When

Use this when A and B remain and the direct upper-target path is not available.

Steps

- Aim a controlled shot at the side rubber beside A and B.

- Use the bank angle to collect one or both targets.

- Stop this route if the rebound reaches a slingshot or outlane.

### Builds Toward

30,000 protected bonus

Steps

- Use top switches and return lanes to raise base bonus to 15,000.

- Roll over the orange top switch to open the lower gate before the drop-target phase.

- Complete A-B-C-D to activate Double Bonus.

- Protect the completed state through the end of the ball.

Star Pool uses top switches and return lanes to build 15,000 base bonus, then A-B-C-D doubles it. Stay upstairs first, roll over the orange top switch to open the lower gate, complete the four drops, and protect the finished 30,000 bonus.

### Overview

Star Pool uses top switches and return lanes to build 15,000 base bonus, then A-B-C-D doubles it. Finish the base upstairs, open the gate, then use the side-rubber bank shot for A-B and attack only the remaining drops directly. Preserve the completed 30,000 collect rather than returning to the low-value, dangerous spinner.
