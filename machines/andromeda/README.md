## Simple strategy

### Summary Title

The goal

### Summary

Hit the black drop target, lock at the orbit saucer, then start two-ball 2x play at the guarded yellow standup. Focus on the spinner; finish a red bank only when one or two targets remain.

### Steps

- Hit the black drop target to light lock.

- Shoot the orbit saucer to lock one ball. A later player can steal an unclaimed lock, so convert it on the same ball when possible.

- Hit the guarded yellow standup to start Andromeda Multiball and 2x scoring.

Details

- Andromeda Multiball: The black target lights the orbit lock. After the lock, the guarded yellow target releases the held ball for two-ball play.

- 2x scoring: Normal playfield scoring is doubled while both balls remain in play.

- During two-ball play, focus on the spinner. Finish the red bank only when one or two targets remain; the first two completions raise the spinner to 3K and 4K.

Details

- Read the current spinner value and Bonus X before deciding whether to finish a red bank or top-lane set.

- Let spinner and upper-playfield returns complete top-lane sets and advance Bonus X toward 10x.

- After multiball, rebuild the black-target lock route before another player can benefit from a staged ball.

### Fallback

Spinner and top bonus

When

Use this when the lock saucer or guarded start target is unsafe.

Steps

- Finish the red drop bank only when one or two targets remain and their rebounds are controlled.

- Repeat the spinner from a controlled flipper.

- Use top-lane feeds to raise Bonus X toward 10x.

- Return to the lock route only after the orbit and yellow-target returns are known.

### Alternatives

- Fast 2x conversion

When

Use this when a lock is already staged and the yellow target is safe.

Steps

- Do not delay the lock for full spinner or bonus preparation.

- Hit the guarded yellow standup to start two-ball 2x play.

- Use the protection to finish red banks and top lanes.

### Builds Toward

4K spinner and 10x Bonus

Steps

- Complete successive red drop banks until the spinner reaches 4K.

- Complete top-lane groups until Bonus X reaches 10x.

- Start two-ball 2x scoring to protect the dangerous progress shots.

- Carry the multiplied bonus to the end of the ball.

### Techniques

- Orbit-to-lock setup

Instruction

Trap before the orbit shot. Use the full orbit only when it reaches the saucer cleanly and does not reject from its entrance.

### Cautions

- Issue

The multiball start is a guarded standup and can rebound toward the center.

Response

Shoot it from a cradle. Keep the opposite flipper ready for the rebound.

Source Url

[Source](https://rules.silverballmania.com/rules/GrXOZ-MLyb0)

- Issue

A missed orbit-saucer shot can hit the lane divider and return unpredictably.

Response

Test the orbit before committing to repeated locks. Use spinner and bonus play when it rejects.

Source Url

[Source](https://rules.silverballmania.com/rules/GrXOZ-MLyb0)

- Issue

A locked ball can remain available for the next player.

Response

After locking, start two-ball play on the same ball when the guarded target is controllable.

### Overview

Andromeda uses the black drop target to light one orbit-saucer lock, then the guarded yellow standup starts two-ball 2x scoring. Use the first red-bank completion to raise the spinner to 3K and the second to 4K, but favor the spinner itself once built. Complete top-lane sets for Bonus X without forcing broad bank rebounds.
