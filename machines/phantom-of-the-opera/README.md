## Simple strategy

### Summary Title

The goal

### Summary

Test the Catwalk ramp and spell P-H-A-N-T-O-M. Repeat the lit ramp for Unlimited Millions. On the configured last ball, make two consecutive ramps for Double Score. Use Organ Multiball when the two-stage relock is reliable.

### Steps

- Test the left ramp and its return on the first controlled ball. Stop the route after one center-feed reject.

- Shoot lit P-H-A-N-T-O-M letters and use safe ramp repeats to complete the word.

- Complete P-H-A-N-T-O-M, then repeat the lit Catwalk ramp for Unlimited Millions.

Details

- Unlimited Millions: Each lit Catwalk shot scores 1,000,000.

- On the configured final ball, shoot the left ramp once to start the Double Score hurry-up and again before it expires.

Details

- Double Score: The second quick ramp starts full-playfield 2x scoring for its displayed timer.

- If the Organ lock path is safe, open the Organ with the skill shot or three Organ targets and lock the first ball.

- Plunge the served ball. A non-top switch releases the lock and starts Two-Ball Play.

Details

- Two-Ball Play: Put both balls into the Organ within about ten seconds to prepare Three-Ball Play.

- Relock both balls in the Organ. Plunge the served ball and make a non-top switch to release them into Three-Ball Play.

- Hit an Organ target to open the collect for about five to seven seconds. Shoot inside the Organ for Jackpot.

Details

- Organ Multiball: The progressive Jackpot starts at 100,000, can reach 2,000,000, and can be collected once per multiball.

- If one ball is already controlled during Organ Multiball, use the other for controlled Magic Mirror hits to advance Bonus X, then return to the Organ Jackpot sequence.

- Use the short grace period after one ball remains for a lit Organ Jackpot, then resume the ramp route.

### Alternatives

- Position play: Raise Jackpot

When

When trailing, use this higher-ceiling route: use this before Organ Multiball when top-lane feeds are safe.

Steps

- Complete the top lanes to start the 20-second Raise Jackpot timer.

- Score switches for 1,000 per switch.

- Repeat the lanes to reset the timer and raise the switch value through 5,000.

- Start Organ Multiball and collect the built progressive Jackpot.

### Builds Toward

- Complete P-H-A-N-T-O-M and repeat Unlimited Millions.

- Use Double Score on the configured final ball.

- Phantom of the Opera has no separate mini-wizard or wizard mode.

### Simple Overview

In Phantom of the Opera, spelling P-H-A-N-T-O-M lights the Catwalk ramp for repeatable Unlimited Millions. Use the Organ route only when its lock, relock, and return are controlled.

### Overview

In Phantom of the Opera, complete P-H-A-N-T-O-M and repeat the lit Catwalk ramp for Unlimited Millions, then use Double Score on the configured final ball when that ramp remains reliable. For Organ Multiball, open and lock at the Organ, release into two-ball play, relock both balls, then reopen the Organ and shoot inside for Jackpot.
