The goal

### Summary

Short-plunge the far-right Advance Spinner lane, complete drop banks only when they show a missing grid number, use each completed color to raise Bonus X and release held balls for Catacomb Multiball, then use the 1,500 spinner when the grid route becomes unsafe.

### Steps

- Before plunging, check both hidden side lock saucers for captive balls.

- Short plunge the far-right top lane.

Details

- Advance Spinner: Each collect raises the spinner from 100 to 500, then 1,000, then 1,500 per spin.

- Read the rotating colored number at the A, B, C, and D drop banks. Choose a bank whose number is missing from the 16-number grid.

- Complete that three-target bank.

Details

- Grid award: The last target spots the number lit at that bank. A duplicate number gives no additional grid progress.

- Use a top-left stop lane when a useful red or yellow number is available.

Details

- Far-left stop lane: It can spot \#6 and hold all banks on red numbers.

- Near-left stop lane: It can spot \#1 and hold all banks on yellow numbers.

- Complete all four numbers of one color.

Details

- Bonus X: Each completed color raises the multiplier one step, to 5x.

- Catacomb Multiball: A completed color releases every ball in the hidden lock saucers. There are no jackpots or playfield multipliers. The multiball ends when one ball remains.

- During Catacomb Multiball, continue useful banks and spinner shots. If another ball enters a lock, complete a different color to release it and add a ball again.

- When the spinner is 1,500 and few useful grid numbers remain, shoot the spinner instead of forcing a poor bank.

- Protect the carried base bonus and Bonus X. A tilt loses the current bonus collect.

- After the drain, finish the Backbox Bonus Game before the next player starts.

Details

- Backbox Bonus Game: The left flipper selects a bank color. The right flipper launches the backbox ball toward A, B, C, or D. A new number extends the turn. A duplicate ends it.

### Alternatives

- Backbox Bonus Game control

When

Use this plan after every drain.

Steps

- Read which grid numbers are missing.

- Tap the left flipper to select and hold the most useful bank color.

- Use the right flipper to send the backbox ball toward A, B, C, or D.

- A made letter spots the selected bank number. A new number extends the turn. A duplicate ends it.

- If a color completes, Bonus X rises. Held balls release after the next playfield ball validates.

- Do not plunge for the next player until the game returns control.

- A-B-C-D Extra Ball route

When

Use this plan only when Extra Ball is enabled or converted to useful points.

Steps

- Complete bank A while its A letter is lit.

- Complete B, then C, then D on the same ball.

- Extra Ball alternates between the two inlanes. Collect the lit inlane.

- Keep the grid-number and Bonus X plan as the main scoring route.

### Builds Toward

5x, a complete grid, and 136,000 Super Bonus

Steps

- Complete colored four-number sets to reach 5x.

- Fill all 16 grid numbers with drop banks and the Backbox Bonus Game.

- Use each completed color to release one or two locked balls for Catacomb Multiball.

- Drain with the full grid lit. The game collects normal bonus and clears the grid.

Mode Notes

- Super Bonus: A full-grid drain lights a carried 136,000 collect for the next ball.

### Check Before Play

- Inspect both hidden side lock saucers before the first plunge. They can already contain balls locked by another player.

- Confirm Extra Ball and Special treatment. Extra Ball can be disabled; novelty play scores Special as 100,000.

- Do not start the next player's ball until the previous player finishes the Backbox Bonus Game.

### Simple Overview

Catacomb uses four colored number sets to fill a 16-number grid, raise Bonus X, and release held balls. Short-plunge Advance Spinner, complete only banks showing missing numbers, then use the 1,500 spinner when the remaining grid choices are poor. The bonus and multiplier carry between balls.

### Overview

Catacomb uses four colored number sets to fill a 16-number grid, raise Bonus X, and release held balls. Start with Advance Spinner, choose banks whose displayed number is missing, and complete colors to release held balls and raise Bonus X. Shift to the 1,500 spinner when the grid offers no safe useful bank.

### Machine Setup

- Inspect both hidden side lock saucers before the first plunge. They can already contain balls locked by another player.

- Confirm Extra Ball and Special treatment. Extra Ball can be disabled; novelty play scores Special as 100,000.

- Do not start the next player's ball until the previous player finishes the Backbox Bonus Game.
