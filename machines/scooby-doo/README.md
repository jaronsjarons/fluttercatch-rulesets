## Simple strategy

### Summary Title

The goal

### Summary

Choose Velma for easier Case starts. Use white investigation shots and the Mystery Machine for a Case, or use Scooby Snacks and the two apron locks for Scooby Snack Multiball.

### Steps

- Start a Case

Choose Velma for easier Case starts. Shoot the flashing fingerprint shots until a Case lights, use the left spinner to cycle the selection and the Launch button to lock it, then shoot the Mystery Machine to start the Case.

Mode Guide

The selected Case

Reason

Velma reduces the work needed to start Cases.

Play

Shoot the lit clue arrows until the magnifying-glass count fills. Shoot any optional lit trap shots, then return to the Mystery Machine before the timer ends to unmask the villain.

- Start Mystery Machine Multiball

Rip either spinner until a lock lights at the Mystery Machine, then shoot the Mystery Machine to lock a ball. Repeat for three locks; the third lock starts Mystery Machine Multiball.

### Quick Info

- Scooby Snacks

Summary

Drop-bank completions light Snacks that advance Bravery, Scooby Snack Multiball, Mystery Machine progress, Bonus X, and end-of-ball bonus.

- Cases

Summary

Collect the required white investigation shots, start the Case at the Mystery Machine, collect clues, make trap shots, then return to the Mystery Machine to unmask the villain.

- Scooby Snack Multiball

Summary

Collect enough Snacks, lock one ball in each apron, then shoot lit Snacks for jackpots and an apron lock for a Super Jackpot and relight.

### Fallback

Alternative route: Scooby Snack Multiball

When

This two-ball Multiball can run with Cases and every other feature.

Steps

- Clear either drop-target bank to light three Scooby Snacks. Shoot the lit character-orbit and spinner Snack shots. After four Snacks, shoot the exposed left VUK behind the drop banks for the first apron lock.

- Collect five more Snacks, reach the upper playfield, and shoot its middle orbit for the second apron lock. The second lock starts Scooby Snack Multiball.

## Full strategy

### Summary

Choose Velma, collect three white investigation shots, and start the first Case at the Mystery Machine before taking the second apron lock. During Scooby Snack Multiball, Snack Jackpots refill Bravery, and either apron lock scores the Super Jackpot and relights every Snack.

### Quick Info

- Scooby Snacks

Summary

Drop-bank completions light Snacks that advance Bravery, Scooby Snack Multiball, Mystery Machine progress, Bonus X, and end-of-ball bonus.

- Cases

Summary

Collect the required white investigation shots, start the Case at the Mystery Machine, collect clues, make trap shots, then return to the Mystery Machine to unmask the villain.

- Scooby Snack Multiball

Summary

Collect enough Snacks, lock one ball in each apron, then shoot lit Snacks for jackpots and an apron lock for a Super Jackpot and relight.

- Mystery Machine Multiball

Summary

Spinner hits light three locks at the Mystery Machine. During multiball, repeat each character orbit to light its Jackpot, then shoot the Mystery Machine to lock matched progress.

- Bravery Meter

Summary

Bravery is both the Case timer and its scoring multiplier, and Scooby Snacks refill it.

### Steps

- Choose Velma before plunging for easier Case starts.

Mode Notes

- Velma makes Cases easier to start. Scooby begins each ball with Ruh-Roh Save lit. Fred makes Mystery Machine Multiball easier to start.

- Select the drop-target skill shot with the flippers, then complete it to spawn four Scooby Snacks.

Mode Notes

- The other skill-shot choices raise the Trap Door or fully tier up the selected character orbit.

- Clear either drop-target bank to light three Snacks, then collect the lit Snacks at the character orbits and spinners.

- After four Snacks, use the exposed VUK behind the drop banks for the left apron lock. Rebuild the Snack requirement, then reach the upper playfield and shoot its middle orbit for the right apron lock.

Mode Notes

- The first apron lock needs four Snacks. Each later lock in the game needs one more, up to twelve.

- Before taking the second apron lock, collect the required white investigation shots and start the chosen Case at the Mystery Machine.

- Start Scooby Snack Multiball with the second apron lock while the Case is active.

- During the stack, collect the Case's clue shots and the lit Snacks. Make the required trap shots, then shoot the Mystery Machine to unmask the villain.

Mode Notes

- Scooby Snacks remain lit after collection while Scooby Snack Multiball is stacked with another feature. The Snacks refill Bravery during the Case.

- Shoot an apron lock for the Scooby Snack Super Jackpot. This also relights all Snacks for another jackpot cycle.

### Fallback

Mystery Machine Multiball

When

This is the separate three-lock Multiball route.

Steps

- Rip either spinner until a lock lights at the Mystery Machine.

- Shoot the Mystery Machine to lock a ball. Repeat for three locks and start Mystery Machine Multiball.

- Shoot one character orbit three times to light its Jackpot.

- Shoot the Mystery Machine while jackpots are lit to lock them in for later orbit shots.

- If all five character orbits reach the same level before jackpots are locked, shoot the Mystery Machine for the multiplied Super Jackpot.

### Alternatives

- Captain Cutler Multiball

When

This route stays on the upper playfield.

Steps

- Reach the upper playfield through the center ramp and bookcase diverter.

- Complete three hits to each hand target, the mini orbit, and the dive helmet.

- Hit the dive helmet again to start the first three-ball Captain Cutler Multiball.

- Hit the helmet to spawn jackpots, then collect the three lit shots before the tide resets their value.

### Builds Toward

Three wizard-mode routes

Steps

- Start all seven Cases to qualify Would've Gotten Away With It at the Mystery Machine.

- Start all five Character Modes to qualify The Gang's All Here.

- Collect 100 Scooby Snacks and shoot behind the drop targets to start Scooby-Doo Where Are You!

### Edition Differences

- Feature

Standard, Blood Sucker, and Collector's editions

Pro

The Standard Edition has the complete widebody playfield, upper playfield, dual apron locks, Mystery Machine lock, secret passage, and shared rules.

Premium

Blood Sucker and Collector's editions add trim, lighting, art, sculpts, shaker, or topper equipment. The main Case and multiball rules remain shared.

Source Url

[Source](https://www.kineticist.com/news/spooky-pinball-announces-scooby-doo-pinball)

- Feature

Optional Bookcase Topper

Pro

A game without the optional Bookcase Topper does not have the topper's Ghost of Elias Kingston feature.

Premium

A game with the topper can qualify Ghost of Elias Kingston from rapid center-ramp shots and start it at the Secret Passage.

### Techniques

- Bookcase upper-playfield entry

### Cautions

- Issue

The two physical apron locks are shared between players.

Response

A ball locked by one player can be taken by another. If the opposite lock is ready, collect it before ending the turn.

Source Url

[Source](https://www.spookypinball.com/wp-content/uploads/2025/01/Scooby-Doo-Rules.pdf)

- Issue

A Mystery award can reverse the flippers for the next feature.

Response

Reverse Flippers changes the controls for the next Mode or Multiball and awards 2x scoring while it runs.

Source Url

[Source](https://www.spookypinball.com/wp-content/uploads/2025/01/Scooby-Doo-Rules.pdf)

### Check Before Play

- Test the Mystery Machine, both spinners, both apron locks, the left VUK, and the upper playfield's middle orbit.

### Simple Overview

Scooby-Doo starts Cases from white investigation shots and the Mystery Machine, while Scooby Snacks prepare the apron locks for Scooby Snack Multiball. Choose Velma before plunging, collect three white investigation shots for the first Case, then shoot the Mystery Machine to start it. For Scooby Snack Multiball, collect four Snacks and lock a ball through the left VUK, then collect five Snacks and lock the second ball through the upper playfield's middle orbit.

### Overview

Scooby-Doo lets Scooby Snack Multiball run with a Case while its Snack Jackpots refill the Case's Bravery timer and scoring multiplier. Choose Velma, collect three white investigation shots, and start the first Case at the Mystery Machine before taking the second apron lock. During the stack, collect clues and Snacks, make the Case's trap shots, return to the Mystery Machine to unmask the villain, and shoot either apron lock for the Scooby Snack Super Jackpot and Snack relight.

### Machine Setup

- Test the Mystery Machine, both spinners, both apron locks, the left VUK, and the upper playfield's middle orbit.
