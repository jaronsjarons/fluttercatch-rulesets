## Simple strategy

### Summary Title

The goal

### Summary

Use the right flipper for repeatable up-top shots, max the base before risking the center bank, then collect Double Bonus through a lit side return lane.

### Steps

- Use the right flipper to send the ball up the left arc or into the upper saucer and build base bonus toward 100,000.

- After the base is valuable, complete the angled center three-bank to light Double Bonus.

- Return the ball to the top so it can feed the lit right or outer-left return lane and activate Double Bonus.

- Continue up top; avoid direct standup shots whose rebounds threaten the drain.

## Full strategy

### Overview

Butterfly is a bonus-first game. Build base bonus to 100,000 with the upper saucer and safer top-return lanes, then complete the angled center three-bank and roll through a lit side return lane for Double Bonus. Repeated bank completions also raise the targets from 100 to 1,000 to 10,000 each.

### Simple Overview

Build bonus with the upper saucer and safe shots back to the top. Complete the angled three-bank to light Double Bonus at the side return lanes, then roll through one of those lit lanes.

### Alternatives

- Drop-value ladder

When

Use this when the bank rebounds are predictable and Double Bonus is already secured.

Steps

- Complete the three-bank once to raise each drop to 1,000.

- Complete it again to raise each drop to 10,000 and light Extra Ball at the left arc if enabled.

- Take further bank shots only while their returns remain controlled.

### Builds Toward

100,000 doubled

Steps

- Max the base bonus through upper routes.

- Complete the three-bank to qualify Double Bonus.

- Roll through a lit side return lane and preserve the 200,000 end-of-ball payout.

### Machine Setup

- Test the upper saucer and eject, three-bank reset and value lamps, both Double Bonus return lanes, bonus ladder, left Extra Ball arc, and asymmetric lower-lane feeds.

- Confirm Extra Ball conversion and which top plunge lane produces the safer return on this copy.

### Cautions

- Issue

The safest plunge and saucer feeds vary by copy, and the lower playfield is asymmetric.

Response

Watch one plunge and one saucer eject before committing; transfer from the left flipper to the right when the feed permits it.
