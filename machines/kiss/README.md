## Full strategy

### Summary

Plunge the center top lane to light both spinners, repeat either spinner until the 40,000 Super Bonus is lit, complete A-B-C-D for 2X Bonus, then return to either spinner.

### Steps

- On each plunge, aim for the center top lane. If the ball touches a top-lane post, use a small nudge toward the center.

Mode Notes

- The center top lane lights both spinners for 1,000 per spin for the rest of the ball.

- If LIGHT-A-LINE is lit, the lane completes the current K-I-S-S row. If OPEN GATE is lit, it opens the right-outlane gate. If both are lit, both happen.

- Repeat either spinner to send the ball through the top lanes until the 40,000 Super Bonus is lit.

Mode Notes

- Each K-I-S-S letter adds 1,000 bonus. Each completed horizontal or vertical line adds 3,000. The carried bonus grid can be completed again for 80,000 and a third time for 120,000.

- After the 40,000 Super Bonus is lit, complete A-B-C-D on the right for 2X Bonus.

Mode Notes

- 2X Bonus does not carry to the next ball. Its A-B-C-D target-progress memory is a separate operator setting.

- If Extra Ball is enabled, complete A-B-C-D a second time to earn it.

- Return to either spinner and the top lanes. Do not chase the left K-I-S-S drop bank or the four K-I-S-S standups because their rebounds enter the bumpers.

### Quick Info

- Center top lane

Summary

It lights both spinners for 1,000 per spin for the rest of the ball. If LIGHT-A-LINE is lit, it completes the current K-I-S-S row. If OPEN GATE is lit, it opens the right-outlane gate. If both are lit, both happen.

- KISS bonus grid

Summary

Top-lane letters build the four-row carried bonus grid while the spinner route repeatedly sends the ball up top.

- Super and Colossal Bonus

Summary

One full grid gives 40,000, two give 80,000, and three cap the carried bonus at 120,000.

- A-B-C-D

Summary

The first completion gives 2X Bonus for the current ball, the second awards Extra Ball when enabled, and the third awards Special. The 2X lamp does not carry.

### Simple Overview

KISS rewards a center-lane plunge by lighting both spinners for 1,000 per spin for the rest of the ball. Repeat either spinner to send the ball through the top lanes until the carried Super Bonus reaches 40,000, then complete the four A-B-C-D targets for 2x end-of-ball bonus on that ball.

### Overview

In KISS, the center top lane lights both spinners and can also complete the current K-I-S-S row or open the right-outlane gate when those lamps are on. Plunge that lane, repeat either spinner until the carried Super Bonus reaches 40,000, then complete A-B-C-D for 2x end-of-ball bonus. Return to the spinners and top lanes instead of forcing the K-I-S-S targets through the bumpers.

### Machine Setup

- Test both spinners, the top-lane switches, A-B-C-D rebounds, bumper exits, the right-outlane gate, tilt sensitivity, and flipper strength.
