## Simple strategy

### Summary Title

The goal

### Summary

Hit the Live Fire Assault Range Warrior four times to start the first four-ball Multiball, shoot either ramp for five Jackpots, then return to the Warrior for the timed Super Jackpot.

### Steps

- Start Live Fire

Hit the Live Fire Assault Range Warrior four times to start the first four-ball Live Fire Assault Range Multiball.

- Collect five Jackpots

During Multiball, shoot the left ramp or right ramp for Jackpots. The first hit on each unlit colored Bug standup raises the Jackpot value, but the ramps are the scoring shots. Collect five ramp Jackpots.

- Collect the Super Jackpot

After the fifth ramp Jackpot, shoot the Live Fire Assault Range Warrior within 16 seconds for the 15,000,000 Super Jackpot. The ramp-Jackpot cycle then starts again while at least two balls remain.

## Full strategy

### Summary

Start Live Fire or Orbit Multiball for immediate points. Between multiballs, clear bugs with the mini-flipper. Decline the first one or two Planet Multiballs at Recon, advance to later planets, then start a larger Planet Multiball at Arm Nukes.

### Steps

- Use the normal B-U-G lane skill shot unless the right-ramp super skill shot is already reliable.

- Test the Warrior shot, both ramps, and one inlane-to-opposite-orbit sequence.

- Hit the Warrior four times to start the first Live Fire Assault Range Multiball.

Mode Notes

- Live Fire Assault Range Multiball: The first start needs four Warrior hits; later starts need more hits and the display gives the current count.

- During four-ball play, shoot the left ramp or right ramp for Jackpots. The first hit on each unlit colored Bug standup raises the Jackpot value.

- After five ramp Jackpots, shoot the Warrior within 16 seconds for a 15,000,000 Super Jackpot.

Mode Notes

- Live Fire restart: If the multiball ends before any Jackpot, a timed Warrior shot restarts it with two balls.

- In single-ball play, roll through an inlane and shoot the lit opposite orbit. Make four lit orbits for each of two locks.

Mode Notes

- Orbit Multiball: The released instruction card requires four lit orbit shots for each lock; two locks start the mode.

- During Orbit Multiball, repeat either orbit for 5,000,000. The first two orbit Jackpots each add a ball.

- Between multiballs, clear the displayed bugs and use the mini-flipper for lit standups when safe.

Mode Notes

- Double bug kill: A lit colored standup hit from the mini-flipper counts as two kills during normal planet play.

- After a planet clears, let the Brain Bug time out if its rebound is unsafe; the planet choice still appears.

- At the Recon scoop, choose Advance Planet for the first one or two cleared planets.

Mode Notes

- Advance Planet: The game skips the ready multiball, starts the next planet, and raises the future Nuke value and ball count.

- After at least three planets are ready, shoot Arm Nukes to start Planet Multiball.

Mode Notes

- Planet Multiball: Both ramps, both orbits, and Recon score unique Nuke Jackpots; Recon scores a Double Nuke and Arm Nukes spots one Nuke.

- Collect all five unique Nukes, then hit the Warrior for a Super Nuke worth 10x the regular value. Repeat until one ball remains.

### Fallback

Recovery: Live Fire Assault Range Multiball

When

Recovery pivot: Use this when bug standups and Arm Nukes are dangerous.

Steps

- Hit the Warrior until Live Fire starts.

- Repeat the ramp with the safer return.

- Use incidental standups to raise Jackpot; do not chase a dangerous target.

- Collect five ramp Jackpots.

- After five ramp Jackpots, shoot the Warrior within 16 seconds for the 15,000,000 Super Jackpot.

- Repeat while two or more balls remain.

### Alternatives

- Position play: Orbit Multiball

When

When trailing, use this higher-ceiling route: use this when both orbit returns are clean.

Steps

- Use an inlane to light the opposite orbit.

- Make four lit orbit shots for the first lock and repeat for the second.

- Loop either orbit for 5,000,000 Jackpots.

- The first two Jackpot orbits each add one ball.

- Stop at one ball; this multiball does not stack with another multiball.

- Recon level 5

When

Use this when both ramps and the Recon scoop form a reliable combo.

Steps

- Complete both ramps to light Recon.

- Shoot both ramps in sequence, then Recon, to raise its level.

- Collect level 5 for a chance at Instant Live Fire or Instant Orbit Multiball.

- Do not depend on a specific pseudo-random award.

### Builds Toward

Klendathu

Steps

- Clear Antilles, Zegema Beach, Dantana, Tango Urilla, and Planet P.

- Choose Advance Planet while another planet remains and the delay is worth the risk.

- After Planet P, start Planet Multiball at Arm Nukes.

- End that Planet Multiball after all five planets are nuked.

- Shoot Recon to start four-ball Klendathu.

- Collect all five Nukes and nine bugs of each color for each 50,000,000 wave.

### Simple Overview

Four Warrior hits start Live Fire in Starship Troopers, four lit opposite-orbit shots qualify each Orbit lock, and cleared bugs advance the planet campaign. Use the quicker Multiballs for immediate scoring, then start a later Planet Multiball at Arm Nukes.

### Overview

In Starship Troopers, four Warrior hits start Live Fire and four lit opposite-orbit shots qualify each Orbit Multiball lock. Use those quicker Multiballs for immediate scoring, clear displayed bugs between them, and choose Advance Planet at Recon while another planet is worth preparing. Start a later Planet Multiball at Arm Nukes, collect all five Nukes, then use the Warrior for repeatable Super Nukes toward Klendathu.
