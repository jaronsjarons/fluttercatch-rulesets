### Steps

## Full strategy

### Overview

Secret Agent Showdown is a standalone lock-and-Multiball game on the Lexy Lightspeed module. The qualification phase serves eight balls; shoot as many of them as possible into the spaceship's physical lock. The ship then releases the successful locks, and the ramps score Jackpots while two or more balls remain.

### Simple Overview

During the eight-ball qualification phase, shoot every served ball into the spaceship lock. The ship then releases the locked balls for Multiball; shoot the ramps for Jackpots until only one ball remains.

### Builds Toward

More balls and Jackpots

Steps

- Treat every qualification drain as a lost Multiball ball, so take time to control before shooting the lock.

- After release, trap one ball when possible and use the other to repeat a ramp Jackpot.

- Follow the display if the Super Duper Jackpot lights; its qualification is intentionally not inferred here.
