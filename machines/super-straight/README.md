## Simple strategy

### Summary Title

The goal

### Summary

Use the left flipper to repeat the upper-right gate and build bonus, use the right flipper to complete both Jacks, collect at the left saucer near 70,000, then use the lit spinner after 100,000.

### Steps

- From the left flipper, shoot the upper-right gate. Use each return to build base bonus.

- From the right flipper, shoot the two Jack standups. This lights Collect Bonus at the left saucer.

- When base bonus reaches about 70,000, shoot the left saucer from the right flipper.

Details

- Collect Bonus: Both Jacks light the left saucer. The saucer awards the current base bonus and resets it.

- After the collect, return to the upper-right gate and rebuild bonus.

- If base bonus reaches 100,000, use the left flipper to shoot the lit center spinner.

Details

- Maximum-bonus spinner: Reaching 100,000 base bonus lights the spinner for 1,000 per spin.

- When the spinner is weak, transfer the ball to the right flipper and collect bonus instead of forcing the spinner.

When

Use this when the Jack targets, Collect Bonus saucer, or center spinner has a dangerous return.

Steps

- Repeat the upper-right gate from the left flipper.

- Use top lanes and bumpers to build base bonus.

- Complete both King targets to open the lower gate only when they are collected naturally.

Upper-gate bonus build

When

Use this when the Jack targets, Collect Bonus saucer, or center spinner has a dangerous return.

### Alternatives

- Double Bonus position play

When

Use this only when base bonus is high and one safe Ace hit remains.

Steps

- Complete the second Ace to light the alternating return lane.

- Guide the ball through the lit return lane to activate Double Bonus.

- Do not collect base bonus at the saucer unless the match position requires immediate points.

### Builds Toward

Repeated high-value bonus collects

Steps

- Complete both Jacks to light Collect Bonus.

- Shoot the upper-right gate to return the ball to the top, then score top lanes and bumper hits to raise base bonus.

- Collect near 70,000 or later when the saucer feed is safe.

- At 100,000, add the lit spinner or protect Double Bonus according to match position.

### Simple Overview

Super Straight uses the upper-right gate to build base bonus, two Jacks to light a left-saucer collect, and the center spinner after bonus reaches 100,000. Repeat the gate, complete both Jacks, collect near 70,000 or later, then use the lit spinner at maximum base.

### Overview

Super Straight uses the upper-right gate to build base bonus, two Jacks to light a left-saucer collect, and the center spinner after bonus reaches 100,000.
