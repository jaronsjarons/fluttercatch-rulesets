## Simple strategy

### Summary Title

The goal

### Summary

Loop the Whirlpool while changing the L-O-C-K lanes, then shoot Pirate's Cove for two-ball Multiball. Cradle one ball and repeat the safer ramp for SINK SHIP letters. After Multiball, load the cannon and hit Broadside to sink each qualified ship.

### Steps

- Trap the ball on the left flipper. Test the Whirlpool ramp and its return.

- If the return is clean, repeat Whirlpool. Use lane change to complete L-O-C-K.

- Shoot Pirate's Cove when Lock lights. Use the two-ball multiball.

Details

- Multiball: Ramp shots score 1 million and add S-I-N-K S-H-I-P letters.

- Cradle one ball. Repeat the ramp with the safer return to build SINK SHIP letters.

- When SINK SHIP opens Davy Jones' Locker after Multiball, shoot the hole beneath the raised side ramp to load the cannon. Fire at the flashing Broadside target.

Details

- Broadside ship: The first ship scores 20 million. Each later ship adds 10 million.

- When a regular cannon shot offers Double Broadside, take it and repeat Broadside for 1, 2, 4, 8, 16, then 32 million before returning to the ship route.

- Repeat Lock, multiball letters, and Broadside ships.

### Alternatives

- Three-ball multiball

When

Use this plan only when Pirate's Cove and both ramp returns are reliable.

Steps

- During two-ball play, lock one ball in Pirate's Cove, then shoot the other there before the lock timer expires.

- Use the served third ball to continue three-ball Multiball.

- Shoot ramps for two SINK SHIP letters per ramp.

- Return to a two-ball cradle when control is available.

### Builds Toward

Escalating Broadside ships

Steps

- Store extra SINK SHIP letters during multiball.

- Use the stored letters to qualify more than one ship.

- Collect each ship for a value 10 million higher than the last.

### Techniques

- Offset cannon hit

Instruction

Aim the cannon slightly off center at the lit Broadside target. Hold the right flipper for the usual return and prepare one corrective nudge.

Do not flail at the return. Time one controlled upper-flipper shot only after the feed is visible.

### Simple Overview

Whirlpool loops spell L-O-C-K in Black Rose, and completing the word lights two-ball Multiball at Pirate's Cove. During Multiball, the ramps bank SINK SHIP letters for later ships. Repeat Whirlpool, start Multiball, use the safer ramp for letters, then load the cannon at Davy Jones' Locker and hit Broadside.

### Overview

Black Rose converts controlled ramp loops into Multiball progress and rising ship awards. Complete L-O-C-K through Whirlpool, start two-ball play, and bank SINK SHIP letters on the safer ramp. Use those letters to qualify ships, load the cannon, and collect Broadside before returning to the loop.
