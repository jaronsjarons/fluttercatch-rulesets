## Full strategy

### Summary

Plunge through Spot All Targets to start Diamond Hurry-Up. Knock down six diamond drop targets to score it and start another. When the right orbit lights, lock a ball; the hurry-up timer keeps running. Plunge to start Multiball and continue the target loop with two balls.

### Quick Info

- Diamond Hurry-Up

Summary

Spot All Targets or a full drop-target completion starts it. Knock down the six diamond drop targets to collect it and immediately begin another cycle.

- Spot All Targets skill plunge

Summary

Plunge across the lane rollover when the bottom of its three inserts is lit to start the first Diamond Hurry-Up.

- Multiball

Summary

Completing all six diamond targets lights the right orbit to lock a ball; the game then feeds the shooter lane for Multiball.

- Playfield X

Summary

Each lit top lane during Multiball adds 1x, up to 15x. It does not multiply Diamond Hurry-Up, Royal Flush, or All Diamonds Down.

- Royal Flush

Summary

Completing A-K-Q-J-10 resets all drops and ends the active Diamond Hurry-Up loop.

- Lit spinner

Summary

An inlane briefly lights its spinner. Use the incoming ball to shoot that spinner before the timer ends.

### Steps

- Plunge across the skill lane while Spot All Targets is lit to start Diamond Hurry-Up.

- Knock down all six diamond drop targets before the hurry-up ends.

- Repeat the six diamond targets when the next Diamond Hurry-Up begins.

- When the right orbit lights, shoot it to lock a ball. Diamond Hurry-Up continues to count down.

- Plunge the served ball to start Multiball. Use the second ball to finish the active six-target cycle.

- During Multiball, roll through lit top lanes to raise Playfield X, then return to the diamond-target loop.

- When an inlane lights its spinner, shoot that spinner before the short timer ends.

- Avoid completing Royal Flush while the Diamond Hurry-Up loop is paying well.

Steps

- Start Diamond Hurry-Up with Spot All Targets or a full target completion.

### Simple Overview

Diamond Lady turns repeated six-target completions into a continuous Diamond Hurry-Up loop. The same targets light a right-orbit lock, Multiball adds Playfield X through the top lanes, and completing Royal Flush ends the active hurry-up cycle.

### Overview

Completing all six diamond drop targets in Diamond Lady collects and restarts Diamond Hurry-Up and lights the right-orbit lock. Lock one ball there, plunge to start Multiball, and continue the target cycle while lit top lanes raise Playfield X. Avoid Royal Flush while the Hurry-Up loop is valuable because it resets the drops and ends that cycle.

### Machine Setup

- Confirm Gottlieb Diamond Lady from 1988 and read Competition Mode, Extra Ball, Special, and Royal Flush awards.

- Test the six drop-target rebounds, right-orbit lock feed, top lanes, kickback timer, and both timed spinners.
