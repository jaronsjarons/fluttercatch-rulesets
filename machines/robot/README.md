## Full strategy

### Overview

Robot begins its Red Special route at the upper Robot Bridge. Shoot the bridge to raise the five Robot targets, then knock them down to advance R-O-B-O-T; completing the required sequence lights Red Special for a return to the targets. The center drop bank lights Time Special and advances Orange Special. The three Z standups and upper-left lane advance the bonus multiplier. Upper lanes light Ball Return, with the yellow-target setting deciding whether one or both return lanes relight.

### Simple Overview

Shoot the upper Robot Bridge to raise five Robot targets, then knock them down to advance R-O-B-O-T toward Red Special. Complete the center drop bank for Time and Orange Special. Use the three Z standups or upper-left lane for Bonus X, and the upper lanes to light Ball Return.

### Builds Toward

Finish the Robot sequence

Steps

- Keep returning through the Robot Bridge and clearing all five raised targets.

- When Red Special lights, prioritize the target collect before starting another bank route.

### Machine Setup

- Check the number of Robot-target completions required for Red Special, the Orange Special requirement, Ball Return setting, ball count, and award values.

- Test Robot Bridge, all five rising targets, center drop bank, Time and Orange targets, Z standups, upper-left lane, upper lanes, yellow targets, and both return lanes.

### Cautions

- Issue

Robot-target and Ball Return behavior varies by setup.

Response

Read the R-O-B-O-T and return-lane lamps instead of relying on one fixed count.
