## Simple strategy

### Summary Title

The goal

### Summary

Collect Computer Screens at the Control Room and relight it at the Power Shed. Cycle through every Screen to start System Failure, then let its replenished balls feed the Turbo Bumpers for switch scoring.

### Steps

- Use the gun trigger for the video skill shot. If Smart Missile is enabled, preserve it for a valuable lit award or a threatened ball.

- Shoot the lit Control Room to collect the current Computer Screen.

Details

- Computer Screens: Each Control Room collect advances the sequence toward System Failure. The screen modes score differently, but collecting the next Screen is the lasting progress.

- Shoot the Power Shed, or use the available inlane relight, to relight the Control Room.

- During a Screen mode, take controlled lit shots while working back toward the next Control Room collect. Do not start Raptor Two-Ball during a valuable timed Screen.

Details

- Raptor Two-Ball aborts many active Computer Screens, and Tri-Ball cannot start while Raptor Two-Ball is running.

- Collect every Computer Screen. Shoot the lit Control Room or Power Shed to start System Failure.

Details

- System Failure aborts the running Computer Screens. They do not resume afterward; only a lit Extra Ball remains collectible.

- During System Failure, let drained balls auto-plunge into the Turbo Bumpers. Flip only when a controlled shot produces more switch activity than the bumper feed.

Details

- System Failure: 45 seconds of replenished six-ball play. Turbo Bumper switches supply the repeatable scoring.

### Quick Info

- Smart Missile

Summary

The action button collects most lit playfield awards once per game.

- Tri-Ball

Summary

Complete the Species map, then feed T-Rex or hit the Raptor Pit enough times to start three-ball play.

- CHAOS

Summary

A Tri-Ball Jackpot lights the first CHAOS set, whose completion starts six-ball play.

### Fallback

Alternative route: Tri-Ball and CHAOS

When

Use this route when the Species targets and Raptor Pit are registering reliably and the installed Tri-Ball settings are practical.

Steps

- Complete the six Species groups. Use a lit Boat Dock shot to spot a difficult group.

- When Tri-Ball is lit, hit the Raptor Pit twice, regain control, then make the third hit to start Tri-Ball.

- During Tri-Ball, shoot the ramp for the Jackpot or the Helicopter Pad for the Double Jackpot.

- After either Jackpot, spell CHAOS while at least two balls remain. Completing the first set starts six-ball play.

- Spell CHAOS again, then feed T-Rex for 50,000,000.

- Shoot the ramp and Helicopter Pad for the twin Super Jackpots. If Smart Missile remains, use it when both are lit.

### Warning

The lit Visitor's Center orbit can hit an upper rubber and return toward the center drain.

Test the first return before you use it for bonus X. Prefer Control Room or Tri-Ball progress when that feed is dangerous.

### Check Before Play

- Confirm CPU ROM 5.13 and display 5.10; older ROMs change Egg, CHAOS, Mr. DNA, values, and mode behavior.

- Test Raptor Pit kickouts, Boat Dock, T-Rex, Control Room, ramp, Helicopter Pad, Power Shed, and Visitor's Center returns.

### Simple Overview

Jurassic Park uses Control Room Computer Screens to build toward System Failure. Collect a Screen, relight Control Room at the Power Shed, and cycle through every Screen; avoid starting Raptor Two-Ball when it would abort a running Screen.

### Overview

Each Control Room Screen advances System Failure in Jurassic Park, and the Power Shed relights the Control Room. Complete the required species to qualify Tri-Ball; its first Jackpot lights C-H-A-O-S. Complete the Screens without interrupting them with Raptor Two-Ball, then use System Failure's replenished balls for Turbo Bumper switch scoring.

### Machine Setup

- Confirm CPU ROM 5.13 and display 5.10; older ROMs change Egg, CHAOS, Mr. DNA, values, and mode behavior.

- Tournament settings can reset T-REX, fix Mr. DNA awards, disable Extra Balls, change Tri-Ball hits, and alter ball saves.

- Test Raptor Pit kickouts, Boat Dock, T-Rex, Control Room, ramp, Helicopter Pad, Power Shed, and Visitor's Center returns.
