## Simple strategy

### Summary Title

The goal

### Summary

Complete the three DINO EGG drop targets to open the Escape Gate, use the Mystery Path or Dinosaur Cave to reach the upper-left flipper, cross the Bridge of Gold, then shoot the open Escape Gateway with the upper-right flipper.

### Steps

- Open the Escape Gate

Complete the three DINO EGG drop targets. The full bank opens the Escape Gate for 30 Time Units, but almost any scoring switch can close it sooner.

- Reach the upper-left flipper

While the gate is open, shoot the Mystery Path ramp or enter the Dinosaur Cave so its elevator feeds the upper-left flipper.

- Cross the Bridge of Gold

Use the upper-left flipper to shoot across the Bridge of Gold. Let the ball reach the upper-right flipper.

- Escape and collect

Use the upper-right flipper to shoot the open Escape Gateway. It scores 50,000, collects the Treasure Value already built during the ball, and releases the reserve ball for two-ball play. Continue scoring the normal playfield awards with both balls.

## Full strategy

### Summary

Learn the three plunge feeds. Build Treasure Value, then complete DINO EGG. Cross the Bridge of Gold and shoot the open Escape Gateway. The shot collects Treasure Value and starts two-ball multiball.

### Steps

- Read the shooter-lane result on the first plunge.

Mode Notes

- Treasure Value: This stored score starts at 100,000 and can reach 2,500,000. The Escape Gateway collects it, then resets it to 100,000.

- Multiball Release Memory: This stored three-lamp counter advances at either 25K rollover. The third lamp releases the reserve ball. Partial progress carries between balls and resets after multiball.

- Gentle plunge: Reach the flipper-return ramp rollover. It scores 25,000, adds 50,000 Treasure Value, and advances Memory once.

- Firm plunge: Reach the upper right flipper for a Volcano shot.

- Hard plunge: Cross the Mountain and operate the Skeleton. It scores 50,000 and adds 100,000 Treasure Value.

- Test one safe feed to the upper left flipper. Use a cave elevator or a short Mystery Path return.

- Build Treasure Value before the collect attempt.

Mode Notes

- Left Golden Idol bank: Complete three targets for 30,000 points and 30,000 Treasure Value.

- Right Golden Idol bank: Complete five targets for 50,000 points and 50,000 Treasure Value.

- Completed banks reset. Partial target progress carries between balls.

- Each center or right cave trip adds 50,000 Treasure Value.

- Each Volcano star rollover adds 100,000 Treasure Value.

- Each Skeleton or Mountain switch adds 100,000 Treasure Value.

- Complete the three DINO EGG drop targets.

Mode Notes

- Escape Gate Timer: The full bank opens the gate and starts a 30-Time-Unit window. A normal scoring switch can close the gate earlier.

- Each DINO EGG target scores 3,000 and adds 10 Time Units.

- An unlit 25K return switch, flipper-return ramp rollover, unlit Golden Idol, or Volcano rollover does not close the gate.

- Shoot the Mystery Path ramp or enter the Dinosaur Cave so its elevator feeds the upper-left flipper before another scoring switch closes the Escape Gate.

- Shoot the Bridge of Gold with the upper left flipper. Prepare the upper right flipper.

- Shoot the open Escape Gateway with the upper right flipper.

Mode Notes

- Two-Ball Multiball: The Gateway scores 50,000, collects Treasure Value, and releases the reserve ball. Normal scoring continues. There is no jackpot or scoring multiplier.

- The Escape Path operates two switches before multiball begins.

- Multiball ends when one ball remains. Multiball Release Memory then resets.

- During multiball, use safe Golden Idol banks, caves, Volcano rollovers, and Mountain paths to rebuild Treasure Value.

- After multiball, rebuild Memory or repeat the Escape Gateway sequence for another start.

### Fallback

Automatic two-ball multiball

When

Use this plan when the Bridge of Gold transfer is not reliable.

Steps

- Use a gentle plunge for the flipper-return ramp rollover.

- Confirm that one Multiball Release Memory lamp is lit.

- Shoot the Right Cave when it gives a controlled flipper-return ramp feed.

- Use the Dinosaur Cave saucer when the ramp feed is poor.

- Each completed 25K rollover scores 25,000, adds 50,000 Treasure Value, and advances Memory once.

- Collect the third Memory lamp. The reserve ball releases from the far-left physical lane.

- Use two-ball play to complete safe Golden Idol banks and rebuild Treasure Value.

- Do not force the Gateway. Multiball has no jackpot.

### Alternatives

- Ball Saver lane start

When

Use this start only when the left return-lane split is predictable.

Steps

- Guide a left return toward the far-left Ball Saver lane with an early legal nudge.

Mode Notes

- Ball Saver lane: This physical far-left lane holds the incoming ball with the reserve ball. It then releases both balls for multiball. It is not a timed software save.

- The lane scores 100,000 and immediately starts two-ball multiball.

- Do not force the route after the ball passes below the slingshot. The adjacent path is the left outlane.

- Mountain opening route

When

Use this plan when the upper right flipper reaches the Mountain more reliably than the DINO EGG bank.

Steps

- Reach the upper right flipper.

- Shoot the closed-gate Mountain path. Each completion operates the Skeleton switch.

- Each completion scores 50,000 and adds 100,000 Treasure Value.

- Repeat until the Escape Gate opens. The required count is adjustable; the factory setting uses six.

- Use the next Bridge of Gold feed to shoot the open Escape Gateway.

- Volcano Extra Ball

When

Use this plan when the upper right flipper reaches the Volcano safely and replay balls have tournament value.

Steps

- Shoot the Volcano Tunnel or send a firm Bridge of Gold shot past the upper right flipper.

Mode Notes

- Extra Ball: A Volcano award qualifies a replay ball at the Skeleton. The award is spent after the current ball drains and SHOOT AGAIN serves the replay ball.

- Each Volcano rollover scores 50,000 and adds 100,000 Treasure Value.

- On medium difficulty, collect two Volcano rollovers to flash Extra Ball.

- Operate the Skeleton switch to collect the flashing Extra Ball.

- Only one Extra Ball can be earned per game ball.

- Extra Ball cannot be earned during replay-ball play or while SHOOT AGAIN is lit.

- Right Cave Special

When

Use this plan only when a replay award has tournament value.

Steps

- Complete the Right Cave until its Special lamp flashes.

Mode Notes

- Special: This operator-configured replay award is qualified by repeated Right Cave completions. A later flashing cave completion spends it. Only one Special is available per game.

- Medium difficulty requires three Right Cave completions to qualify Special.

- Shoot the flashing Right Cave again to collect it.

- Ignore this route when tournament settings remove replay value.

- Hold Bonus route

When

Use this plan when cave returns are safe and the current bonus is valuable.

Steps

- Enter any Dinosaur Cave opening until HOLD BONUS WHEN FLASHING flashes.

Mode Notes

- Lava Pit Bonus: This end-of-ball award grows from normal switches to 510,000. It has no multiplier. A drain collects it. A tilt cancels it.

- Hold Bonus: Repeated cave entries qualify stored bonus progress. A cave entry while the lamp flashes stores the current award for the next ball.

- Medium difficulty needs two entries on Ball 1, three on Ball 2, and four on Ball 3.

- Enter a cave again while HOLD BONUS WHEN FLASHING is lit.

- Confirm the BONUS HELD lamp.

- A normal drain collects the current Lava Pit Bonus.

- The held value carries to the next ball and combines with the next held award.

- Avoid a tilt. It cancels the bonus collect.

### Builds Toward

2,500,000 Treasure collect and two-ball multiball

Steps

- Repeat both Golden Idol banks.

- Use controlled cave entries for 50,000 Treasure Value each.

- Use Volcano and Mountain paths for 100,000 Treasure Value each.

- Continue until Treasure Value reaches 2,500,000.

- Complete DINO EGG to open the Escape Gate.

- Feed the upper left flipper and cross the Bridge of Gold.

- Shoot the open Escape Gateway with the upper right flipper.

- Collect 2,500,000 plus the 50,000 Gateway award. Start two-ball multiball.

### Check Before Play

- Read the difficulty settings for Mountain, Right Cave, Volcano, and Dinosaur Cave before depending on a fixed qualification count.

- Treat the Escape Gate as 30 Time Units, not 30 real seconds. A scoring switch can close it before the displayed window ends.

- Confirm whether Extra Ball and Special have tournament value before using either secondary route.

### Cautions

Start the nudge before the ball reaches the split. A late nudge has less effect.
