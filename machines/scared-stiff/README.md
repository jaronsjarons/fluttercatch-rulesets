## Simple strategy

### Summary Title

The goal

### Summary

Soft-plunge into Spin Spider and take Coffin, shoot the left ramp and left loop to collect three locks, then alternate ramp Jackpots during Stiff in the Coffin or control one ball and repeat the left ramp.

### Steps

- Soft-plunge just beyond the second gate to enter Spin Spider. Stop it on Coffin.

- Shoot the left ramp to light a lock. Shoot the left loop to collect it. Repeat for all three locks.

- Start Stiff in the Coffin and alternate the left and right ramp Jackpots.

Details

- Stiff in the Coffin: Three locks start three-ball play. Alternate the lit ramp Jackpots.

- Coffin restart: The Coffin Web award restarts this multiball once after it ends.

- If alternating ramps breaks control, trap spare balls on the left and shoot one controlled ball. Unlit ramp shots still raise the Jackpot.

- Use the right ramp to relight Spin Spider during single-ball play. Collect useful Web awards only before another multiball starts.

- Continue the six Tale objectives toward Scared Stiff. Do not force the Crate when its rebound is unsafe.

### Quick Info

- Spin Spider

Summary

A soft plunge can enter the spider, where Coffin advances the lock and awards one Stiff in the Coffin restart.

- Stiff in the Coffin

Summary

Shoot the left ramp to light Lock and the left loop to collect it three times, then alternate ramp Jackpots during three-ball play.

- Terror from the Crate

Summary

Hit the Crate enough times to start two-ball play with repeatable Crate Jackpots.

### Fallback

Alternative route: Left-ramp loop

When

Use this when the Crate, Coffin lock loop, or upper kickout is unsafe.

Steps

- Repeat the left ramp from a controlled feed.

- Use its growing value and same-flipper return to advance Boney Beast.

- Take Terror from the Crate only after the Crate restart Web award is collected.

- Return to Coffin progress when the left loop is under control.

### Warning

Ramp returns are fast, and the left-outlane Spell standups are dangerous.

Do not force Spell standups. Use controlled ramp loops and incidental bank hits.

### Alternatives

- Terror from the Crate

When

Use this when the Crate is safer than the left-loop lock path.

Steps

- Hit the Crate for the displayed qualification requirement.

- Start two-ball Terror from the Crate.

- Repeat the Crate for Jackpots. Use the Crate Web award for one restart.

### Builds Toward

Scared Stiff and Spider Mania

Steps

- Complete Stiff in the Coffin, Terror from the Crate, Leapers, Deadheads, Monster's Lab, and Boney Beast.

- Shoot the Crate to start Scared Stiff. Alternate a ramp with the Crate through ten Stiff-O-Meter levels.

- Make the final Crate shot to start four-ball Monster Multiball.

- Collect all sixteen unique Web awards to start four-ball Spider Mania.

### Cautions

The Crate is a dangerous direct shot, and its upper kickout is unpredictable.

Response

Test the kickout before you make Crate multiball the main. Use Coffin locks or the left-ramp loop when it is unsafe.

### Simple Overview

Three left-ramp and left-loop locks start Stiff in the Coffin, while repeated Crate hits start Terror from the Crate in Scared Stiff. Soft-plunge Spin Spider for Coffin, then use the Multiball route whose shots return safely.

### Overview

In Scared Stiff, Coffin shots build Stiff in the Coffin, Crate hits build Terror from the Crate, and six completed Tales qualify Scared Stiff. Use a Coffin award to advance the three-lock route, then alternate ramp Jackpots or control one ball and repeat the left ramp. Build Tales alongside safe Multiballs without delaying a ready start for Double Trouble alone.
