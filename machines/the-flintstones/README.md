## Simple strategy

### Summary Title

The goal

### Summary

Start a safe 1-2-3 mode before completing C-O-N-C-R-E-T-E, then use multiball to alternate the center-lane Jackpot and upper-flipper U-Turn Super.

### Steps

- Test the ramps, center lane, U-Turn, BED targets, ROCK targets, and orbit-to-Time-Machine feed.

- Complete the lit 1-2-3 ramp sequence to start a mode whose shots overlap the main route.

- Build C-O-N-C-R-E-T-E through the safer BED or ROCK bank and any available Bronto Crane spotting.

- Shoot a lit orbit, or complete DIG where applicable, to start three-ball multiball.

- Shoot the center lane for the regular Jackpot and prepare for its feed to the upper flipper.

- Use the upper flipper to shoot the U-Turn Super Jackpot, which relights the center-lane Jackpot.

- Repeat the center-to-U-Turn cycle while using the running mode's overlapping lit shots.

- Between starts, complete a shell bank for Drain Shield before attacking the central target areas.

### Fallback

Alternative route: Dino Frenzy

When

Use this when ramp transfers and C-O-N-C-R-E-T-E banks reject but the Dino targets are safe.

Steps

### Alternatives

- Bronto Crane spot

When

Use this when the left orbit is reliable and direct BED or ROCK hits are dangerous.

Steps

- Shoot the left orbit to light Bronto Crane.

- Shoot it again for the diverted award.

- Take Spell CONCRETE when awarded, then start multiball from the safest lit route.

- Bowl-A-Rama multiball

When

Use this when two strikes are already recorded and the ramp-to-bowling feed is consistent.

Steps

- Shoot the lit Go Bowling ramp.

- Make the center strike target; use Bowling Power-Up when available.

- After the third strike, take Super Strikes during two-ball play.

### Builds Toward

Mystery Mode

Steps

- Play all four 1-2-3 modes.

- Start Mystery Mode on the next completed sequence.

- Knock down BED and ROCK inside the timer for the completion award.

### Simple Overview

Any of The Flintstones' four 1-2-3 modes can continue during C-O-N-C-R-E-T-E Multiball. Start a mode through its three lit ramps, finish CONCRETE, then collect the center-lane Jackpot and use its upper-flipper feed for the U-Turn Super before repeating the cycle.
