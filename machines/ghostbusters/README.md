## Full strategy

### Summary

Use the left-ramp Scene ladder, start a Scene before Storage Facility Multiball, then build the 2x and 3x Gear multipliers for Storage or We Came, We Saw.

### Steps

- Before the plunge, use the flippers to select the left-ramp Start Scene skill shot. Plunge. Shoot the left ramp.

Mode Notes

- Start Scene skill shot: The display selects one major shot. Make that shot after the plunge to start the first unplayed scene at that location.

- The left-ramp ladder has We Got One, He Slimed Me, and The Ballroom. Complete them in that order.

- Complete the flashing scene shots. Return to the left ramp to start the next scene when it lights.

Mode Notes

- Scene: A timed single-ball mode. Make its flashing shot sequence before time expires. Scenes do not stack with other scenes.

- A drain ends the current attempt. Completed lower scenes stay complete. The highest scenes can resume under current rules.

- The left-ramp ladder is the main route because its skill shot is easier, its scenes score well, and its final multiball uses three balls instead of two.

- While a left-ramp Scene is active, repeat the left ramp to light and collect three Storage locks. The third lock starts Storage Facility Multiball.

Mode Notes

- Storage Facility Multiball: Complete the captive-ball award to light all three locks. You can also earn one lock at 10, 30, and 50 collected ghosts.

- A running scene continues into Storage. Start the scene first. A scene cannot start during multiball.

- Storage ends when one ball remains.

- During Storage, shoot every lit ghost shot for a jackpot and one ghost. After all lit ghosts are collected, shoot the left ramp for three Super Jackpots.

Mode Notes

- A full ghost set lights three Super Jackpots at the left ramp. After the third Super, the ghost jackpots relight.

- Complete the scene during Storage when possible. If it is the final scene in its ladder, We Came, We Saw can start inside Storage.

- During Storage, hit the captive ball until Add-A-Ball lights. Then shoot the left scoop.

Mode Notes

- Storage add-a-ball: Two hits qualify it on some configurations and three on others. The lit scoop launches one ball and restarts ball save.

- Use multiball ball save for the captive-ball hits. Do not force them during single-ball play.

- Make a Gear Combo. Start both timed multipliers. Keep both targets active for 6x scoring.

Mode Notes

- Gear Combo: Shoot the left ramp. Then hit the left captive ball or a flashing yellow Gear target.

- The first combo lights the 2x target. The next combo lights the 3x target. Hit each lit target to start its timer.

- The two timers run together for 6x. Hit an active target again to add time.

- Use 6x during Storage, a valuable scene, or We Came, We Saw.

- Complete The Ballroom. Play We Came, We Saw. Alternate jackpots so completed shots relight.

Mode Notes

- We Came, We Saw: Completing one scene ladder starts this mini-wizard at that ladder's final shot. Its ball count equals the number of scenes in the ladder.

- All major shots start as jackpots. A collected shot turns off. Another jackpot relights it.

- The jackpot starts at 6,250,000 and grows by 750,000 to a 30,000,000 cap. Enough jackpots light a 100,000,000 Super Jackpot.

- The mode ends when one ball remains. Keep 2x and 3x active when possible.

### Fallback

Short scoop ladder

When

Use this plan when the left ramp return is too dangerous.

Steps

- Select the left-scoop Start Scene skill shot. Start Spooked Librarian.

- Complete Spooked Librarian. Start and complete Back Off, Man!

- Play the two-ball We Came, We Saw from the scoop.

Mode Notes

- This route needs only two scenes. Its final multiball has only two balls, so it is less forgiving than the main route.

- Use Gear Combo multipliers only when the captive-ball return is controlled.

### Alternatives

- Ghost-meter route

When

Use this plan when Storage and scene shots are not repeatable but ghost shots occur naturally.

Steps

- Collect ghosts. The meter gives Storage locks at 10, 30, and 50 ghosts.

- At 20 ghosts, collect Tobin's Spirit Guide at the left scoop for several awards.

- Continue to 60 for Loopin' Supers and 80 for PKE Frenzy.

- Collect 100 ghosts to start Mass Hysteria.

Mode Notes

- Mass Hysteria: The flipper buttons are reversed. Major shots score jackpots. Captive-ball hits temporarily restore normal controls. The ghost meter resets after the multiball.

### Builds Toward

We're Ready to Believe You and Are You a God?

Steps

- Complete one Scene ladder to start We Came, We Saw. Complete a second ladder to start it again.

- Complete all nine Scenes to start We're Ready to Believe You.

- Are You a God? starts only after the required ghost total is reached during that wizard mode; the Build section stops when We're Ready to Believe You begins.

### Techniques

- Ball-save captive test

Instruction

During initial ball save, use a short plunge or the safe validation window to test one captive-ball hit. Stop if the return is not controlled.

- Scoleri graze

Instruction

Hit the edge of a Scoleri target. Let the ball continue past the target instead of rebounding straight down the middle.

Source Url

[Source](https://www.kineticist.com/news/ghostbusters-pinball-tutorial)

- Crossed-arm flippers

Instruction

During Mass Hysteria, cross your arms so each hand remains aligned with the flipper that it controls. Uncross when a captive-ball hit restores normal controls.

### Cautions

- Issue

The layout has a wide flipper gap and fast side-to-side feeds.

Response

Use the first ball to test major returns. Nudge early, before the ball reaches the outlane entrance.

Source Url

[Source](https://www.youtube.com/watch?v=3WhGslpP6NM&t=883s)

- Issue

The center inlane rails can bounce a ball toward an outlane.

Response

Do not assume a rail feed is safe. Keep both hands ready and nudge before the ball reaches the slings.

Source Url

[Source](https://www.kineticist.com/news/ghostbusters-pinball-tutorial)

- Issue

A left-ramp return can hit the center-inlane post and leave through an outlane.

Response

Test the return under ball save. Use the short scoop ladder when the left-ramp feed cannot be saved.

Source Url

[Source](https://www.kineticist.com/news/ghostbusters-pinball-tutorial)

- Issue

A direct Scoleri hit can return down the middle.

Response

Graze the edge of the target so the ball continues past it. Make direct hits during multiball when possible.

Source Url

[Source](https://www.kineticist.com/news/ghostbusters-pinball-tutorial)

- Issue

The left captive ball and right ramp are high-risk precision shots.

Response

Make captive-ball hits during multiball. Ignore the right ramp unless a selected scene requires it.

### Overview

Ghostbusters uses three ordered Scene ladders, and completing one ladder starts We Came, We Saw with one ball for each Scene in that ladder. Select Start Scene at the left ramp before plunging, make the ramp as the first major shot to start We Got One, then complete the left-ramp ladder. While a Scene runs, collect the third Storage lock at the left ramp so the Scene continues into Storage Facility Multiball. Shoot the left ramp, then the left captive ball or a flashing yellow Gear target to light 2x and 3x; hit both lit targets for 6x playfield scoring. Collect every lit ghost Jackpot, then shoot the left ramp for the three Super Jackpots and the final We Came, We Saw ladder.

### Simple Overview

The left scoop, left ramp, and right orbit each hold an ordered Scene ladder in Ghostbusters. Before plunging, select Start Scene at the left ramp, then make the ramp as the first major shot to start We Got One. Complete its flashing sequence and return to the lit left ramp for He Slimed Me and The Ballroom. Collect Storage locks at the left ramp after captive-ball progress or 10, 30, and 50 ghosts; a running Scene continues when the third lock starts Storage Facility Multiball. Shoot the left ramp, then the left captive ball or a flashing yellow Gear target to light 2x and 3x; hit both lit targets for 6x playfield scoring.
