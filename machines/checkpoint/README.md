## Simple strategy

### Summary Title

The goal

### Summary

Advance the tachometer to 8000 RPM for Red Line Multiball, raise the Jackpot with C-A-R-R-E-R-A, then use the Checkpoint shot to double a controlled ramp collect.

### Steps

- Use L-A-P, the safer CARRERA bank targets, and clean ramp shots to move the tachometer toward 8000 RPM.

- Read the RPM awards before choosing the next risk.

Details

- 6000 RPM: Checkpoint starts a two-ball multiball.

- 7000 RPM: Checkpoint or Pit Stop starts a two-ball multiball.

- 8000 RPM: Red Line starts with three balls.

- Enter Red Line Multiball with CARRERA already near completion when the target rebounds are controllable.

- Hit the Checkered Flag target to light the ramp jackpot, then collect the ramp before its short light expires.

- Complete CARRERA between collects to raise the jackpot, but stop at 4 million because another completion wraps it to 2 million.

- With three balls still alive, shoot Checkpoint before the next ramp collect to double that jackpot.

- If FAST is ready, start it during protected play and favor dense switches without abandoning a lit jackpot.

### Quick Info

- RPM

Summary

L-A-P, the CARRERA bank, pop bumpers, fast ramps, and Pit Stop awards can advance the tachometer.

- Multiballs

Summary

6000 RPM starts two-ball Checkpoint Multiball; 8000 RPM starts three-ball Red Line Multiball.

- Jackpot

Summary

The Checkered Flag target lights the ramp briefly; CARRERA completions raise the next jackpot.

### Fallback

Alternative route: Checkpoint Multiball cashout

When

Use this when 6000 RPM is ready but reaching 8000 RPM would require unsafe target rebounds.

Steps

- Shoot Checkpoint at 6000 RPM to start two-ball play.

- Use the extra ball to finish CARRERA or F-A-S-T progress.

- Return to ramp and RPM work after one ball remains.

### Warning

CARRERA and the Checkered Flag can rebound toward the center drain.

Use protected play or a settled flipper feed for target work.

### Alternatives

- Ramp and country route

When

Use this when the ramp is repeatable and the standups are rejecting.

Steps

- Repeat the ramp to light country flags and advance the consecutive-ramp award.

- Use the ramp return to regain control rather than forcing CARRERA.

- Resume RPM progress when a controlled CARRERA drop-target shot is available.

- FAST switch window

When

Use this when F-A-S-T is complete and a multiball start is close.

Steps

- Hold the FAST start at Checkpoint until protected play is ready.

- Start FAST, then start the available multiball.

- Take controlled switch feeds while preserving any lit jackpot.

### Builds Toward

Repeated doubled Red Line jackpots

Steps

- Reach 8000 RPM with CARRERA near completion.

- Start Red Line and light the ramp jackpot.

- Use Checkpoint to double a collect while three balls remain.

- Complete CARRERA to raise the Jackpot, then hit the Checkered Flag target to relight the ramp.

### Techniques

- Jackpot-light discipline

Instruction

### Check Before Play

- Confirm the pop-hit RPM threshold and whether the lit 1-million ramp award repeats during its ten-second window.

- Test the Checkered Flag drop, ramp, CARRERA bank, Checkpoint, and Pit Stop; all mode timers end without a grace period.

### Simple Overview

Checkpoint uses L-A-P, CARRERA, bumpers, ramps, and Pit Stop awards to move its tachometer toward Multiball. Reach 8000 RPM for three-ball Red Line, hit the Checkered Flag target to light the ramp Jackpot, then use Checkpoint before a ramp collect to double it while three balls remain.

### Overview

Checkpoint starts two-ball Checkpoint Multiball at 6000 RPM and three-ball Red Line at 8000 RPM. Favor 8000 RPM when CARRERA is controllable, hit the Checkered Flag target before each ramp Jackpot, and use Checkpoint to double the next collect while three balls remain. Take the earlier start when more target work would cost control.
