## Simple strategy

### Summary Title

The goal

### Summary

Complete A-B-C-D at the top to raise the Hole Value. Shoot a Roto target only when it shows a missing number. Then return to top play and favor the lit side Hole Value lanes.

### Steps

- Plunge through a missing A-B-C-D lane.

- Send controlled balls to the top until A-B-C-D is complete and the Hole Value reaches 5,000.

- Read both exposed Roto numbers before each lower-playfield shot.

- Hit a Roto target only when it shows a number that is still missing.

- When both exposed numbers are already complete, send the ball to the top instead.

- After most numbers are complete, use top play and the lit side Hole Value lanes for repeatable scoring.

- Avoid the center hole unless its shot and return are clearly safer on this machine.

### Quick Info

- A-B-C-D lanes

Summary

Each completed top letter raises the center hole and lit side Hole Value lanes by 1,000, to a maximum of 5,000.

- Roto targets

Summary

The two exposed Roto targets collect the numbers that they show from the seven-number set.

- Hole Value lanes

Summary

A lit side Hole Value lane collects the built value without the direct risk of a center-hole shot.

### Fallback

Alternative route: Recovery: A-B-C-D and top play

When

Recovery pivot: Use this when the Roto targets, center hole, or side-lane gaps reject shots dangerously.

Steps

- Ignore direct Roto and center-hole shots.

- Send the ball to the top through the widest controlled route.

- Complete A-B-C-D to raise the Hole Value to 5,000.

- Take lit side Hole Value lanes only when upper play feeds them naturally.

### Warning

The direct center-hole shot is not worth its normal drain risk.

Use a lit side Hole Value lane or return to the top. Test the center hole only when its geometry is unusually safe.

### Alternatives

- Position play: Controlled center-hole collect

When

When trailing, use this distinct scoreboard route: use this only when the center-hole shot is reliable and its return is known.

Steps

- Complete as many A-B-C-D letters as practical.

- Build the center-hole value toward 5,000.

- Shoot the center hole from a controlled flipper.

- Return to side-lane and top play after one dangerous miss.

### Builds Toward

5,000 Hole Value and a useful number set

Steps

- Complete A-B-C-D to raise Hole Value to 5,000.

- Collect missing Roto numbers only when they face a flipper.

- Stop shooting Roto targets when both exposed numbers are complete.

- Convert later top play into lit side-lane Hole Value collects.

### Simple Overview

Spin Out uses A-B-C-D to raise a shared Hole Value, then lets either side lane or the tighter center hole collect it. Complete the top letters for 5,000, take missing roto numbers only when they face a flipper, and favor the lit side Hole Value lanes.

### Overview

Spin Out uses A-B-C-D to raise a shared Hole Value, then lets either side lane or the tighter center hole collect it. Repeat upper play to finish A-B-C-D, shoot only missing roto numbers, then stop targeting the rotos once both exposed numbers are complete. Convert later top feeds into the safer lit side-lane collects instead of forcing the center hole.
