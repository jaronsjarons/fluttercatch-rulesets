## Simple strategy

### Summary Title

The goal

### Summary

Shoot lit rollunder gates A-E in order to raise them to 10x, then 100x; use the lit side saucer for steady value, and at 100x choose the next gate through the Roto window because it scores the shown value and resets the sequence.

### Steps

- Plunge either center 50-point lane to spin the Roto.

- Read the currently lit letter and shoot only that A-E rollunder.

- Complete A through E once to raise the rollunder value to 10x.

- Repeat the ordered sequence to reach 100x.

- At 100x, compare the value visible beneath the next reachable rollunder.

- Shoot the best controlled lit gate to score its displayed value at 100x, then expect the base value to reset.

- When the ordered gate is not controlled, shoot the currently lit side saucer for 50, 100, or 150.

- Use bumper and safe-lane action to change the tens digit when swapping the lit saucer improves the next shot.

### Alternatives

- Bumper-value route

When

Use this plan when both saucer kickouts and the current rollunder are unreliable.

Steps

- Hit a rollunder only when its broad gate is naturally presented.

- Use that gate to light the bumper above it for 10.

- Let the always-10 center bumper and newly lit bumper provide incidental value.

- Resume the ordered sequence after the ball reaches a controlled flipper.

### Builds Toward

High-value 100x Roto collect

Steps

- Complete the lit A-E sequence for 10x.

- Complete it again for the rollunder's 100x value.

- Read the Roto value under the next reachable gate.

- Wait for a controlled shot at a favorable value.

- Score the 100x gate and begin rebuilding after its reset.

### Techniques

- Lit-letter discipline

Instruction

Read the illuminated A-E letter before every aimed gate shot. Ignore unlit rollunders until the required letter advances.

### Cautions

- Issue

Only the required A-E rollunder advances the ordered sequence.

Response

Read the lit letter before shooting. Use the lit saucer rather than forcing an unlit gate.

- Issue

The first rollunder after 100x spends the built value and resets the base to 1.

Response

### Overview

Complete the sequence twice for 100x, compare the visible windows, and take the best survivable lit gate for the cashout. Use the currently lit side saucer while the ordered gate is unavailable rather than breaking control.
