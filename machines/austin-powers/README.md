## Simple strategy

### Summary Title

The goal

### Summary

Prepare Mini-Me Hurryup or Sub-Drill, then start Fat Bastard Multiball so four-ball play protects its repeated shots. Start all six main modes for Virtucon Multiball and complete all six for Moonbase Multiball.

### Steps

- Use the opening save to test the toilet ramp, Mini-Me spinner, Time Machine, outer ramps, loops, Dr. Evil target, and their returns.

- Shoot the toilet ramp three times, leaving Fat Bastard Multiball one shot from starting.

- Start Mini-Me Hurryup at the spinner or Sub-Drill by completing both outer ramps four times within its timer.

- Shoot the toilet ramp again to start Fat Bastard Multiball. Make each of the six major shots four times; the fourth hit on each scores its Super Jackpot.

Details

- Fat Bastard Multiball: The fourth toilet-ramp shot starts four-ball play with a generous ball save. Each major shot needs four hits to finish the mode.

- Mode stack: Mini-Me and Sub-Drill can remain active during this multiball, and their timers pause while multiball runs.

- After multiball, start the remaining main modes from the safest major shots. Finish a mode until its five inserts are solid before treating it as complete.

- After all six modes have started, play Virtucon Multiball. Repeat completed-mode shots for double jackpots; complete the normal six-shot set to relight it.

- Complete all six main modes to light Moonbase Multiball.

### Alternatives

- Mojo Multiball

When

Use this when the MOJO standups and Dr. Evil target are safer than either ramp multiball route.

Steps

- Spell MOJO at the two left standups to start two-ball play.

- Hit Dr. Evil ten times to lower him and light the six major shots.

- Clear the six shots, then shoot the Time Machine for the Super Jackpot.

- Repeat the Dr. Evil and six-shot cycle while two balls remain.

- Start Moonbase Multiball after all six modes are complete.

### Cautions

- Issue

Each main mode has specific completion rules that can be missed if only its start shot is repeated.

Response

Read the lit objectives and finish the current mode before qualifying another route.

Source Url

[Source](https://pinball.org/rules/austinpowers.html)

- Issue

No new main mode can start during a multiball.

Response

Start Mini-Me or Sub-Drill before Fat Bastard; do not leave an unstarted mode one shot away and expect to add it during multiball.

Source Url

[Source](https://pinball.org/rules/austinpowers.html)

- Issue

A completed Time Machine mode no longer provides its single-ball scoring save.

Response

Treat later Time Machine shots as normal dangerous ramp shots and do not expect an automatic relaunch.

Source Url

[Source](https://pinball.org/rules/austinpowers.html)

- Issue

Mini-Me, Time Machine, and left-ramp switches can fail to register cleanly.

Response

Watch the inserts and display for confirmed progress instead of assuming that every physical shot counted.

### Simple Overview

Austin Powers cannot start a new main mode during Multiball. Leave Fat Bastard one toilet-ramp shot from starting, begin Mini-Me Hurryup or Sub-Drill first, then shoot the toilet ramp and use four-ball play to finish the running mode.

### Overview

Starting all six main modes lights Virtucon Multiball in Austin Powers; completing all six lights Moonbase Multiball. Prepare Fat Bastard, start Mini-Me or Sub-Drill before it, then use four-ball play for the six major-shot sets. Finish the remaining modes from their safest starts, and use Time Machine or Mojo when either qualification is already close.
