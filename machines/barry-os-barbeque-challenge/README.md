Complete the orange recipe shots for a cook-off, use a saucer lock and the upper-right saucer for Pitmaster Multiball, and repeat the right ramp for playfield X.

### Steps

Mode Guide

The opening cook-off

Reason

The orange recipe shots show the complete opening objective without requiring a separate selection menu.

Play

Shoot the orange recipe shots. When they are complete, shoot any open saucer to cash the trophy.

## Full strategy

### Summary

Cash a safe cook-off trophy. Bank a large Pitmaster jackpot, keep F-I-R-E ready as protection, raise playfield X, and start Pitmaster Multiball.

### Steps

- Choose the right-ramp skill shot when you can make it. It increases the time for each playfield multiplier level.

Mode Notes

- Skill-shot power: Each skill shot gives a permanent game power. The right-ramp power extends the playfield-X timer.

- In the first cook-off, complete the orange recipe shots. Build extra stars only from controlled shots.

Mode Notes

- Cook-off: Orange shots complete the main recipe. Spinner sauce, the correct Mild or Spicy target, and two sets of side-dish targets can add four more stars.

- Recipe value: Switches and features build the current cook-off value. Orange recipe shots also add this value to the next Pitmaster jackpot base.

- After the orange shots are complete, shoot any open saucer to cash the trophy. Cash three or more stars unless the ball is fully controlled.

Mode Notes

- Trophy cash-out: The saucer ends the cook-off. Each earned star adds 1x to the cook-off value.

- Use the left ramp, top lanes, and safe recipe shots to build the next Pitmaster base. Bank useful value before you take a high-risk shot.

- Complete F-I-R-E until one lane remains. Keep that lane ready as an outlane save.

Mode Notes

- F-I-R-E protection: If an outlane completes the word, the game saves the ball.

- F-I-R-E hurry-up: If an inlane completes the word, shoot the flashing blue orbit. A collect scores the value and adds it to the recipe. A timeout cuts the recipe value in half.

- Lock at least one ball in the left or lower-right saucer. If a challenge is already qualified, start it at an open saucer before Pitmaster.

- Shoot the right ramp while the ball is controlled. Each shot adds 0.5x playfield scoring, up to 4x.

Mode Notes

- Playfield X: Each level runs for about 30 seconds. The right-ramp skill-shot power extends this time.

- Shoot the upper-right saucer to start Pitmaster Multiball. Shoot a lit red jackpot, then move balls between different saucers for larger awards.

Mode Notes

- Pitmaster Multiball: It starts with the Pitmaster base that you banked before the multiball. Normal jackpots advance from 1x to 1.5x, 2x, and higher ladder values.

- Super Jackpot: Lock one ball in a saucer. Lock another ball in a different saucer before the timer ends. The award advances the ladder by two steps.

- Mega Jackpot: Lock balls in all three saucers within the sequence. The award advances the ladder by four steps.

- During Pitmaster, keep shooting the right ramp when it is safe. Use the larger playfield X on Super and Mega Jackpots. Shoot the upper-right saucer when jackpots need to relight.

### Quick Info

- Combomania and Multiball

Summary

Start Combomania before Multiball if you want both running. A running Combomania continues into Multiball, but it cannot be started after Multiball begins.

### Fallback

Side Dish Multiball

When

Use this plan when the Pitmaster saucers or right ramp reject the ball.

Steps

- Complete the drop-target bank until all three cycling Side Dish inserts are collected.

Mode Notes

- Side Dish Multiball: The third Side Dish award starts the multiball. Red shots score jackpots.

- Shoot red jackpots. Switch hits raise their value.

- Complete the drop-target bank to relight all jackpots. If none is lit, one jackpot moves between shots.

- Use the right ramp to add playfield X only when its return is safe.

### Alternatives

- Aggressive F-I-R-E build

When

Use this plan when both blue orbits are repeatable and you need a larger Pitmaster base.

Steps

- Complete F-I-R-E through an inlane to start the orbit hurry-up.

- Shoot the flashing blue orbit before time expires. The collect adds the value to the current recipe.

- Repeat F-I-R-E to raise its multiplier by 0.5x, up to 5x.

- Stop this plan if the orbit is not repeatable. A failed hurry-up cuts the recipe value in half.

- Challenge stack

When

Use this plan when orbit progress has qualified a challenge before Pitmaster or Side Dish starts.

Steps

- Shoot purple shots to build the next challenge value. Start the challenge at an open saucer.

Mode Notes

- Challenge: Each challenge gives a timed shot task. Only one challenge can run, but it can run during a multiball.

- Start Pitmaster or Side Dish while the challenge runs.

- Use the multiball to make the purple or challenge shots. Do not risk a drain only to prebuild more value.

### Builds Toward

Meat Coma

Steps

- Win three cook-offs to start Meat Coma.

- In Meat Coma, complete the six red shot areas. Then shoot any saucer for the jackpot.

Mode Notes

- Meat Coma: It starts as multiball. The first three completed jackpot rounds add a ball. If play reaches one ball, a 20-second timer starts.

- Repeat the red shots and saucer. Spend an available add-a-ball before the single-ball timer ends.

### Cautions

- Issue

A hard saucer shot can reject and return without starting or locking the feature.

Response

Test the three saucers early. Use a softer shot on a saucer that rejects hard entries.

Source Url

[Source](https://www.youtube.com/watch?v=A6HGPFbJ1oI&t=5815s)

- Issue

A drain removes the unbanked recipe value.

Response

Complete the orange recipe or add its value to Pitmaster before you take a high-risk shot. Banked Pitmaster value remains after a drain.

Source Url

[Source](https://www.youtube.com/watch?v=A6HGPFbJ1oI&t=662s)

- Issue

A failed F-I-R-E hurry-up cuts the current recipe value in half.

Response

Leave one F-I-R-E lane ready for an outlane save when the blue orbit is not repeatable.

### Simple Overview

In Barry O's Barbeque Challenge, orange recipe shots complete the active cook-off and an open saucer cashes its trophy. Lock a ball in a saucer, then shoot the upper-right saucer to start Pitmaster Multiball. Repeated right-ramp shots raise playfield X for the larger Pitmaster awards.

### Overview

In Barry O's Barbeque Challenge, orange recipe shots build the Pitmaster Jackpot base, and an open saucer cashes the cook-off trophy. Complete a safe cook-off, keep one F-I-R-E lane ready for an outlane save, lock a ball in a saucer, and repeat the right ramp for playfield X. Start Pitmaster at the upper-right saucer and use the multiplier on its larger Super and Mega Jackpots.
