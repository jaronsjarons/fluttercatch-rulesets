## Simple strategy

### Summary Title

The goal

### Summary

Use the Stage entrance for a mode, the right inner loop for Trunk Multiball, and the Milkcan loop-to-ramp combo for playfield X.

### Steps

- Start a Stage mode

Hit the stage curtain four times, make a clean Stage Alley shot, or shoot the Key Lane and hit the red Key Target to open the curtain. Then shoot the Stage to start the selected mode.

- Start Trunk Multiball

Shoot the right inner loop for the first lit lock. After each lock, shoot Stage Alley to light the next one, then shoot the right inner loop again. The third lock starts Trunk Multiball.

- Start Milkcan playfield X

Shoot the Milkcan loop, then complete the lit ramp while the multiplier is available. Use this only when both returns are controlled.

## Full strategy

### Summary

Start a controllable Stage Mode or Movie Mode before Trunk and Seance Multiball, use the overlap for HOUDINI letters, and activate the Milkcan playfield multiplier only from a controlled Milkcan-loop-to-ramp combo.

### Quick Info

- Master Magician

Summary

Seven HOUDINI letters track Stage modes, Movies, Magic Shop items, Jail Escapes, Secret Missions, and jackpot goals in both major multiballs.

- Stage Mode

Summary

Hit the stage curtain four times, make a clean Stage Alley shot, or shoot the Key Lane and hit the red Key Target to open the curtain. Shoot the Stage to start the mode; a clean Stage Alley entry starts it at 2x.

- Mode order

Summary

A Stage Mode and Movie Mode cannot run together and must start before a multiball to overlap it.

- Trunk Multiball

Summary

Use the right inner loop for locks, make the required jackpot shots, then return to the trunk for the Super Jackpot.

- Seance Multiball

Summary

Spell SEANCE, then complete the ordered jackpot sequence toward its Super Jackpot.

- Milkcan multiplier

Summary

A Milkcan loop followed by the ramp starts or raises a timed 2x, 3x, or 4x playfield-scoring multiplier.

### Steps

- Hit the stage curtain four times, make a clean Stage Alley shot, or shoot the Key Lane and hit the red Key Target to open the curtain. Shoot the Stage to start the selected mode.

- Select a Stage Mode or Movie Mode whose marked shots remain accessible during Multiball, then start it before any Multiball. A clean Stage Alley entry starts a Stage Mode at 2x.

- While the mode is active, complete its marked shots and use orbit shots for added Stage time when needed.

- Start Trunk or Seance Multiball, then add the other if it is ready.

- During Trunk Multiball, collect the lit jackpot shots and return to the trunk for the Super Jackpot; secure at least three Trunk jackpots for its HOUDINI letter.

- During Seance Multiball, follow the lit sequence and collect at least two jackpots for its HOUDINI letter.

- Use the Milkcan loop-to-ramp playfield multiplier only when both shots feed safely, then place the remaining mode and multiball shots inside that window.

### Builds Toward

Master Magician

Steps

- Complete each of the ten Stage Mode features and five Movie Mode features.

- Collect eight Magic Shop items.

- Complete five Jail Escapes and five Secret Missions.

- Collect three Trunk Multiball jackpots and two Seance Multiball jackpots.

- Use the seven completed objectives to enter Master Magician.

### Simple Overview

A Stage mode can continue into Multiball, but it must start first. Hit the curtain four times, make a clean Stage Alley shot, or complete the Key Lane and red Key Target to open the curtain. Shoot the Stage before Multiball because a mode cannot be added afterward; the right inner loop builds Trunk Multiball, and the Milkcan loop-to-ramp combo starts playfield X.

### Overview

Shoot the Stage before Trunk or Seance Multiball because modes cannot be added after Multiball starts; use the Milkcan loop-to-ramp combo when the active shots are ready for playfield X.
