## Simple strategy

### Summary Title

The goal

### Summary

Collect items through a standup target or the captive ball and the raised wall scoop. Every shot displays its point value; Multiball keeps those values and has no Jackpots.

### Steps

- How to collect an item

Hit any one of the four standup targets or the captive ball. One wall scoop rises at random; shoot that scoop to collect the offered item.

- How scoring is shown

Read the point value displayed at each shot. Making that shot scores the displayed value.

- How Multiball works

Some items lock balls or start an instant Multiball. During Multiball, continue shooting the displayed values; there are no Jackpots or Super Jackpots.

### Steps

- Hit any one of the four standup targets or the captive ball. One wall scoop rises at random.

- Shoot the raised wall scoop to collect the offered item. Each item can help, hinder, change scoring, lock balls, or start an instant Multiball.

- Read the point value displayed at each shot. Making that shot scores the displayed value.

- If an item starts Multiball, continue shooting the displayed values. There are no Jackpots or Super Jackpots.

### Simple Overview

Ranger in the Ruins is an item-collection game. Hit one of the four standup targets or the captive ball to raise a random wall scoop, then shoot that scoop to collect its item. If an item starts Multiball, keep shooting the displayed values because Multiball does not add Jackpots.
