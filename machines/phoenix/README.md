## Simple strategy

### Summary Title

The goal

### Summary

Use the top lanes to build base bonus and PHOENIX progress, complete either four-bank until Bonus X reaches 5x, then shoot the bullseye only after its rebound is safe.

### Steps

- On ball one, plunge for top lane 1. On later plunges, choose a missing 1-through-5 lane.

- Send the ball to the top. Use the lanes to build base bonus and advance the 1-through-5 set.

- Complete the safer four-bank. Repeat bank completions until Bonus X reaches 5x.

- Shoot the left spinner while base bonus is from 10,000 through 20,000.

- Use the A and B center targets for 10,000 only from a controlled feed. Relight A with top lane 2 or the left return lane.

- Relight B with top lane 4 or the right return lane. Shoot the PHOENIX bullseye only after its rebound is known.

### Quick Info

- Bonus

Summary

Lanes and targets build base bonus to 29,000, and 5x Bonus produces a maximum 145,000 collect.

- Bonus X

Summary

Each completion of either four-bank advances Bonus X toward 5x.

- A and B targets

Summary

Each center target scores 10,000 and one bonus advance, then remains down until its matching lane relights it.

### Fallback

Alternative route: A-B and lit spinner

When

Use this when drop-bank or bullseye rebounds are not safe.

Steps

- Collect A or B from a controlled flipper for 10,000 and one bonus advance.

- Return the ball to the top to relight the collected target.

- Use the left spinner while base bonus is in its lit range.

- Protect the built bonus instead of forcing the four-banks.

### Warning

The PHOENIX bullseye can return directly toward the center drain.

Test the rebound before you build around this shot. Use top play if the return is not controlled.

### Alternatives

- PHOENIX bullseye route

When

Use this only when the bullseye rebound is safe on this machine.

Steps

- Complete the 1-through-5 lanes to add one PHOENIX letter.

- Repeat the lane set to raise the displayed bullseye value.

- Shoot the bullseye from control.

- Stop if its rebound reaches the center or an outlane.

### Builds Toward

5x Bonus and a raised bullseye

Steps

- Score top lanes, return lanes, and targets until base bonus reaches 29,000.

- Complete either four-bank until Bonus X reaches 5x.

- Complete 1-through-5 sets to add PHOENIX letters.

- Shoot the bullseye to collect its displayed PHOENIX value only when the return is controlled.

### Simple Overview

Phoenix builds a 29,000 base bonus through lanes and targets, while either four-bank advances Bonus X to 5x. Build both values, use the 1-through-5 lanes to add P-H-O-E-N-I-X letters, and shoot the bullseye only after its return is proven.

### Overview

Phoenix builds a 29,000 base bonus through lanes and targets, while either four-bank advances Bonus X to 5x. Build base and multiplier together, using the A and B targets when they are relit by their matching lanes. Add letters through complete 1-through-5 sets, then convert the bullseye value only from a controlled angle and preserve the 145,000 end-of-ball bonus.
