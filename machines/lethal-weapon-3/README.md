## Simple strategy

### Summary Title

The goal

### Summary

Complete either drop bank and shoot the upper VUK for Lotsaballs, then repeat the left-ramp Jackpot and saucer relight.

### Steps

- Start Lotsaballs

Complete either three-target drop bank, then shoot the upper VUK to start Lotsaballs.

- Repeat the Jackpot

During Lotsaballs, shoot the left ramp for a Jackpot and shoot any saucer to relight it. Repeat while the ramp returns cleanly.

- Try the larger awards

With both balls controlled, send both up the left ramp within the timer for a Double Jackpot. Use the left orbit and subway pair for a Quadruple Jackpot only when both returns are controlled.

## Full strategy

### Summary

Repeat both orbits to build all six Uzi bullets, then win the Shoot Out with the launch trigger. Complete one drop bank for Lotsaballs, start it at the upper VUK, collect the left-ramp Jackpot, and use a saucer to relight it.

### Quick Info

Summary

- Lotsaballs Jackpot

Summary

- Freeway

Summary

Repeat the left ramp for increasing Millions and a possible extra-ball light, with later Looping making each timed repeat worth 10M.

- Shoot Out

Summary

Build six Uzi bullets with both orbits, then use the launch trigger during the DMD duel while the live ball remains in play.

- Stunts during Lotsaballs

Summary

Stunt progress continues during Multiball: completing all three saucers awards the current Stunt, but its display animation is skipped.

### Steps

- Test both orbit returns, the left-ramp return, and the VUK-hole release before committing to a repeatable shot.

- Repeat the safer left and right orbits to light Uzi bullets. Complete both orbits once for each bullet.

Mode Notes

- Shoot Out: Six bullets start the DMD duel. Pull the launch trigger before the opponent fires while keeping the live playfield ball under control.

- The third Shoot Out lights Super Spinners. The sixth starts Looping, which makes timed left-ramp repeats worth 10,000,000.

- While the orbit route is under control, complete either three-target drop bank to qualify Lotsaballs.

- Shoot the upper VUK to start Lotsaballs.

Mode Notes

- Lotsaballs qualification: Complete either three-target bank. The upper VUK then starts multiball. The other bank can qualify another start.

- During Lotsaballs, shoot the left ramp for a Jackpot. Shoot any saucer to relight it.

Mode Notes

- Lotsaballs Jackpot: The left ramp collects the lit Jackpot. The left, center, or right saucer relights it.

- Completing all three saucers during Multiball also awards the current Stunt without showing its animation.

- When two balls are controlled, send both up the left ramp within the award window for a Double Jackpot.

- For the larger award, send two balls through the left orbit and subway within the award window for a Quadruple Jackpot.

- If ball separation breaks down, collect one safe Jackpot and use a saucer relight. Do not force the two-ball combo.

### Fallback

Freeway repeats

When

Use this when the drop banks, VUK, or two-ball timing is unsafe.

Steps

- Trap on the right flipper.

- Repeat the left Freeway ramp.

- Collect its increasing Millions and extra-ball progress when enabled.

- If Looping is active, continue the ramp before its timer ends.

### Alternatives

- Shoot Out ladder

When

Use this when both orbits are safer than the drop banks and ramp.

Steps

- Complete both left and right orbits to light an Uzi bullet.

- Repeat until all six bullets are lit.

- During Shoot Out, use the launch trigger to fire before the opponent fires. Continue to control the live playfield ball.

Mode Notes

- Shoot Out: The DMD presents an opponent. A later trigger press can score more, but waiting too long loses the duel. The playfield ball does not stop.

- Repeat Shoot Outs to advance the fixed award ladder toward Super Lethal Weapon.

- Unlimited Millions

When

Use this when the center bank and colored wire targets are under control.

Steps

- Hit the center target on either drop bank to start Red Wire or Blue Wire.

- Hit the matching colored wire target.

- Repeat the lower-left target while Unlimited Millions is active.

### Builds Toward

Super Lethal Weapon

Steps

- Complete both orbits repeatedly to build all six Uzi bullets.

- Win each Shoot Out with the launch trigger while you protect the live ball.

- Advance through the six earlier Shoot Out awards.

- Win the seventh Shoot Out to collect Super Lethal Weapon.

- Issue

Saucer relights can eject into an uncontrolled feed.

Response

Watch one eject before relying on repeated Jackpot relights. Use the saucer with the cleanest return on this copy.

- Issue

The playfield ball stays live during Shoot Out while the DMD asks for a launch-trigger decision.

Response

Trap the ball before the duel when possible. Keep your eyes on the playfield between trigger presses.

### Simple Overview

Lethal Weapon 3 uses either three-target bank and the upper VUK to start Lotsaballs. Complete a bank, start Multiball, shoot the left ramp for Jackpot, and use any saucer to relight it. Orbit shots build Uzi bullets for Shoot Out.

### Overview

Lethal Weapon 3 uses either three-target bank and the upper VUK to start Lotsaballs. Complete a bank and shoot the upper VUK, then alternate the left ramp with any saucer while multiple balls protect the route. Between Multiballs, repeat both orbits for six Uzi bullets and use the launch trigger during each DMD duel without losing the live ball.
