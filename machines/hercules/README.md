## Simple strategy

### Summary Title

The goal

### Summary

Complete all three top lanes, use full Path of Victory orbits to collect Double Bonus and useful awards, unlock each Base Bonus threshold, then switch to the raised left spinner.

### Steps

- Plunge and watch the oversized cue ball's spin before the first flipper shot.

- Complete all three top lanes to activate the yellow, orange, and red award paths.

- Transfer to the left flipper and shoot the complete right-to-left Path of Victory.

Details

- Path of Victory: The ball must operate both orbit rollovers without touching another switch; a weak shot that falls into the bumpers does not count.

- Repeat the Path until all three yellow lights under Double Bonus are lit, then make one more full Path to earn Double Bonus.

- Continue toward Extra Ball or Special only when the tournament setting gives those awards useful value.

- Build Base Bonus with top lanes, pad targets, and return lanes. Hit the flashing pad at each 10,000 threshold.

Details

- Base Bonus: A flashing threshold pad scores the current stored value and unlocks more progress without removing the bonus.

- Protect the prepared 2x end-of-ball bonus, which can pay up to 98,000.

- After useful Path awards are complete, finish top-lane sets and shoot the left spinner at 1,000 or more per spin.

### Quick Info

- Path of Victory

Summary

A complete right-to-left orbit must operate both rollovers without another switch and advances every active award path.

- Base Bonus

Summary

Bonus stops at each 10,000 threshold until its matching flashing pad is hit.

- Double Bonus

Summary

Complete three full Paths of Victory to light the three yellow Double Bonus lamps, then complete one more full Path for 2x end-of-ball bonus on that ball.

### Fallback

Alternative route: Recovery: Base Bonus and Double Bonus

When

Recovery pivot: Use this when the full Path of Victory does not validate reliably.

Steps

- Complete the left yellow top lane.

- Use successful full Path shots only to advance the yellow path.

- Build Base Bonus with safer lanes and pad targets.

- Hit each flashing threshold pad before adding more bonus.

- If the yellow path becomes ready, attempt one full Path and collect Double Bonus.

### Alternatives

- Position play: High-value spinner

When

When trailing, use this higher-ceiling route: use this after useful Path awards are complete.

Steps

- Complete one top-lane set for a 1,000 spinner.

- Complete more sets for 2,000 and 3,000 per spin.

- Shoot the left spinner from the right flipper.

- Do not collect another Path award because it resets the spinner to 100.

- Extra Ball path

When

Use this only when Extra Balls are enabled or compensated.

Steps

- Complete the center top lane to activate the orange path.

- Build five orange steps with the lane and full Path shots.

- Use a full Path for the final step, then collect either lit inlane.

### Builds Toward

Maximum bonus and a 3,000 spinner

Steps

- Collect Double Bonus from the yellow path.

- Unlock Base Bonus at 10,000, 20,000, 30,000, and 40,000.

- Continue to 49,000 Base Bonus.

- Complete three top-lane sets for a 3,000 spinner.

- Shoot the spinner and protect up to 98,000 drain bonus.
