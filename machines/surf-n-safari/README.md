## Simple strategy

### Summary Title

The goal

### Summary

Advance the Bonus Grid to light the Pipeline lock, lock the ball, make the Plunge skill shot for three-ball Multiball, complete two lit shots for the Rapids Jackpot, then complete all five shots and return to Rapids for the Super Jackpot.

### Steps

- Use a gentle plunge to enter the Plunge saucer. Watch the Rapids return to the right flipper.

- Hit Pipeline, Rapids, Boomerang, all three Splash targets, and Whirlpool to advance their Bonus Grid columns. A lit inlane can advance one random column.

- Complete the bottom three grid rows or the Rapids column. Shoot the Pipeline when Lock is lit.

Details

- Multiball qualification: The third row lights the Pipeline lock. The Rapids column lights it as a timed hurry-up.

- After the Pipeline lock, make the gentle Plunge skill shot to start three-ball Multiball. A miss starts two-ball play.

- If Pipeline and Plunge awards complete D-O-U-B-L-E before the lock, start Multiball while rest-of-ball Double Round is active so its Jackpots and Super Jackpots score twice.

- Shoot the two random lit major shots. Then shoot the Rapids for the Jackpot.

Details

- Jackpot phase: Two of Pipeline, Rapids, Boomerang, Whirlpool, and Arcade light first. Their completion lights the Rapids Jackpot.

- After the Jackpot, complete all five lit major shots. Shoot the Rapids for the Super Jackpot.

- Repeat the five-shot cycle and Rapids Super Jackpot while at least two balls remain.

### Techniques

- Plunge saucer skill shot

Instruction

Plunge gently so the ball enters the Plunge saucer. A hard plunge enters the pop bumpers instead.

### Cautions

- Issue

The Souvenirs and Arcade targets are spring-loaded and return the ball with force.

Response

Use them only when the grid or award value justifies the rebound. Keep both flippers ready.

Source Url

[Source](https://pinball.org/rules/surfnsafari.html)

- Issue

The Rapids-column Multiball light is a hurry-up and can expire.

Response

Do not complete the column until the Pipeline shot is ready. Use the row-based lock when timing is safer.

Source Url

[Source](https://pinball.org/rules/surfnsafari.html)

### Simple Overview

Surf 'n Safari uses five slide shots to fill a Bonus Grid and light the Pipeline lock. Complete the bottom rows or Rapids column, lock at Pipeline, then make the gentle Plunge skill shot for three-ball Multiball and complete all five lit shots before returning to Rapids for the Super Jackpot.

### Overview

Surf 'n Safari uses five slide shots to fill a Bonus Grid and light the Pipeline lock. Build the lock through the bottom rows or Rapids column, then start three-ball play and complete two lit shots for the Jackpot. Finish all five major shots and return to Rapids for the 30M Super Jackpot.

Label

Tournament 4E10

Differences

Changes

- With Tournament Mode set to YES, the top skill-shot saucer always scores 500K and outlanes score 100K instead of random awards.

- With Tournament Mode set to NO, those awards use their original behavior.

Strategy

Summary

Surf 'n Safari, Tournament 4E10

Step Format

feature-guide

Steps

- Hit Pipeline, Rapids, Boomerang, all three Splash targets, and Whirlpool to advance their Bonus Grid columns. Complete the bottom three rows or the Rapids column to light the Pipeline lock; the column award is timed.

- Shoot the lit Pipeline lock. Make the gentle Plunge skill shot to start three-ball multiball; a miss starts two-ball play.

- During multiball, complete the two lit major shots, then shoot Rapids for the Jackpot. Complete all five lit major shots and return to Rapids for the Super Jackpot. Repeat that five-shot cycle while at least two balls remain.

Check Before Play

- These changes require Tournament Mode set to YES. With it set to NO, the saucer and outlanes use their original behavior.
