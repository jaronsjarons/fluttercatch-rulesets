## Simple strategy

### Summary Title

The goal

### Summary

Build the base bonus to 20,000 through the top lanes and Advance buttons. Complete targets 1 through 4, then repeat the spinner at 1,000 while its return remains safe.

### Steps

- Before the plunge, read the lit top lane and the current base bonus.

- Plunge across both Advance buttons when possible, then guide the ball through the lit top lane.

- During single-ball play, send controlled shots to the top to collect more bonus advances.

- Build the base bonus to 20,000 before you accept repeated drop-target risk.

- Read targets 1 through 4 and shoot only the missing targets from controlled flipper positions.

- After the bank is complete, confirm that the spinner now scores 1,000.

- Repeat the spinner while the entry avoids the bumper behind it and the return stays controlled.

- If the spinner return becomes unsafe, go back to broad upper-playfield shots.

### Quick Info

- Base bonus

Summary

The lit top lane and the two Advance rollover buttons build base bonus to 20,000.

- Spinner value

Summary

Completing drop targets 1 through 4 raises the spinner from 100 to 1,000.

- Drop-bank award

Summary

Completing targets 1 through 4 also lights both outlanes for Extra Ball when that award is enabled.

### Fallback

Alternative route: Bonus-only upper play

When

Use this plan when the drop targets or spinner send the ball toward the center drain.

Steps

- Stop shooting the unsafe feature.

- Read which top lane is lit.

- Send the ball to the top through the broadest available path.

- Use the Advance buttons and lit lane to build base bonus.

- Return to the main route only after you have a controlled target or spinner angle.

### Warning

A poor exit from the top can travel directly toward the center drain.

Track the full upper exit and use one early legal nudge before the ball gains speed toward the center.

### Alternatives

- Enabled Extra Ball route

When

Use this plan only when the lit-outlane award has tournament value.

Steps

- Confirm how Extra Ball is handled before the game starts.

- Build base bonus through the top while you wait for controlled drop-target shots.

- Complete targets 1 through 4 to light both outlanes.

- Do not aim at an outlane after it lights.

- Collect the award only through natural play, then use the 1,000-point spinner.

### Builds Toward

20,000 bonus and the 1,000-point spinner

Steps

- Use the Advance buttons and lit top lane to reach 20,000 base bonus.

- Complete missing targets from 1 through 4.

- Confirm that the spinner value has increased to 1,000.

- Repeat the spinner only while its feed remains controlled.

- Take the double-bonus ball when the current ball number allows it.

### Techniques

Instruction

Set the plunge so the ball crosses both Advance buttons before it enters the currently lit top lane.

### Cautions

- Issue

A straight spinner shot can hit the underside of the bumper behind it and return down the middle.

Response

Test the spinner angle once and abandon the repeat if the ball does not pass the bumper cleanly.

Targets 3 and 4 can produce dangerous rebounds when they are the last targets needed.

Response

### Overview

Sky Rider / Hi-Flyer raises base bonus through the lit top lane and two Advance buttons, then turns the spinner from 100 to 1,000 by completing targets 1 through 4. Use plunges and upper feeds for the lit lane and Advance buttons, then complete targets 1 through 4 after the bonus is secure. Repeat the 1,000 spinner only while the bumper behind it and the lower return remain predictable.
