## Simple strategy

### Summary Title

The goal

### Summary

Shoot either vertical spinner whenever a clean entry is available and hope it stops on 500. That single result dwarfs ordinary scoring, so preserve the ball and prefer upper exits through a spinner or side lane.

### Steps

- Observe which vertical spinner has the cleaner entry and safer return on this copy.

- When the ball reaches a controlled flipper, shoot the reachable spinner instead of a 50-point standup.

- Let the spinner stop completely and read its 5, 50, or 500 value.

- Prepare both flippers while the ball moves through the upper bumpers.

- Favor exits through either spinner or an upper side lane over raw bumper exits.

- If the ball returns safely, set up the cleaner spinner again.

- Use ordinary lanes and targets only when reached naturally or when no spinner entry is available.

- Repeat the survival-and-spinner plan for every ball, regardless of the previous stop value.

### Quick Info

When

Use this plan when neither spinner can be reached from a controlled angle.

Steps

- Take a natural 50-point side lane or standup only when it preserves an upper path.

### Alternatives

- Copy-specific spinner selection

When

Use this plan when one spinner consistently returns more safely than the other.

Steps

- Test each spinner once from a controlled flipper.

- Compare whether the exits reach a flipper, sling underside, or center.

- Choose the spinner with the safer return even if the other is easier to hit.

- Repeat only while that return remains predictable.

### Builds Toward

Repeated chances at 500

Steps

- Preserve control rather than chasing low-value targets.

- Enter a vertical spinner cleanly.

- Accept the stop value without changing the next decision.

- Use spinner and side-lane exits to survive upper play.

- Create another controlled spinner attempt.

### Cautions

Response

### Simple Overview

Fun Land / Fun Park is dominated by two vertical spinners that stop on 5, 50, or 500 rather than scoring every revolution. Shoot the spinner with the cleaner entry, prepare for its bumper exit, and repeat whenever the ball returns safely; ordinary lanes and standups are secondary.

### Overview

Fun Land / Fun Park is a high-variance spinner game in which a 500 stop outweighs routine scoring. Improve access and survival by choosing the cleaner spinner, favoring upper exits through a spinner or side lane, and resetting control after each return. The stop value is random, so do not change a safe route after a low result.
