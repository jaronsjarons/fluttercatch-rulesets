## Simple strategy

### Summary Title

The goal

### Summary

Build W-A-R and one color bank, start Two-Ball Multiball at its base, relock both balls in different bases, then hit all nine color targets before collecting Ion Cannon at the ramp.

### Steps

- Plunge through an unlit W, A, or R lane. Use the right flipper to move the lit letters before the ball commits.

- Complete W-A-R to advance Bonus X toward 5x.

Details

- W-A-R: W adds 2,000 to red, A adds 2,000 to yellow, and R adds 2,000 to blue.

- Watch one full pop-bumper exit. Choose the color bank with the safest standup returns.

- Complete all three targets in one color. Shoot that color's lit base and plunge the served ball.

Details

- Two-Ball Multiball: The base holds the first ball; the replacement plunge releases it and starts two-ball play.

- Lock the first ball in any base. Send the second ball to a different base before the first ball ejects.

Details

- Two-base relock: Both balls must be held in different bases to qualify the next phase.

- After both balls are held, plunge the served ball to release them and start Three-Ball Multiball.

Details

- Three-Ball Multiball: The objective stays active until one ball remains.

- Hit all nine red, yellow, and blue targets before you shoot the ramp.

Details

- Ion Cannon Jackpot: Each color target adds 100,000, so all nine targets build the collect to 1,000,000.

- Shoot the ramp to collect Ion Cannon. After one ball remains, resume Bonus X and color-bonus play.

Recovery pivot: Use this when the two-base relock is unreliable.

### Alternatives

- Position play: Ramp multiplier loop

When

When trailing, use this higher-ceiling route: use this when the ramp is repeatable in single-ball play.

Steps

- Shoot the ramp once and confirm that the Ramp Multiplier lamp is lit.

- Repeat the ramp while the Ramp Multiplier lamp remains lit to add 1x.

- Continue to the 5x ramp-value maximum while the lamp and feed remain safe.

- When multiball starts, change to the Ion Cannon target-and-ramp route.

- Base-number awards

When

Use this when all three base lanes return safely.

Steps

- Shoot all three bases with number 1 flashing, then collect 100,000 at the ramp.

- Shoot all three bases with number 2 flashing, then collect Hold Bonuses at the ramp.

- The number 3 set lights Extra Ball; its tournament value depends on settings.

### Builds Toward

Maximum Ion Cannon and bonus

Steps

- Start Three-Ball Multiball.

- Hit all nine color targets before the ramp.

- Collect the 1,000,000 Ion Cannon Jackpot.

- Hit each color's three targets, matching W-A-R top lane, and base until all three color bonuses reach 31,000. Complete W-A-R until Bonus X reaches 5x.

- Test each base eject, ramp entrance and wireform return, pop exits, target rebounds, tilt sensitivity, and flipper strength.

### Simple Overview

Completing one red, green, or blue target bank in Laser War lights that color's base for two-ball play. Relock the two active balls in different bases to start three-ball Multiball. Complete W-A-R to raise Bonus X, then hit all nine color targets before shooting the ramp for Ion Cannon.

### Overview

Completing one red, green, or blue target bank in Laser War lights that color's base for two-ball play. Complete one color and start two-ball play, store both balls in different bases, then release them for three-ball Multiball. Hit all nine color targets before the ramp to build the full Ion Cannon collect.
