## Full strategy

### Summary

Use the left orbit and the upper-right flipper to keep the ball up top, repeatedly complete the upper three-bank, and let the X-O card build from incidental standup hits.

### Steps

- Short-plunge below the shooter-lane switch before the timed skill shot expires for 100,000.

- From the lower flippers, shoot the outer-left orbit or feed the upper-right flipper.

- Use the upper-right flipper to complete the upper three-bank. Each completion raises both the bank and outer-left-lane values.

- Let standup hits fill the X-O card. If one symbol already dominates the card, time later target hits so they keep that same symbol.

- Repeat the upper-playfield route. The completed card and any three-in-a-row bonuses carry between balls.

Response
