## Simple strategy

### Summary Title

The goal

### Summary

In the Hub, prepare Test Chambers and three stackable Multiballs. Hit the Elevator Call Button and Elevator Scoop for a chamber. For the full Multiball stack, collect three Turret locks and start Turret first, then add Aerial Faith Plate and Edgeless Safety Cube.

### Steps

- In the Hub, hit the Elevator Call Button standup and shoot the raised far-left Elevator Scoop when you want to enter the selected Test Chamber.

- Before leaving the Hub for a large stack, hit the Turret Lock standup and collect the red Turret Control Center scoop three times. Start Turret Multiball first.

- Prepare Faith Plate by raising the left ramp, shooting under it into the L.O.F.T., and using the right white flipper button to push the Companion Cube back through its portal.

- Hit three lit Faith Plate shots to start Aerial Faith Plate Multiball. It can be added after Turret has started.

- Hit the ESC captive ball twice, then hit the Ramp Control Target while the virtual ball travels across the screen to start Edgeless Safety Cube Multiball.

- Once the Hub stack is spent, return to Test Chambers. Main Multiballs cannot progress in a chamber, and a chamber cannot start during a main Multiball.

## Full strategy

### Overview

In Portal Extended, work in the Hub to prepare Turret, Faith Plate, and Edgeless Safety Cube Multiballs. Start Turret first if you want a three-Multiball stack, then add the other two before returning to the Test Chambers.

### Simple Overview

### Check Before Play

- This shot map is for Portal Extended. Portal Standard omits the lower extension and substitutes some required shots in software.

- Confirm that the game is on Portal 1.2.3.0 with module driver 1.0.3.4 or newer before relying on current jackpot and option behavior.

### Builds Toward

GLaDOS final battle

Steps

- Start Test Chambers 1 through 6. Completion helps, but starting each one is enough for final qualification.

- Unlock and start Test Chamber 7, Turret Manufacturing.

- After all seven chambers have been played, the final wizard mode begins automatically.
