## Full strategy

### Overview

Completing 1-2-3-4 through any matching numbered target or rollover upgrades the rotating pointer's 50 sector to 500. The three pointer-value rollovers and both kick-out holes cash the value it indicates; collecting that upgraded value resets the numbered sequence. Each kick-out sends the ball quickly along a wire rail toward a flipper.

### Simple Overview

Complete 1-2-3-4 at whichever matching numbered targets or rollovers are safely available. That changes the pointer's 50 sector to 500. Then cash the upgraded pointer through the center lane or a kick-out hole whose fast wire-rail return you have already tested. Take ordinary pointer values when they arrive safely, but never aim for an outlane just because it also scores the pointer.

Response

Test each return before relying on a hold; be ready for an immediate flip if that copy does not settle the ball.

Response

### Machine Setup

- Confirm Gottlieb Roller Coaster model 296, OPDB exact variant G42pZ-ML171, the June 1971 two-player EM. Do not transfer this guide to the 1973 Maresa derivative G42pZ-Mp4PZ; its rules and playfield parity are unverified.

- Check ball count, replay or credit handling, tilt response, pointer indexing, and whether the installed event rules alter any replay award.

- Test every numbered target and rollover, the pointer and 50-to-500 upgrade, all five pointer-value switches, both kick-out coils, wire-rail alignment, flipper strength, and post position before competition play.
