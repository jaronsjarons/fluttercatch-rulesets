## Simple strategy

### Summary Title

The goal

### Summary

Use the green left eject for a Tour, the left ramp for Zeppelin Multiball, and the four target banks for Icarus X.

### Steps

- Start Earl's Court

Shoot the green left eject and select Earl's Court.

Mode Guide

Earl's Court

Reason

Choose it because its first objective is normally a direct spinner total.

Play

Make 70 spinner spins for the default first objective, then return to the left eject to start Earl's Court Tour Multiball.

- Start Zeppelin Multiball

Shoot the left ramp for three locks. The third lock starts Zeppelin Multiball. Later attempts require R-O-C-K to light the locks.

- Start Icarus X

Finish a bank-ending combo at each of the four target banks, then hit Icarus to start the 15-second playfield multiplier.

## Full strategy

### Summary

Complete Earl's Court and its Tour Multiball. During Zeppelin Multiball, complete the next Tour's objectives and finish combos at all four target banks to light Icarus X for its valuable scoring window.

### Steps

- Shoot the green left eject and select Earl's Court.

- Complete the current Earl's Court objective. The default first objective is 70 spinner spins.

Mode Notes

- Tour objective: Completing it stores one Tour lock. Complete all current objectives to light Tour Multiball at the left eject.

- The first Tour has one objective and starts with two balls. Later Tours add objectives and balls, up to four objectives and five balls.

- Return to the left eject to start Earl's Court Tour Multiball.

Mode Notes

- Complete LED, ZEP, and ROCK target banks for jackpots.

- LED builds a Super at the left eject. ZEP builds one at the right orbit. ROCK builds one at the left ramp.

- Each unique Super adds 1x to later Supers during this multiball.

- Hit Icarus three times to add a ball. The feature ends when one ball remains.

- After Tour Multiball, make the required flashing green right-ramp shots and select the next Tour at the left eject.

- For the first Zeppelin Multiball, shoot the left ramp three times to lock balls and start it. On later attempts, complete ROCK before each left-ramp lock.

Mode Notes

- Tour objectives and Tour locks can advance during a non-Tour multiball.

- A Tour Multiball cannot start during another multiball. A running Tour objective stays ready for later start.

- Start Zeppelin Multiball. Collect its four red jackpots and their paired double jackpots.

Mode Notes

- Left-orbit jackpot lights the upper side shot for double. Left-ramp jackpot lights the right orbit.

- Center-ramp jackpot lights the right orbit. Right-ramp jackpot lights the left eject.

- After all four resolve, collect a Super at the left eject or upper side shot. The upper side-shot Super is 2x.

- Complete LED, ZEP, and ROCK while Supers are lit. Each bank adds 1x, up to 4x.

- Hit Icarus three times to add a ball. The feature ends when one ball remains.

- During Zeppelin Multiball, complete the current Tour objectives. After multiball ends, shoot the left eject to start the completed Tour.

- During either multiball, finish bank-ending combos at all four target banks. Hit Icarus to start Icarus X when a valuable Super or Tour payoff is ready.

Mode Notes

- Each combo shot adds 0.1x to the ending bank. The four bank values multiply together.

- Icarus X runs for 15 seconds. Each upper side shot adds five seconds, and an Icarus hit recalculates the multiplier.

- Build Icarus X under multiball protection instead of forcing the target banks during single-ball play.

- Use a stored Band Boost to finish a valuable running combo. Save a red Super Band Boost for add-a-ball.

Mode Notes

- Band Boost: A stored action-button award. Green completes the running combo at the lowest bank and scores a 5x combo.

- Super Band Boost: Made from three stored boosts. Red completes the two lowest banks and scores a 10x combo.

- During multiball, green spots one Icarus hit. Red adds a ball.

### Fallback

Zeppelin Multiball first

When

Use this plan when the left Tour eject is not under control.

Steps

- Complete ROCK if left-ramp locks are not lit.

- Shoot the left ramp three times and start Zeppelin Multiball.

- Collect the four red jackpots.

- Use ball save for the upper side shot only when a double jackpot or Super is available.

- Complete the current Tour objectives during multiball.

- After multiball, shoot the left eject once to start the completed Tour.

### Builds Toward

Mothership Multiball

Steps

- Complete five songs. Shoot the lit right orbit into the eject to start Mothership Multiball.

### Overview

Led Zeppelin's Song runs during Tours and Multiballs; Tour objectives advance during Zeppelin Multiball. Choose Earl's Court at the green-lit left eject, finish its spinner objective, then return for Tour Multiball. Shoot right ramp to relight Tours, choose another, shoot left ramp three times for Zeppelin Multiball, finish its Tour objectives, complete combos at four target banks, then hit Icarus for playfield X.

### Simple Overview

Led Zeppelin runs Song shot patterns throughout the ball; Tours and Zeppelin Multiball are separate scoring routes. Shoot the green-lit left eject, choose a Tour, complete its shown objectives, then return for Tour Multiball. Shoot the left ramp three times for the first Zeppelin Multiball; finish a combo at each target bank, then hit the lit Icarus target for 15-second playfield X.
