## Simple strategy

### Summary Title

The goal

### Summary

Complete A-B to light double bonus. Shoot one side's spinner until its bonus reaches 50,000, collect 100,000 at that side saucer, and refill it.

### Steps

- Plunge the top saucer for 5,000 and one bonus advance.

- Nudge the saucer exit so the bumpers can knock down A and B. A-B lights double bonus.

- Choose the spinner with the safer return. Repeat it to build that side's bonus.

- At 50,000 bonus, the spinner rises from 100 to 1,000 per spin.

- After double bonus is lit, collect the full side bonus at its saucer for 100,000.

- Return to that spinner. Refill the side and repeat the doubled collect.

### Quick Info

- Double bonus

Summary

Complete A-B to double side-saucer and end-of-ball bonus collects; it does not multiply general playfield scoring.

- Side bonus

Summary

Each spinner builds its own side toward 50,000, where that spinner rises from 100 to 1,000 per spin.

- Saucer collect

Summary

A full 50,000 side scores 100,000 at its saucer after double bonus is lit, then can be refilled.

### Fallback

Alternative route: Spinner and end-of-ball collect

When

Use this plan when a side-saucer eject does not return safely.

Steps

- Leave the full doubled bonus uncollected.

- Keep shooting the 1,000-per-spin side.

- Before the drain, note which side arrow is lit. That side is collected at end of ball.

Details

- Verify that double bonus affects bonus collects only and that the drain awards the side shown by the lit arrow.

### Warning

A live catch can roll through the gap above an inlane and drain.

Use dead-bounce passes. Do not use an imperfect live catch, alley pass, or unnecessary post pass.

### Cautions

- Issue

A live catch can roll through the gap above an inlane and drain.

Response

Use dead-bounce passes. Do not use an imperfect live catch, alley pass, or unnecessary post pass.

Source Url

[Source](https://rules.silverballmania.com/rules/G4O1L-MDW47)

- Issue

A side-saucer kickout can return down the middle or reach only the end of the same-side flipper.

Response

Test each kickout. Use the end-of-ball fallback when a controlled return is not possible.

Source Url

[Source](https://rules.silverballmania.com/rules/G4O1L-MDW47)

- Issue

A weak spinner shot can fall onto a sling and return down the middle.

Response

Use only the spinner that reaches the top reliably.

Source Url

[Source](https://rules.silverballmania.com/rules/G4O1L-MDW47)

- Issue

The open gap above each inlane can drain a fast ball after a catch attempt.

Response

Let a safe feed dead bounce instead of stopping it high on the flipper.

Response

Stop and call the tournament director if the displayed score does not advance correctly.

### Simple Overview

In Grand Prix, complete A-B to light Double Bonus, then choose the side spinner with the safer return and repeat it until that side's bonus reaches 50,000. Shoot the matching saucer to collect 100,000, refill the same side through its spinner, and collect it again.

### Overview

In Grand Prix, A-B lights Double Bonus, each side spinner builds its own bonus to 50,000, and the matching saucer collects that side. Complete A-B, repeat the safer spinner until its value reaches 50,000 and the spinner rises to 1,000 per spin, then shoot that side's saucer for 100,000. Refill the same side and repeat the collect.
