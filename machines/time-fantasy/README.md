### Summary

Build time, complete T-I-M-E to start Snail Time, and use repeated 1-2-3-4-5 sets to reach 5x playfield scoring. Complete F-A-N-T-A-S-Y for held Bonus X.

### Steps

- Before starting Snail Time, add seconds with a lit return lane, the top 1 lane, and F-A-N-T-A-S-Y completions; time cannot be added once Snail Time begins.

- Complete the cycling T-I-M-E letters in the recessed left alley to start Snail Time.

- During Snail Time, use lane change to complete 1-2-3-4-5 repeatedly and raise playfield scoring toward 5x.

- At 5x, complete another 1-2-3-4-5 set for 450,000; complete F-A-N-T-A-S-Y between Snail Time runs to raise the held Bonus X toward 10x.

## Full strategy

### Overview

Complete T-I-M-E in the recessed left alley to start Snail Time, a slow-motion ball-save period that begins with at least 30 seconds. Add time before it starts with lit return lanes, the top 1 lane, and F-A-N-T-A-S-Y completions. During Snail Time, complete the top 1-2-3-4-5 lanes repeatedly to raise playfield scoring toward 5x; a full set at 5x is worth 450,000. Complete F-A-N-T-A-S-Y to raise the held end-of-ball Bonus X toward 10x.

### Simple Overview

Complete T-I-M-E in the recessed left alley to start Snail Time. During Snail Time, complete the top 1-2-3-4-5 lanes repeatedly to raise playfield scoring to 5x. Complete F-A-N-T-A-S-Y for held Bonus X, and build Snail Time above its 30-second minimum before starting it.

### Alternatives

- Build the mushroom value

When

Use this when the left orbit is repeatable and Snail Time is not ready.

Steps

- Shoot the mushroom jump in the arrow direction to raise its held value toward 100,000; avoid the opposite direction, which lowers it.

### Builds Toward

Use a full 99-second Snail Time

Steps

- Accumulate time before completing T-I-M-E, up to the 99-second cap.

- Enter Snail Time with lane progress ready so the 5x scoring window begins sooner.

### Machine Setup

- Confirm Snail Time duration, Extra Ball and Special conversions, ball count, playfield-multiplier behavior, and Bonus X maximum.

- Test the recessed T-I-M-E alley, all five upper lanes and lane change, F-A-N-T-A-S-Y switches, both return lanes, top 1 lane, mushroom jump, and ball-save releases.

### Cautions

- Issue

Snail Time cannot be extended after it begins.

Response

Build the timer before the final T-I-M-E letter instead of starting at the 30-second minimum.
